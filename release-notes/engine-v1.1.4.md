## Desk Widgets 1.1.4 (엔진)

위젯과 AI 도우미 연결을 받쳐 주는 기능이 늘어난 버전입니다(엔진 API 1.10 → 1.11).

### 바뀐 것

- **알림 카드 닫힘을 위젯이 압니다**: 카드를 확인·X·모두 확인으로 닫으면 위젯이 알 수 있습니다. 시계 1.1.3의 알림음이 이 방법으로 멈춥니다.
- **앱을 끌 때 작업 중인 위젯이 먼저 물어볼 수 있습니다**: 작업이 없으면 묻지 않고, 업데이트를 설치할 때도 묻지 않습니다.
- **AI 도우미 연결**: 도구가 사용자 확인을 요구한다는 표시를 AI 앱에 전달할 수 있게 했습니다.

### 설치

- `DeskWidgets-Setup-1.1.4.exe` 실행 (관리자 권한). 이전 엔진 위에 그대로 설치하면 되고, 설정과 설치한 위젯은 유지됩니다.
- 엔진 1.1.0 이상을 쓰고 있으면 위젯 관리 창의 **업데이트** 칸(또는 알림 카드)에서 바로 업데이트할 수 있습니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**. 앱 안에서 업데이트할 때는 Windows 관리자 권한 확인 창에 "알 수 없는 게시자"로 표시됩니다.

### 호환

- 엔진 API 1.11(1.10에 추가만). 지금 설치한 위젯은 모두 그대로 동작합니다.
