## Desk Widgets 1.1.1-test.1 (엔진, 내부 테스트)

> **내부 테스트 빌드**(Gitea 사전 릴리스)입니다. GitHub 릴리스·다운로드 페이지·앱 안 업데이트에는 나오지 않습니다. 정식 1.1.1 릴리스 노트는 GitHub에 배포할 때 따로 씁니다.

**메모리를 덜 쓰는** 버전입니다(엔진 API 1.6 그대로). 엔진과 모든 위젯이 1.1.1로 함께 배포됩니다.

### 바뀐 것

- **알림 카드**: 화면에 뜬 알림 카드들이 프로세스 하나를 함께 씁니다. 카드가 한 장 늘 때마다 메모리가 약 18 MB에서 약 2 MB로 줄어듭니다. 카드 순서(새 카드가 위)·위치·메뉴·버튼·대기열·모두 확인은 그대로입니다.
- **스티키 노트**: 스티키 노트 위젯 1.1.1과 함께 쓰면 노트 창과 목록 창도 프로세스 하나를 함께 씁니다(노트 한 장당 약 16 MB → 약 2 MB).
- **복구**: 함께 쓰는 프로세스가 비정상 종료되면 카드와 노트가 새 프로세스에서 다시 열립니다. 카드 프로세스가 1분에 3번 넘게 종료되면 그 뒤로는 예전처럼 카드마다 프로세스를 따로 씁니다.
- 위젯 창을 닫을 때 엔진이 들고 있던 정리 작업도 함께 지웁니다(오래 켜 둘 때 조금씩 쌓이던 것).
- 다른 위젯 창(두레이·캘린더·메일·할 일·시계·시스템 모니터)은 위젯마다 따로 격리된 그대로입니다.

### 설치

- `DeskWidgets-Setup-1.1.1-test.1.exe` 실행 (관리자 권한). 이전 엔진 위에 그대로 설치하면 되고, 설정과 설치한 위젯은 유지됩니다.
- 내부 테스트 빌드라 앱 안 업데이트에는 나오지 않습니다. Gitea 사전 릴리스에서 설치 파일을 받아 직접 실행합니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**. 앱 안에서 업데이트할 때는 Windows 관리자 권한 확인 창에 "알 수 없는 게시자"로 표시됩니다.

### 호환

- 엔진 API 1.6 그대로. 지금 배포된 모든 위젯이 그대로 동작합니다.
- 위젯 개발: 같은 페이지 창을 여러 개 띄우는 위젯은 `ctx.createSharedWidgetWindow`로 창들을 한 프로세스에 열 수 있습니다([위젯 만들기](https://github.com/Htaeyong/desk-widgets/blob/main/docs/widget-dev.md)).
