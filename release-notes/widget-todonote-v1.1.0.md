## Desk Widgets-TodoNoteWidget 1.1.0 (할 일 노트 위젯)

새 위젯 **할 일 노트**의 첫 정식 버전입니다. 스티키 노트를 바탕으로 만든 별도 위젯으로, **날짜를 걸면 그 노트가 할 일**이 됩니다. 스티키 노트·할 일 목록은 그대로이며 함께 설치해도 됩니다.

### 기능

- **날짜 걸기**: 노트 창의 ⏰ 버튼·Ctrl+Shift+D·`/` 명령으로 "내일 3시", "10/30", "다음 주 월요일 오후 3시", "매월 1일", "완료 후 30일"처럼 말로 입력합니다. 날짜 창에서 시간·종일·반복·알림을 고르고 달력에서도 고릅니다. 새 노트의 첫 줄이 날짜 문구로 끝나면 Tab으로 적용하는 제안이 보입니다.
- **마감 줄과 완료**: 날짜가 걸린 노트에 마감 칩(지남·오늘·곧·나중)과 **✓ 완료**(Ctrl+Enter). 완료하면 창이 닫히고 노트는 `완료` 폴더로 갑니다(되돌리기 가능).
- **반복**: 정해진 날(매주 금, 매월 말일, 매년…) 또는 완료 후 기간. 완료하면 다음 회차로 넘어가고 체크 목록을 비웁니다(설정).
- **알림**: 마감 시각(또는 정한 만큼 전)에 알림 카드 — 완료·N분 뒤·노트 열기. 종일 할 일은 그날 오전 9시. PC가 꺼져 있던 동안 지난 알림은 한 장으로 모아 보여 줍니다.
- **목록**: 노트·할 일·완료·보관함 4탭. 할 일은 지남·오늘·곧·나중으로 묶어 마감 빠른 순.
- **자동 삭제**: 완료한 노트는 정한 기간(기본 30일, 삭제 안 함 가능) 뒤 **Windows 휴지통으로** 옮깁니다. 반복 노트·보관함 노트는 지우지 않습니다.
- **연동**(설정에서 켜면): 두레이·메일의 "할 일에 추가"가 할 일 노트를 만들고, 캘린더에 노트 마감을 표시합니다. 할 일 목록 위젯의 할 일을 노트로 가져올 수 있습니다.
- 스티키 노트와 같은 편집·첨부·`[[링크]]`·Markdown 파일 저장(`문서\Desk Widgets\할 일 노트`, 스티키 노트와 다른 폴더), 노트 제목과 ID 파일 이름, 엔진 1.1.1의 **동기화**(노트·보관함·완료·첨부)를 지원합니다.

### 설치

- `DeskWidgets-TodoNoteWidget-Setup-1.1.0.exe` 실행 (관리자 권한). 노트는 문서 폴더의 Markdown 파일이라 위젯을 지워도 남습니다. 내부 시험판(0.0.x)을 쓰던 PC는 그 위에 그대로 설치하면 됩니다.
- 제어판: **Desk Widgets-TodoNoteWidget 1.1.0**
- 설치 순서: **엔진(Desk Widgets) 1.1.1 먼저**, 그다음 위젯. 엔진 1.1.0을 쓰고 있으면 위젯 관리 창의 **업데이트** 칸에서 엔진을 먼저 업데이트하세요(엔진이 오래되면 위젯 업데이트에 "엔진을 먼저 업데이트"가 표시됩니다).
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**.

### 요구 사항

- **Desk Widgets 엔진 1.1.1 이상** (엔진 API 1.8). 두레이·메일·캘린더 연동은 각 위젯 1.1.1이 필요합니다.
