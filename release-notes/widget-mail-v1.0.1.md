## Desk Widgets-MailWidget 1.0.1 (메일 위젯)

### 새 기능

- **함께 볼 메일함**: 서버의 메일 규칙으로 받은편지함이 아닌 메일함에 바로 옮겨지는 메일도 볼 수 있습니다. 계정 설정 → **메일함 불러오기** → 볼 메일함 체크. 그 메일함의 메일이 목록·안 읽은 수·새 메일 카드·대시보드에 함께 들어가고 메일함 이름이 표시됩니다. 받은편지함은 바로, 다른 메일함은 3분마다 확인합니다(⟳는 바로).

### 고친 점

- **⟳ 새로고침**: 누르면 아이콘이 제자리에서 돌고, 끝나면 `새 메일 N통` / `새 메일 없음` / 오류를 잠깐 보여 줍니다(세 테마 모두).
- **중요·안 읽음 숫자와 목록**: 숫자를 눌렀을 때 나오는 목록이 숫자보다 적게 보이던 문제를 고쳤습니다. 이제 둘 다 서버 기준으로 같습니다(처음 200통, 더 있으면 더 보기).

### 설치

- `DeskWidgets-MailWidget-Setup-1.0.1.exe` 실행 (관리자 권한). 1.0.0 위에 그대로 설치하면 되고, 계정·비밀번호·분류·주소록은 유지됩니다.
- 제어판: **Desk Widgets-MailWidget 1.0.1**

### 요구 사항

- Desk Widgets 엔진 1.0.1 이상 (엔진 API 1.3). 새 메일 카드의 분류 메뉴는 엔진 1.0.2부터.
