## Desk Widgets-DoorayWidget 1.0.0 (두레이 대시보드 위젯)

Desk Widgets 엔진에서 동작하는 **두레이 대시보드 위젯**의 첫 정식 버전입니다.

> **Desk Widgets 1.0.0(엔진)이 먼저 설치되어 있어야 합니다.** 엔진이 없으면 설치 파일이 안내하고 멈춥니다.
> 이전 앱 **Dooray Widget 1.0.0~1.0.3**과는 다른 제품이며, 그 앱을 대신합니다.

### 설치

1. (처음이면) `DeskWidgets-Setup-1.0.0.exe`로 엔진 설치
2. `DeskWidgets-DoorayWidget-Setup-1.0.0.exe` 실행 (관리자 권한)
   - 설치 위치: `C:\Program Files\chilgong88\widgets\dooray`
   - 제어판 이름: **Desk Widgets-DoorayWidget** (게시자 chilgong88)
   - 설치하면 바로 위젯이 뜹니다. 처음 쓰는 경우 **두레이 대시보드 설정** 창이 열리면 두레이 도메인과 API 토큰을 입력하세요.

### 이전 앱(Dooray Widget)에서

- 설치할 때 이전 앱 **Dooray Widget**을 설정은 남긴 채 자동으로 제거합니다(자동 실행 등록·바로가기 포함).
- 엔진이 옮겨 둔 이전 설정(두레이 주소·API 토큰, 분류, 조건 알림, 테마, 창 위치)으로 바로 시작합니다. 토큰을 다시 입력하지 않아도 됩니다.

### 기능

- 전체 요약(미완료·지연·임박·내 업무)과 프로젝트별 대시보드, 프로젝트를 별도 위젯 창으로 분리
- 검색(초성 포함), 두레이 태그, 나만의 분류
- 알림: 멘션·새 댓글·배정·새 업무·상태 변경·완료·마감 지남, 조건 알림(예: 일일보고 미등록)
- **알림 카드에서 바로 분류 지정**: 카드의 "분류" 버튼으로 위젯을 열지 않고 업무를 내 분류에 넣고 빼거나 새 분류를 만들기
- 테마 10종(다크 글래스, 빅서 라이트, 미드나잇, 선셋, 모노 미니멀, 사이드바, 칸반 보드, 일정, 미니 바, 페이퍼)과 미리보기
- 설정은 위젯 제목줄의 ⚙ (또는 트레이 → 위젯 관리 → 설정). 제목줄 ✕는 이 위젯 끄기(앱 종료는 트레이 메뉴)

### 요구 사항

- Desk Widgets 엔진 1.0.0 이상 (엔진 API 1.1)

### 제거

제어판에서 **Desk Widgets-DoorayWidget** 제거 → "두레이 대시보드 위젯의 설정도 함께 삭제할까요?" (기본: 유지).
