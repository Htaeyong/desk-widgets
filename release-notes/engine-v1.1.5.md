## Desk Widgets 1.1.5 (엔진)

동기화 탭의 위젯 체크를 다듬은 버전입니다.

### 바뀐 것

- **동기화할 위젯 체크가 되돌아가지 않습니다**: 체크를 바꾼 뒤 "설정 저장"을 누르기 전에 자동 확인이 돌면 체크가 저장된 값으로 돌아가던 문제를 고쳤습니다. "지금 동기화"는 바꾼 체크를 먼저 저장합니다.
- **체크를 끈 위젯은 완전히 빠집니다**: 그 위젯의 설정·테마 선택·항목·노트가 이 PC에서 오가지 않고, 되돌리기와 충돌 처리에서도 빠집니다.
- 탭 제목을 "동기화할 위젯"으로 바꾸고, 체크를 끄면 무엇이 빠지는지 안내를 넣었습니다.

### 설치

- `DeskWidgets-Setup-1.1.5.exe` 실행 (관리자 권한). 이전 엔진 위에 그대로 설치하면 되고, 설정과 설치한 위젯은 유지됩니다.
- 엔진 1.1.0 이상을 쓰고 있으면 위젯 관리 창의 **업데이트** 칸(또는 알림 카드)에서 바로 업데이트할 수 있습니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**. 앱 안에서 업데이트할 때는 Windows 관리자 권한 확인 창에 "알 수 없는 게시자"로 표시됩니다.

### 호환

- 엔진 API 1.11(변경 없음). 지금 설치한 위젯은 모두 그대로 동작합니다.
