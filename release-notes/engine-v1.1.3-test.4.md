# Desk Widgets 1.1.3-test.4 — 내부 테스트 (#108)

현장 테스트에서 나온 동기화 문제를 고쳤습니다(엔진만, 위젯은 그대로).

- **나중에 연결한 PC에 노트가 안 오던 문제**: 노트 폴더가 OneDrive 안에 있으면 노트를 통째로 건너뛰던 규칙을 고쳤습니다(동기화 폴더와 겹칠 때만 건너뜀). 충돌 하나가 다른 받기까지 멈추던 문제도 고쳐, 충돌 항목만 기다리고 나머지는 계속 주고받습니다. 두 PC가 같은 이름의 노트를 만들면 한쪽에 (2)가 붙습니다.
- **충돌이 너무 많던 문제**: 손대지 않은 기본값 설정은 내보내지 않아 충돌이 줄었습니다. 비교 화면에 "모두 이 PC 값 / 모두 다른 PC 값 / 모두 최신 값" 버튼(위젯별 포함)을 넣었습니다. "다른 PC 값"이 이 PC 값을 고르던 경우와, 자동 확인 중 선택이 버려지던 경우도 고쳤습니다.
- **동기화 주기**: 동기화 탭에서 자동 확인 주기(1·2·5·10·30분, 기본 2분)를 고르고, 마지막 확인·다음 확인·폴더 감시 상태(감시 중 / 주기 확인만)를 실시간으로 보여 줍니다.
