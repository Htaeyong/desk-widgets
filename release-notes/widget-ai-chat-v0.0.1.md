# Desk Widgets-AiChatWidget 0.0.1 — 내부 테스트 (#129)

말로 시키면 **이 PC에 설치된 Claude Code가 내 API 키로** 작업하고 결과를 돌려주는 위젯입니다. 구독 로그인은 쓰지 않습니다.

- 세션 목록과 이어 가기, 승인·질문 카드, 중지, 월 예산 대비 추정 잔여 표시.
- 결과에 만족하면 작업을 요약해 보고 고친 뒤 저장하고, 비슷한 요청에 다시 씁니다. 쓴 요약은 화면에 표시됩니다.
- **필요한 것:** Claude Code 2.1.309 이상, 전용 workspace에서 만든 API 키. 시험 순서는 위키의 "AI 대화 내부 테스트"를 보세요.
- **주의:** 내 Windows 계정 권한으로 명령을 실행합니다. Windows에는 샌드박스가 없어 작업 폴더가 강제 경계가 아닙니다. 중요한 자료는 백업하고, 전용 키와 낮은 한도를 쓰세요.
- 실제 Claude Code와 API로는 이번 내부 테스트에서 처음 돌립니다.
