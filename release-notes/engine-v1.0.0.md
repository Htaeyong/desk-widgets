## Desk Widgets 1.0.0 (엔진)

바탕화면 위젯 **엔진**의 첫 정식 버전입니다. 엔진을 한 번 설치하고, 사용할 위젯은 따로 설치합니다. 설치한 위젯은 모두 이 엔진 안에서 함께 실행됩니다(위젯마다 Electron을 따로 띄우지 않음).

> 이전 앱 **Dooray Widget 1.0.0~1.0.3**(`DoorayWidget-Setup-*`)과는 다른 제품입니다. 두레이 기능은 **두레이 위젯**(`DeskWidgets-DoorayWidget-Setup-1.0.0.exe`)으로 따로 설치합니다.

### 설치

1. `DeskWidgets-Setup-1.0.0.exe` 실행 (관리자 권한, 모든 사용자용)
   - 설치 위치: `C:\Program Files\chilgong88\Desk Widgets`
   - 제어판 이름: **Desk Widgets** (게시자 chilgong88)
   - 설치가 끝나면 실행되고, 작업 표시줄 오른쪽에 **트레이 아이콘**과 위젯 관리 창이 나타납니다.
2. 이어서 사용할 위젯의 설치 파일을 실행합니다. 설치하면 바로 나타납니다.

코드 서명이 없어 처음 실행할 때 SmartScreen 경고가 뜰 수 있습니다: **추가 정보 → 실행**.

### 주요 기능

- **트레이 아이콘 + 위젯 관리 창**: 설치된 위젯(이름·버전·상태), 사용 켜기/끄기, 위젯별 설정, 위젯이 없을 때 설치 안내
- 위젯을 **설치·제거하면 실행 중에 바로 반영** (다시 켤 필요 없음). 설정이 필요한 위젯은 설치 직후 설정 창이 열림
- 일반 설정: Windows 시작 시 자동 실행, 바탕 화면 보기(Win+D)에도 위젯 유지, 자리 비움 중 갱신 멈춤, 알림 카드(유지 시간·최대 개수)
- 알림 카드: 화면 오른쪽 아래에 쌓이는 카드, 위젯이 붙인 메뉴(예: 두레이 "분류") 지원
- 엔진 API 1.1 (위젯이 요구하는 버전과 맞지 않으면 "호환 안 됨"과 이유 표시)

### 이전에서 옮겨 오기

- 이전 앱 Dooray Widget을 쓰셨다면, 엔진이 처음 실행될 때 `%APPDATA%\dooray-widget`의 설정(두레이 주소·API 토큰, 분류, 조건 알림, 테마, 창 위치)을 새 폴더로 복사해 둡니다. 바로 이어서 두레이 위젯을 설치하세요. 이전 폴더는 지우지 않고 백업으로 남깁니다(제거할 때도 지우지 않음).
- 테스트 빌드(1.1.0-test.x)를 설치해 두셨다면 그대로 1.0.0을 설치하면 됩니다. 테스트 빌드를 설정은 유지한 채 제거하고 설치합니다.

### 제거

제어판에서 **Desk Widgets** 제거 → "사용자 설정도 함께 삭제할까요?" (기본: 유지). 설치한 위젯은 제어판에서 따로 제거합니다.
