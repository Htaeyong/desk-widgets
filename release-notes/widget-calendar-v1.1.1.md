## Desk Widgets-CalendarWidget 1.1.1 (캘린더 위젯)

**D-day**, **새 일정 종일 기본값**, 할 일 노트의 **노트 마감**, 엔진 1.1.1의 **동기화**가 들어간 버전입니다.

### 바뀐 것

- **D-day**: 일정 자세히의 **D-day로 표시**, 달력 위 ★ 버튼, D-day 줄의 +로 만듭니다. D-N / D-day / D+N(당일 포함), 매년 반복(2월 29일은 평년에 2월 28일), 지난 한 번짜리 D-day는 7일 뒤 보관함으로. 기본 테마는 위쪽 D-day 줄(가까운 순, 기본 3개), 큰 달력은 날짜 칸 ★ 배지와 위쪽 요약 줄. 일정과 연결한 D-day는 일정의 날짜·제목을 따라갑니다(반복 일정은 다음 회차).
- **D-day 알림**(선택, 기본 꺼짐): 당일·1·3·7일 전 오전 9시에 알림 카드. 켜기·끄기는 PC마다 따로입니다.
- **새 일정은 종일로 시작**(설정 → 표시, 기본 꺼짐): 켜면 + 버튼·날짜 두 번 클릭으로 여는 새 일정 창이 종일로 열립니다. 종일을 풀면 다음 정각부터 1시간입니다.
- **노트 마감**: 새 위젯 할 일 노트의 마감을 달력에 보여 주고(반복 노트는 지금 회차만), 캘린더에서 날짜를 바꾸면 노트의 마감이 바뀝니다. 상세의 **노트 열기**로 노트를 엽니다. 할 일 목록 위젯 마감 표시도 그대로입니다.
- **마감 색**: 설정 → 할 일 연동의 **노트 마감 색**·**할 일 마감 색**으로 두 오버레이의 색을 바꿀 수 있습니다(기본 노랑·주황).
- **동기화**(선택): 내 캘린더 일정, D-day, CalDAV 계정 정보(이름·주소·색·캘린더 선택)와 설정을 다른 PC와 주고받습니다. 동기화는 엔진 1.1.1의 **동기화 폴더**(위젯 관리 창 → 동기화 탭)를 켜고 이 위젯을 고를 때만 동작합니다. 비밀번호와 비공개 ICS 주소는 동기화하지 않고, 다른 PC에서 받은 계정은 꺼진 상태로 들어옵니다(이 PC에서 비밀번호를 넣고 켜기).
- **Google 계정 로그인은 나중에**: 설정에 **Google 계정** 칸이 보이지만 이 버전에서는 꺼져 있습니다(Google의 앱 확인이 끝나면 다음 버전에서 켭니다). 그동안 Google 캘린더는 iCal(ICS) 주소를 **ICS 구독**으로 넣어 읽기 전용으로 볼 수 있습니다.

### 설치

- `DeskWidgets-CalendarWidget-Setup-1.1.1.exe` 실행 (관리자 권한). 이전 버전 위에 그대로 설치하면 되고, 구독·계정·비밀번호·테마는 유지됩니다.
- 제어판: **Desk Widgets-CalendarWidget 1.1.1**
- 설치 순서: **엔진(Desk Widgets) 1.1.1 먼저**, 그다음 위젯. 엔진 1.1.0을 쓰고 있으면 위젯 관리 창의 **업데이트** 칸에서 엔진을 먼저 업데이트하세요(엔진이 오래되면 위젯 업데이트에 "엔진을 먼저 업데이트"가 표시됩니다).
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**.

### 요구 사항

- **Desk Widgets 엔진 1.1.1 이상** (엔진 API 1.8). 노트 마감은 할 일 노트 1.1.0, 할 일 마감은 할 일 목록 위젯이 필요합니다.
