## Desk Widgets-StickyNoteWidget 1.1.1 (스티키 노트 위젯)

**메모리 절약**, **노트 제목과 파일 이름 분리**, 엔진 1.1.1의 **동기화**가 들어간 버전입니다.

### 바뀐 것

- **메모리 절약**: 노트 창과 노트 목록 창이 프로세스 하나를 함께 씁니다. 노트가 한 장 늘 때마다 메모리가 약 16 MB에서 약 2 MB로 줄어듭니다. 함께 쓰는 프로세스가 비정상 종료되면 창이 보낸 내용을 저장하고 노트와 목록을 같은 자리에 다시 엽니다.
- **제목과 파일 이름 분리**: 노트 파일 이름은 바뀌지 않는 ID 이름(`YYYYMMDD-HHmmss-<id>.md`)이고 제목은 노트 머리말(`title:`)에 있습니다. 제목을 바꿔도 파일·첨부 폴더 이름은 그대로이고, 같은 제목의 노트를 여러 개 만들 수 있습니다. 검색과 `[[제목]]` 링크는 제목으로 찾습니다.
- **처음 켤 때 한 번 정리**: 이전 버전의 노트 폴더는 처음 켤 때 위젯이 만든 노트의 파일 이름을 ID 이름으로 바꿉니다(첨부 폴더·이미지 경로·다른 노트의 파일 링크도 함께). 제목·내용과 고친 시각은 그대로이고, 결과는 목록 위에 한 줄로 알립니다. 탐색기 등에서 직접 만든 파일은 이름을 바꾸지 않습니다.
- **정보…**: 노트 오른쪽 클릭 → **정보…** 에서 제목, 파일 경로(복사), 만든 때·바뀐 때, 크기를 봅니다.
- **노트 폴더 바꾸기**: 폴더를 바꾸면 "기존 노트를 새 폴더로 옮길까요?"를 묻습니다. **옮기기**는 노트·첨부·보관함을 복사해 확인한 뒤 원본을 휴지통으로 보냅니다.
- **미드나잇 글래스** 노트 색 추가(새 노트의 기본 색은 노랑 그대로).
- **동기화**(선택): 노트·보관함·첨부 파일과 노트별 색, 표시 설정을 다른 PC와 주고받습니다. 동기화는 엔진 1.1.1의 **동기화 폴더**(위젯 관리 창 → 동기화 탭)를 켜고 이 위젯을 고를 때만 동작합니다. 노트는 그대로 이 PC의 노트 폴더에 있고, 창 위치와 노트 폴더 경로는 PC마다 따로입니다. 파일 하나의 한도는 20MB입니다.
- **고침**: 저장 대기 중이던 노트가 다른 프로그램(또는 다른 PC)에서 고친 내용을 덮어쓸 수 있던 문제, 이번 실행에서 만든 노트를 창이 열리기 전에 닫으면 빈 노트로 보고 지울 수 있던 문제를 고쳤습니다.

### 설치

- `DeskWidgets-StickyNoteWidget-Setup-1.1.1.exe` 실행 (관리자 권한). 이전 버전 위에 그대로 설치하면 되고, 설정과 노트 파일(`문서\Desk Widgets\스티키 노트`)은 그대로입니다(파일 이름만 위처럼 한 번 정리).
- 제어판: **Desk Widgets-StickyNoteWidget 1.1.1**
- 설치 순서: **엔진(Desk Widgets) 1.1.1 먼저**, 그다음 위젯. 엔진 1.1.0을 쓰고 있으면 위젯 관리 창의 **업데이트** 칸에서 엔진을 먼저 업데이트하세요(엔진이 오래되면 위젯 업데이트에 "엔진을 먼저 업데이트"가 표시됩니다).
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**.

### 요구 사항

- **Desk Widgets 엔진 1.1.1 이상** (엔진 API 1.8). 날짜·알림이 있는 할 일 노트가 필요하면 새 위젯 **할 일 노트**를 함께 설치하세요(노트 폴더는 따로).
