## Desk Widgets-DoorayWidget 1.1.1 (두레이 대시보드 위젯)

엔진 1.1.1의 **동기화**와 새 위젯 **할 일 노트** 연동이 들어간 버전입니다.

### 바뀐 것

- **동기화**(선택, 기본 꺼짐): 나만의 분류, 업무 지정, 조건 알림 규칙을 다른 PC와 주고받습니다. 동기화는 엔진 1.1.1의 **동기화 폴더**(위젯 관리 창 → 동기화 탭)를 켜고 이 위젯을 고를 때만 동작합니다. API 토큰은 동기화하지 않습니다. 다른 PC에서 받은 조건 알림 규칙은 **꺼진 상태로** 들어오며, 이 PC에서 켤 때까지 알리지 않습니다.
- **할 일에 추가 → 할 일 노트**: 할 일 노트가 설치돼 있으면 업무를 할 일 노트로 보냅니다(제목·본문 글자·마감·원본 링크가 든 노트). 할 일 노트와 할 일 목록이 모두 설치돼 있으면 설정 → **할 일 연동**의 **추가할 곳**에서 고릅니다. 같은 업무를 다시 추가하면 그 노트를 엽니다. 두레이의 업무는 바꾸지 않습니다.
- 그 밖의 기능과 화면은 1.1.0과 같습니다.

### 설치

- `DeskWidgets-DoorayWidget-Setup-1.1.1.exe` 실행 (관리자 권한). 이전 버전 위에 그대로 설치하면 되고, 두레이 주소·API 토큰·분류·조건 알림·테마는 유지됩니다.
- 제어판: **Desk Widgets-DoorayWidget 1.1.1**
- 설치 순서: **엔진(Desk Widgets) 1.1.1 먼저**, 그다음 위젯. 엔진 1.1.0을 쓰고 있으면 위젯 관리 창의 **업데이트** 칸에서 엔진을 먼저 업데이트하세요(엔진이 오래되면 위젯 업데이트에 "엔진을 먼저 업데이트"가 표시됩니다).
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**.

### 요구 사항

- **Desk Widgets 엔진 1.1.1 이상** (엔진 API 1.8). **할 일에 추가**는 할 일 노트 1.1.0 또는 할 일 목록 위젯이 필요합니다.
