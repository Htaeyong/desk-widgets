# Desk Widgets-StickyNoteWidget 1.1.3-test.6 — 내부 테스트 (#113)

노트 파일 이름을 **바뀌지 않는 ID 이름**(`YYYYMMDD-HHmmss-<id>.md`)으로 바꿨습니다. 제목은 노트 안(`title:`)에만 두어, 제목을 바꿔도 파일·첨부 폴더 이름은 그대로이고 같은 제목의 노트를 여러 개 만들 수 있습니다. 검색과 `[[제목]]` 링크는 제목으로 찾습니다. 노트 오른쪽 클릭 → **정보…** 에서 제목, 파일 경로(복사), 만든 때·바뀐 때, 크기를 볼 수 있습니다.

이전 판의 노트 폴더는 처음 켤 때 한 번 정리해 위젯이 만든 노트의 파일 이름을 ID 이름으로 바꿉니다(첨부 폴더·이미지 경로·다른 노트의 파일 링크도 함께). 제목과 내용은 그대로이며 결과를 목록 위에 한 줄로 알립니다. 탐색기 등에서 직접 만든 파일은 이름을 바꾸지 않습니다.

내부 테스트용(Gitea 사전 릴리스)이며 GitHub·다운로드 페이지·앱 안 업데이트에는 나오지 않습니다.
