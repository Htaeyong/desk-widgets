# Desk Widgets 1.1.3-test.2 — 내부 테스트 (#108)

동기화 구조를 다시 만들었습니다. 위젯은 이 PC의 기본 저장소만 쓰고, 동기화 폴더는 엔진만 쓰는 주고받기 폴더입니다. 엔진이 이 PC의 변경을 내보내고 다른 PC의 변경을 항목 단위로 반영하며, 같은 항목을 양쪽에서 바꿨을 때만 비교 화면을 보여 줍니다. 엔진 저장소를 항목·파일·비밀 저장소 세 가지로 정리했고(엔진 API 1.8 확정), 비밀번호·토큰은 동기화에 들어갈 수 없게 막았습니다. 1.1.3-test.1에서 동기화 폴더에 직접 저장된 데이터는 처음 실행 때 확인·백업한 뒤 이 PC 저장소로 되돌립니다(동기화 폴더의 원본은 지우지 않음).
