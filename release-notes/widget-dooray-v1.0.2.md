## Desk Widgets-DoorayWidget 1.0.2 (두레이 대시보드 위젯)

### 새 기능

- **테마 배경 불투명도**: 설정 창의 테마 아래 슬라이더(0~100%)로 바탕화면이 얼마나 비칠지 테마마다 정합니다. 글자는 그대로 선명하고, 미리보기에도 반영됩니다. (엔진 1.0.1 이상에서 동작)
- **'댓글 수정' 알림** (선택, 기본 꺼짐): 설정 → 알림 종류에서 켜면, 내 업무 범위 안에서 다른 사람이 댓글을 고쳤을 때도 알림 카드가 뜹니다. 내가 고친 것은 알리지 않고, 수정으로 나를 멘션하면 멘션 알림으로 옵니다. 앱을 켠 뒤 본 적이 있는 댓글의 수정만 알 수 있어, 다시 켠 직후의 첫 수정은 놓칠 수 있습니다.

### 설치

- `DeskWidgets-DoorayWidget-Setup-1.0.2.exe` 실행 (관리자 권한). 1.0.1 위에 그대로 설치하면 되고, 설정·분류·조건 알림은 유지됩니다.
- 제어판: **Desk Widgets-DoorayWidget 1.0.2**

### 요구 사항

- Desk Widgets 엔진 1.0.0 이상 (엔진 API 1.1). 배경 불투명도 슬라이더는 엔진 1.0.1 이상에서 적용됩니다.
