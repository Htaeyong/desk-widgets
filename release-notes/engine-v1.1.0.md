## Desk Widgets 1.1.0 (엔진)

엔진과 설치한 위젯의 **새 버전을 앱 안에서 알려 주고, 누르면 설치**하는 버전입니다(엔진 API 1.6 그대로).

### 새 기능

- **앱 안에서 업데이트**: 시작할 때(조금 뒤)와 하루 한 번 엔진과 설치한 위젯의 최신 버전을 확인합니다. 새 버전이 있으면 알림 카드와 트레이 메뉴(**업데이트 있음**)로 알려 줍니다.
- 위젯 관리 창의 **업데이트** 칸에서 제품마다 현재·최신 버전을 보고 **업데이트**를 누르면 설치 파일을 받아 실행합니다. **자동으로 설치하지 않습니다.** **업데이트 확인** 버튼으로 바로 확인할 수도 있습니다.
- 설치 파일은 이 프로젝트의 GitHub 릴리스에서만 받고, 다운로드 페이지에 게시된 크기·SHA-256과 같을 때만 실행합니다. 다르면 파일을 지우고 알립니다.
- 위젯의 새 버전이 더 새 엔진을 요구하면 **엔진을 먼저 업데이트**하라고 알려 줍니다.
- 엔진을 업데이트하면 Desk Widgets가 잠시 종료되고, 설치가 끝나면 다시 시작됩니다. 설정과 설치한 위젯은 그대로입니다.

### 개인정보

- 업데이트 확인은 `widgets.chilgong88.com`에서 버전 정보(`products.json`)를 받아 오는 것뿐이고, 설치한 위젯 목록이나 다른 정보는 보내지 않습니다. 설치 파일은 GitHub에서 받습니다.
- 자동 확인은 위젯 관리 창 → **새 버전 자동 확인**에서 끌 수 있습니다(기본 켜짐).

### 설치

- `DeskWidgets-Setup-1.1.0.exe` 실행 (관리자 권한). 이전 엔진 위에 그대로 설치하면 되고, 설정과 설치한 위젯은 유지됩니다.
- 이 버전부터는 다음 업데이트를 앱 안에서 받을 수 있습니다. 1.0.x에서 1.1.0으로는 설치 파일을 직접 받아 설치합니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**. 앱 안에서 업데이트할 때는 Windows 관리자 권한 확인 창에 "알 수 없는 게시자"로 표시됩니다.

### 호환

- 엔진 API 1.6 그대로. 지금 배포된 모든 위젯이 그대로 동작합니다.
