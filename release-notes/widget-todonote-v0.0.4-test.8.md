# Desk Widgets-TodoNoteWidget 0.0.4-test.8 — 내부 테스트 (#113)

노트 제목과 파일 이름을 분리했습니다. 제목은 노트 안(`title:`)에 적고, 같은 제목의 노트를 여러 개 만들 수 있습니다. 완료한 노트는 완료 폴더에 `완료날짜 제목.md`로 저장되어, 반복 할 일을 완료해도 제목에 (2), (3)이 붙지 않습니다. `[[제목]]` 링크는 같은 제목이 여럿이면 열 수 있는 노트, 그다음 가장 최근에 완료한 노트를 엽니다.

이전 판에서 쓰던 노트 폴더는 처음 켤 때 한 번 정리합니다(제목을 노트 안에 적고, 자동으로 붙은 (n)을 빼고, 완료 노트 파일 이름 앞에 완료 날짜를 붙임). 내용은 그대로이며, 결과를 목록 위에 한 줄로 알립니다.
