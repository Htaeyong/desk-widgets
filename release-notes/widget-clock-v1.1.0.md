## Desk Widgets-ClockWidget 1.1.0 (시계 위젯)

Desk Widgets **1.1.0**부터 엔진과 모든 위젯이 같은 버전 번호로 배포됩니다. 이 위젯의 기능은 1.0.0과 같습니다.

### 바뀐 것

- **버전 통일**: 1.0.0 → 1.1.0. 위젯 코드와 화면은 1.0.0과 같습니다.
- **앱 안에서 업데이트**(엔진 1.1.0의 기능): 엔진 1.1.0을 쓰면 위젯 관리 창의 **업데이트** 칸에서 이 위젯의 새 버전을 알려 주고, 누르면 설치합니다.

### 설치

- `DeskWidgets-ClockWidget-Setup-1.1.0.exe` 실행 (관리자 권한). 이전 버전 위에 그대로 설치하면 되고, 설정·타이머·알람·테마는 유지됩니다.
- 제어판: **Desk Widgets-ClockWidget 1.1.0**
- 설치 순서: **엔진(Desk Widgets) 먼저**, 그다음 위젯. 엔진이 없으면 위젯 설치 파일이 알려 주고 멈춥니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**.

### 요구 사항

- Desk Widgets 엔진 1.0.1 이상 (엔진 API 1.3). 앱 안에서 업데이트하려면 엔진 1.1.0이 필요합니다.
