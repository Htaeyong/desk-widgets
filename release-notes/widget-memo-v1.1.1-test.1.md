## Desk Widgets-StickyNoteWidget 1.1.1-test.1 (스티키 노트 위젯, 내부 테스트)

> **내부 테스트 빌드**(Gitea 사전 릴리스)입니다. GitHub 릴리스·다운로드 페이지·앱 안 업데이트에는 나오지 않습니다. 정식 1.1.1 릴리스 노트는 GitHub에 배포할 때 따로 씁니다.

엔진·위젯 모두 1.1.1로 배포됩니다(같은 버전 정책). 이 위젯은 아래가 바뀌었습니다.

### 바뀐 것

- **메모리 절약**: 엔진 1.1.1에서는 노트 창과 노트 목록 창이 프로세스 하나를 함께 씁니다. 노트가 한 장 늘 때마다 메모리가 약 16 MB에서 약 2 MB로 줄어듭니다. 노트 편집·저장·위치·색·항상 위·접기·Win+D 고정은 그대로입니다.
- **복구**: 노트 창들이 함께 쓰는 프로세스가 비정상 종료되면, 창이 보낸 내용을 저장하고 노트와 목록을 같은 자리에 다시 엽니다(1분에 3번까지). 종료 직전 아직 전달되지 않은 몇 글자는 잃을 수 있습니다.
- **고침**: 이번 실행에서 만든 노트를 창이 열리기도 전에 닫으면, 내용이 있어도 빈 노트로 보고 파일을 지울 수 있던 문제를 고쳤습니다.
- 이전 엔진(1.1.0 이하)에서는 예전처럼 노트마다 프로세스 하나로 동작합니다.

### 설치

- `DeskWidgets-StickyNoteWidget-Setup-1.1.1-test.1.exe` 실행 (관리자 권한). 이전 버전 위에 그대로 설치하면 되고, 설정과 노트 파일(`문서\Desk Widgets\스티키 노트`)은 그대로입니다.
- 제어판: **Desk Widgets-StickyNoteWidget 1.1.1-test.1**
- 설치 순서: **엔진(Desk Widgets) 먼저**, 그다음 위젯. 엔진이 없으면 위젯 설치 파일이 알려 주고 멈춥니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**.

### 요구 사항

- Desk Widgets 엔진 1.0.0 이상 (엔진 API 1.0). 앱 안에서 업데이트하려면 엔진 1.1.0, 노트들이 프로세스 하나를 함께 쓰려면 엔진 1.1.1이 필요합니다.
