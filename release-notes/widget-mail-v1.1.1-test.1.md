## Desk Widgets-MailWidget 1.1.1-test.1 (메일 위젯, 내부 테스트)

> **내부 테스트 빌드**(Gitea 사전 릴리스)입니다. GitHub 릴리스·다운로드 페이지·앱 안 업데이트에는 나오지 않습니다. 정식 1.1.1 릴리스 노트는 GitHub에 배포할 때 따로 씁니다.

엔진·위젯 모두 1.1.1로 배포됩니다(같은 버전 정책). 이 위젯은 아래가 바뀌었습니다.

### 바뀐 것

- **오래 켜 둘 때 메모리 절약**: 목록에서 **더 보기**로 불러온 이전 메일은 30분 동안 더 보기를 누르지 않으면 다음 동기화 때 최근 메일(설정한 보관 개수)만 남기고 정리합니다. 이전 메일은 **더 보기**로 다시 불러옵니다. 그 밖의 기능과 화면은 1.1.0과 같습니다.
- **버전 통일**(엔진 1.1.1 메모리 개선과 함께 배포).

### 설치

- `DeskWidgets-MailWidget-Setup-1.1.1-test.1.exe` 실행 (관리자 권한). 이전 버전 위에 그대로 설치하면 되고, 계정·비밀번호·주소록·분류·테마는 유지됩니다.
- 제어판: **Desk Widgets-MailWidget 1.1.1-test.1**
- 설치 순서: **엔진(Desk Widgets) 먼저**, 그다음 위젯. 엔진이 없으면 위젯 설치 파일이 알려 주고 멈춥니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**.

### 요구 사항

- Desk Widgets 엔진 1.0.1 이상 (엔진 API 1.3). 새 메일 카드의 분류 메뉴는 엔진 1.0.2부터, **할 일에 추가**는 엔진 1.0.4와 할 일 목록 위젯 1.0.0이 필요합니다. 앱 안에서 업데이트하려면 엔진 1.1.0이 필요합니다.
