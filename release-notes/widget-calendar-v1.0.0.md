## Desk Widgets-CalendarWidget 1.0.0 (캘린더 위젯)

바탕화면 **캘린더 위젯**의 첫 정식 버전입니다. 여러 캘린더의 일정을 한 달력에 색으로 구분해 보여 주고, CalDAV 캘린더에는 위젯에서 바로 일정을 만들고 고치고 지울 수 있습니다.

### 주요 기능

- **화면**: 월 달력 + 다가오는 일정(기본), 날짜 칸에 일정이 보이는 **큰 달력**. 테마마다 배경 불투명도와 창 크기를 따로 기억합니다.
- **ICS 구독**: Google·Outlook 비공개 iCal 주소, 공휴일 캘린더 등을 주소만으로 구독(읽기 전용). 반복 일정·시간대 처리.
- **CalDAV 계정**: iCloud · 네이버 · 네이버 웍스 · 두레이 · 기타 CalDAV 서버를 앱 전용 비밀번호로 연결. 비밀번호는 Windows 데이터 보호로 암호화해 저장하고, 계정 서버에만 보냅니다.
- **일정 만들기·수정·삭제**: 쓰기 권한이 있는 CalDAV 캘린더에서. 저장하면 창이 바로 닫히고 뒤에서 서버에 반영하며, 실패하면 알림 카드로 알려 줍니다(다시 시도). 다른 곳에서 먼저 바뀐 일정은 덮어쓰지 않습니다.
- **테마**: 기본·큰 달력 내장, 다른 사람이 만든 캘린더 테마도 넣어 쓸 수 있습니다.

### 설치

1. 먼저 **Desk Widgets 엔진 1.0.1 이상**을 설치합니다(엔진 API 1.3 필요).
2. `DeskWidgets-CalendarWidget-Setup-1.0.0.exe` 실행 (관리자 권한). 설치하면 바로 나타납니다.
- 개발판 0.0.1을 쓰셨다면 그대로 덮어 설치하면 됩니다. 구독·계정·비밀번호·테마·창 위치가 유지됩니다.
- 제어판: **Desk Widgets-CalendarWidget 1.0.0**

### 알려 둘 점

- 반복 일정과 다른 사람이 보낸 회의 초대, ICS 구독 일정은 위젯에서 바꿀 수 없습니다(원래 캘린더 앱에서).
- Google·Microsoft 계정 로그인 연결은 아직 없습니다. 그때까지 ICS 주소로 구독하세요.
- 일정 쓰기는 두레이 캘린더에서 확인했습니다. 다른 서비스는 처음에 테스트용 캘린더로 한 번 해 보세요.
