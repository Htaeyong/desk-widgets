## Desk Widgets 1.1.2 (엔진)

위젯 클릭, 트레이 메뉴, 할 일 노트로 합쳐진 위젯 안내를 고친 버전입니다(엔진 API 1.8 → 1.9).

### 고친 것

- **위젯 하나를 클릭하면 그 위젯만 앞으로 옵니다**("바탕화면에 고정" 방식). 지금까지는 위젯 하나를 누르면 다른 위젯까지 모두 다른 앱 창 위로 올라왔습니다. 이제 다른 위젯은 원래 있던 자리에 그대로 있습니다. Win+D와 항상 위 위젯은 전과 같습니다.

### 새 기능

- **트레이 메뉴에 위젯 항목**: 켜져 있는 위젯이 트레이 아이콘 오른쪽 클릭 메뉴에 자기 항목을 넣을 수 있습니다. 할 일 노트 1.1.1은 **새 할 일 노트**와 **할 일 노트 목록**을 넣습니다(메뉴가 길어지지 않게 트레이의 "할 일 노트 설정"은 뺌, 설정은 목록 창의 오른쪽 클릭이나 위젯 관리 창에서).
- **할 일 노트로 합쳐진 위젯 안내**: 할 일 목록과 스티키 노트는 할 일 노트로 합쳐져 더 이상 새 버전이 나오지 않습니다. 처음 쓸 때 위젯 고르기에서는 **시계·캘린더·할 일 노트**가 미리 체크되고, 두 위젯은 목록 맨 끝에 "할 일 노트로 합쳐진 위젯"으로 보입니다(계속 설치할 수 있음). 위젯 관리 창에도 같은 안내와 할 일 노트 설치 버튼이 보입니다. 이미 쓰고 있는 두 위젯은 그대로 동작합니다.

### 설치

- `DeskWidgets-Setup-1.1.2.exe` 실행 (관리자 권한). 이전 엔진 위에 그대로 설치하면 되고, 설정과 설치한 위젯은 유지됩니다.
- 엔진 1.1.0 이상을 쓰고 있으면 위젯 관리 창의 **업데이트** 칸(또는 알림 카드)에서 바로 업데이트할 수 있습니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**. 앱 안에서 업데이트할 때는 Windows 관리자 권한 확인 창에 "알 수 없는 게시자"로 표시됩니다.

### 호환

- 엔진 API 1.9(1.8에 추가만). 지금 설치한 위젯은 모두 그대로 동작합니다.
