## Desk Widgets 1.0.4 (엔진)

첫 공개 릴리스에 맞춘 엔진입니다(엔진 API 1.6). 1.0.3은 따로 배포하지 않았고 그 내용이 이번 버전에 함께 들어 있습니다.

### 새 기능

- **Windows 측정 서비스**(엔진 API 1.5): CPU·메모리·드라이브·디스크 I/O·네트워크·GPU·배터리·가동 시간을 위젯에 제공합니다. 시스템 모니터 위젯이 씁니다. 창이 가려졌거나 자리를 비운 동안에는 측정을 멈추고, PowerShell·WMI는 실행하지 않습니다.
- **위젯 사이 연동**(엔진 API 1.6): 위젯이 서로 허용한 기능만 부를 수 있습니다. 두레이·메일에서 **할 일에 추가**, 할 일 마감을 캘린더에 표시하는 기능이 이것을 씁니다. 양쪽 위젯 설정에서 모두 켜야 동작합니다(기본 꺼짐).

### 고친 점

- **비밀 값은 암호화해서만 저장**: 토큰·비밀번호 같은 값은 Windows 데이터 보호로 암호화할 수 있을 때만 저장합니다. 예전 버전이 평문으로 남긴 값은 처음 읽을 때 암호화해 다시 저장합니다.

### 설치

- `DeskWidgets-Setup-1.0.4.exe` 실행 (관리자 권한). 이전 엔진 위에 그대로 설치하면 되고, 설정과 설치한 위젯은 유지됩니다.
- 설치 순서: **엔진(Desk Widgets) 먼저**, 그다음 위젯. 엔진이 없으면 위젯 설치 파일이 알려 주고 멈춥니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**.

### 호환

- 엔진 API 1.6. 1.0~1.5를 요구하는 위젯은 모두 그대로 동작합니다.
- 시스템 모니터 위젯은 이 엔진(1.0.4) 이상이 필요합니다.
