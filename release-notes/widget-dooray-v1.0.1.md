## Desk Widgets-DoorayWidget 1.0.1 (두레이 대시보드 위젯)

두레이 위젯만 고친 버전입니다. **엔진(Desk Widgets 1.0.0)은 그대로** 두고 이 설치 파일만 실행하면 됩니다.

### 고친 점

- **조건 알림** 창과 **분류 관리** 창이 스타일 없이 보이던 문제(어두운 바탕에 검은 기본 글자, 기본 모양 버튼)를 고쳤습니다. 두 창이 쓰는 기본 스타일을 위젯 안에 함께 넣어, 설치된 위젯에서도 원래 모양(색, 글꼴, 버튼, 입력 칸, 스크롤바)으로 보입니다.

### 설치

- `DeskWidgets-DoorayWidget-Setup-1.0.1.exe` 실행 (관리자 권한). 1.0.0 위에 그대로 설치하면 되고, 설정·분류·조건 알림은 유지됩니다.
- 실행 중인 Desk Widgets에 바로 반영됩니다(다시 켤 필요 없음).
- 제어판: **Desk Widgets-DoorayWidget 1.0.1**

### 요구 사항

- Desk Widgets 엔진 1.0.0 이상 (엔진 API 1.1)
