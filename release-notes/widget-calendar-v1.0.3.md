## Desk Widgets-CalendarWidget 1.0.3 (캘린더 위젯)

### 고친 것

- **큰 달력 테마가 빈 화면으로 뜨던 문제**: 1.0.2에서 큰 달력 테마를 고르면 월 제목과 날짜 칸이 비어 보였습니다. 이제 정상으로 보이고, 큰 달력에서도 달력에 표시된 할 일 마감을 눌러 목표 날짜를 고칠 수 있습니다.

### 설치

- `DeskWidgets-CalendarWidget-Setup-1.0.3.exe` 실행 (관리자 권한). 이전 버전 위에 그대로 설치하면 되고, 구독·계정·비밀번호·테마는 유지됩니다.
- 제어판: **Desk Widgets-CalendarWidget 1.0.3**
- 설치 순서: **엔진(Desk Widgets) 먼저**, 그다음 위젯. 엔진이 없으면 위젯 설치 파일이 알려 주고 멈춥니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**.

### 요구 사항

- Desk Widgets 엔진 1.0.1 이상 (엔진 API 1.3). 할 일 마감 표시는 엔진 1.0.4와 할 일 목록 위젯 1.0.0이 필요합니다.
