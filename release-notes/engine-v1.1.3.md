## Desk Widgets 1.1.3 (엔진)

AI 도우미 연결과 비밀 노트를 뒷받침하는 기능, 동기화 수정이 들어간 버전입니다(엔진 API 1.9 → 1.10).

### 새 기능

- **AI 도우미 연결 (MCP, 선택, 기본 꺼짐)**: Claude 데스크톱·Claude Code 등 MCP를 지원하는 앱에 Desk Widgets를 직접 추가하면, 그 앱이 위젯 내용을 읽고 할 일을 처리할 수 있습니다. 위젯 관리에서 켜고, 쓰기는 따로 허용합니다. 쓰기마다 알림 카드가 뜨고 10분 안에 되돌릴 수 있으며, 지우는 도구는 없습니다. 네트워크로 열리지 않고 이 PC 안에서만 연결됩니다. 켜면 도구 결과는 사용자의 AI 앱으로 전달되고, 그 처리는 해당 앱의 약관과 설정을 따릅니다.

### 동기화

- **옛 파일 정리**: 어느 PC도 쓰지 않는 옛 노트 파일을 동기화 폴더에서 지웁니다. 잠그기 전의 평문이 남지 않게 하기 위한 것이며, **모든 노트의 옛 버전에 적용됩니다.** 해당 사실을 처음 본 때부터 하루 뒤에 지웁니다.
- **되돌리기 수정**: 충돌에서 "상대 것 받기"를 고른 뒤 되돌리면 실패하던 문제를 고쳤습니다. 다른 PC의 정리가 되돌리기에 필요한 파일을 지우지도 않습니다. 그래서 충돌에서 버린 버전은 잠그기 전 평문이어도 동기화 폴더에 최대 30일 남을 수 있습니다.

### 설치

- `DeskWidgets-Setup-1.1.3.exe` 실행 (관리자 권한). 이전 엔진 위에 그대로 설치하면 되고, 설정과 설치한 위젯은 유지됩니다.
- 엔진 1.1.0 이상을 쓰고 있으면 위젯 관리 창의 **업데이트** 칸(또는 알림 카드)에서 바로 업데이트할 수 있습니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**. 앱 안에서 업데이트할 때는 Windows 관리자 권한 확인 창에 "알 수 없는 게시자"로 표시됩니다.

### 호환

- 엔진 API 1.10(1.9에 추가만). 지금 설치한 위젯은 모두 그대로 동작합니다.
