## Desk Widgets-MailWidget 1.0.0 (메일 위젯)

바탕화면 **메일 위젯**의 첫 정식 버전입니다. 여러 메일 계정의 받은편지함을 한곳에서 보고, 새 메일을 알림으로 받고, 받은 계정 그대로 답장할 수 있습니다.

### 주요 기능

- **계정**: 두레이 · 네이버 · 다음 · Gmail(앱 비밀번호) · 기타 IMAP. 비밀번호는 Windows 데이터 보호로 암호화해 저장하고, 그 계정의 서버에만 보냅니다(암호화 연결만).
- **받은편지함**: 모든 계정을 모은 목록, 계정별 안 읽은 수, 새 메일은 서버 알림(IDLE)으로 바로 받기.
- **새 메일 알림 카드**: 보낸 사람·제목, **열기** / **읽음**, 카드에서 바로 **분류**(엔진 1.0.2 이상).
- **안전한 메일 보기**: 스크립트를 끈 격리 창에서 원문 표시, 외부 이미지는 메일마다 직접 허용할 때만.
- **보내기**: 위젯의 쓰기 창에서 그 계정으로 직접 보내기(새 메일·답장·전체 답장·전달, 원문 인용, 대화 묶음, 받는 사람 칩, 계정별 서명, 첨부 20MB, 보낸편지함 저장). 메일 프로그램이나 웹메일로 넘기는 방식도 고를 수 있습니다.
- **분류**: 이 PC에서만 쓰는 메일 분류(색, 여러 개, 분류별 걸러 보기). 메일 서버에는 반영하지 않습니다.
- **주소록**: 주고받은 메일 주소로 이 PC에 자동으로 만들고, vCard·CSV 가져오기, 받는 사람 자동완성.
- **테마**: 기본 · 작은 카드 · 계정 대시보드(계정별 카드 → 계정 목록 → 메일). 다른 사람이 만든 메일 테마도 넣어 쓸 수 있습니다. 마우스 뒤로·앞으로 버튼, Alt+←/→로 화면 이동.

### 설치

1. 먼저 **Desk Widgets 엔진 1.0.1 이상**을 설치합니다(엔진 API 1.3). 새 메일 카드의 분류 메뉴는 **1.0.2**부터 보입니다.
2. `DeskWidgets-MailWidget-Setup-1.0.0.exe` 실행 (관리자 권한). 설치하면 바로 나타납니다.
- 개발판 0.0.1을 쓰셨다면 그대로 덮어 설치하면 됩니다. 계정·비밀번호·분류·주소록이 유지됩니다.
- 제어판: **Desk Widgets-MailWidget 1.0.0**

### 알려 둘 점

- Outlook.com · Microsoft 365는 아직 연결할 수 없습니다(Microsoft가 비밀번호 로그인을 막아 OAuth가 필요).
- 받은편지함만 봅니다. 첨부 파일 내려받기, 메일 삭제·이동, 서식 있는 메일 쓰기, 서비스 주소록 연결은 아직 없습니다.
- 두레이의 IMAP·SMTP 서버 주소는 기본값이 들어 있으며, 다르면 계정 설정에서 바꿀 수 있습니다.
- 처음 보낼 때는 본인 주소로 한 번 보내 보세요.
