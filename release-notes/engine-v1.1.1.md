## Desk Widgets 1.1.1 (엔진)

**여러 PC 사이 동기화**, **처음 쓸 때 위젯 고르기**, **메모리 절약**, 새 위젯 **할 일 노트**를 위한 위젯 연동이 들어간 버전입니다(엔진 API 1.6 → 1.8).

### 새 기능

- **동기화 폴더**(위젯 관리 창 → **동기화** 탭): OneDrive·Google Drive·Dropbox 등이 동기화하는 **이 PC의 폴더**를 하나 고르면, 엔진이 그 폴더를 통해 다른 PC와 위젯 데이터를 주고받습니다. 클라우드 계정에 직접 접속하지 않습니다.
  - 동기화할 위젯과 항목을 고릅니다. 할 일·내 캘린더 일정·D-day·알람·스티키 노트·할 일 노트와 각 위젯의 설정, 두레이·메일의 분류·규칙·주소록(두레이·메일은 기본 꺼짐)을 주고받을 수 있습니다.
  - 처음 연결할 때 받아올 항목과 올릴 항목을 미리 보여 줍니다. 두 PC에서 같은 항목을 다르게 고쳤을 때만 **이 PC 것 유지 / 다른 PC 것 받기 / 둘 다 남기기**를 묻고, 위젯별·전체 일괄 선택도 됩니다. 비교에서 버린 값은 30일 안에 되살릴 수 있습니다.
  - **비밀번호·토큰은 동기화하지 않습니다**(이 PC에 암호화해 둔 그대로). 창 위치, 알림 상태, 위젯 사이 연동 허용 같은 PC별 설정도 PC마다 따로입니다.
  - 자동 확인 주기(1·2·5·10·30분, 기본 2분), 마지막·다음 확인 시각과 폴더 감시 상태를 보여 줍니다. 네트워크 드라이브처럼 폴더 감시가 안 되는 곳은 주기 확인만으로 계속 동기화합니다. 드라이브 맨 위(`Y:\` 등)를 고르면 그 안에 폴더를 만들어 쓰도록 안내합니다.
  - 노트 폴더를 바꾸거나 노트 폴더를 찾을 수 없을 때(USB를 뺀 경우 등) **다른 PC로 삭제를 보내지 않습니다**.
- **처음 쓸 때 위젯 고르기**: 위젯이 하나도 없는 상태로 엔진을 처음 켜면 위젯 목록이 열립니다(시계·캘린더·스티키 노트가 미리 체크됨). 고른 위젯은 앱 안 업데이트와 같은 방법(GitHub 릴리스, 크기·SHA-256 확인)으로 하나씩 내려받아 설치합니다(위젯마다 관리자 확인 1번). 위젯 관리 창의 **위젯 추가**로 언제든 다시 열 수 있고, 인터넷이 안 되면 **내려받은 설치 파일 열기**로 직접 받은 설치 파일을 고를 수 있습니다.
- **메모리 절약**: 화면에 뜬 알림 카드들, 그리고 스티키 노트·할 일 노트의 노트 창들이 프로세스 하나를 함께 씁니다. 카드·노트가 한 장 늘 때마다 메모리가 약 16~18 MB에서 약 2 MB로 줄어듭니다. 함께 쓰는 프로세스가 비정상 종료되면 카드와 노트가 같은 자리에 다시 열립니다.
- **할 일 노트 연동**(엔진 API 1.7): 두레이·메일의 "할 일에 추가"가 새 위젯 **할 일 노트**로 노트를 만들 수 있고, 캘린더가 노트 마감을 보여 주고 날짜를 바꿀 수 있습니다. 할 일 목록 위젯의 할 일을 할 일 노트로 가져올 때 엔진이 읽기 전용으로 읽어 건넵니다(할 일 목록 데이터는 그대로).

### 고친 것

- 위젯 창을 닫을 때 엔진이 들고 있던 정리 작업이 오래 켜 두면 조금씩 쌓이던 문제.

### 설치

- `DeskWidgets-Setup-1.1.1.exe` 실행 (관리자 권한). 이전 엔진 위에 그대로 설치하면 되고, 설정과 설치한 위젯은 유지됩니다.
- 엔진 1.1.0을 쓰고 있으면 위젯 관리 창의 **업데이트** 칸(또는 알림 카드)에서 바로 업데이트할 수 있습니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**. 앱 안에서 업데이트할 때는 Windows 관리자 권한 확인 창에 "알 수 없는 게시자"로 표시됩니다.

### 호환

- 엔진 API 1.8(1.6에 추가만). 지금 설치한 위젯(1.1.0)은 그대로 동작합니다.
- 이번에 함께 나온 위젯 1.1.1(두레이·메일·캘린더·시계·할 일 목록·스티키 노트)과 할 일 노트 1.1.0은 **엔진 1.1.1이 필요**합니다. 엔진을 먼저 업데이트하세요. 시스템 모니터는 1.1.0 그대로입니다.
- 위젯 개발: 엔진 저장소(항목·파일·비밀 저장소)와 동기화 선언, 공유 창(`ctx.createSharedWidgetWindow`)은 [위젯 만들기](https://github.com/Htaeyong/desk-widgets/blob/main/docs/widget-dev.md)에 있습니다.
