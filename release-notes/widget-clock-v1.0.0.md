## Desk Widgets-ClockWidget 1.0.0 (시계 위젯)

첫 정식 버전입니다.

### 주요 기능

- **테마 5종**: 다크 글래스(기본), 라이트, 미니멀, 네온, 아날로그. 테마마다 배경 불투명도를 따로 정하고, 받은 시계 테마를 테마 폴더에 넣어 쓸 수 있습니다.
- **스톱워치·타이머·알람** (오른쪽 클릭 → 스톱워치·타이머 사용): 어느 테마에서나 아래쪽 탭으로 씁니다. 테마를 바꾸거나 Win+D를 눌러도 계속 돌고, 끝나면 확인할 때까지 남는 알림 카드가 뜹니다.
- **알람**: 최대 20개, 반복 요일, 5분 뒤 다시 알림. 꺼져 있던 동안 지난 알람은 소리 없이 카드 한 장으로 모아 알려 줍니다.
- 초 표시·12시간제, 항상 위에 표시, 창 위치·크기 기억.

### 설치

- `DeskWidgets-ClockWidget-Setup-1.0.0.exe` 실행 (관리자 권한). 예전에 받은 시계(1.0.0 테스트판) 위에 그대로 설치하면 되고, 설정·알람·타이머는 유지됩니다.
- 제어판: **Desk Widgets-ClockWidget 1.0.0**
- 설치 순서: **엔진(Desk Widgets) 먼저**, 그다음 위젯. 엔진이 없으면 위젯 설치 파일이 알려 주고 멈춥니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**.

### 요구 사항

- Desk Widgets 엔진 1.0.1 이상 (엔진 API 1.3)
