# Desk Widgets 1.1.5-test.1 — 내부 테스트 (#134)

- **동기화 탭:** 위젯 체크를 바꾼 뒤 "설정 저장"을 누르기 전에 자동 확인이 돌면 체크가 저장된 값으로 되돌아가던 문제를 고쳤습니다. "지금 동기화"는 바꾼 체크를 먼저 저장합니다.
