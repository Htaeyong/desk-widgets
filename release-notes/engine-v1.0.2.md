## Desk Widgets 1.0.2 (엔진)

알림 카드 메뉴를 모든 위젯이 쓸 수 있게 넓힌 작은 업데이트입니다(엔진 API 1.4).

### 바뀐 점

- **위젯 공용 알림 카드에도 카드 메뉴**: 지금까지 두레이 업무 카드에만 있던 카드 메뉴(분류 넣고 빼기, 새 분류 만들기)를 다른 위젯의 알림 카드에도 붙일 수 있습니다. 메일 위젯 1.0.0의 새 메일 카드에 **분류 ▾**가 이것을 씁니다.
- 두레이 알림 카드는 이전과 똑같이 동작합니다.

### 설치

- `DeskWidgets-Setup-1.0.2.exe` 실행 (관리자 권한). 1.0.1 위에 그대로 설치하면 되고, 설정과 설치한 위젯은 유지됩니다.
- 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다: **추가 정보 → 실행**.

### 호환

- 엔진 API 1.4. 1.0~1.3을 요구하는 위젯(두레이, 시계, 캘린더, 메일)도 그대로 동작합니다.

자세한 내용: [사용자 가이드](https://github.com/Htaeyong/desk-widgets/blob/main/docs/user-guide.md)
