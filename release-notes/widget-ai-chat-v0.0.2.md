# Desk Widgets-AiChatWidget 0.0.2 — 내부 테스트 (#129)

첫 실사용 의견을 반영했습니다.

- **위젯 도구 연결 안내:** 엔진의 "AI 도우미 연결 (MCP)"이 꺼져 있으면 창 위에 이유와 **위젯 관리 열기** 버튼이 나옵니다. 도구가 없을 때 다른 서비스 연결을 권하지 않습니다.
- **입력:** Enter로 보내고 Shift+Enter로 줄을 바꿉니다. 한글 입력 중의 Enter로는 보내지 않습니다.
- **메신저형 대화:** 내 글은 오른쪽, AI 답은 왼쪽 말풍선입니다. 도구 사용, 카드, 비용은 AI 말풍선 안에 묶습니다.
- **금액:** 소수점 2자리까지, 1센트 미만은 "$0.01 미만"으로 표시합니다.
- **사용량 게이지:** 월 예산 대비 퍼센트 게이지입니다. 마우스를 올리거나 누르면 상세가 나옵니다.
- **대화 목록:** 기본 폭을 줄였고, 경계를 끌어 폭을 바꾸거나 접을 수 있습니다. 두 번 누르면 기본 폭으로 돌아갑니다.
- 엔진은 1.1.4-test.1 그대로 쓰면 됩니다.
