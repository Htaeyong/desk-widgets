## Desk Widgets-ClockWidget 1.1.1 (시계 위젯)

엔진 1.1.1의 **동기화**를 지원하는 버전입니다.

### 바뀐 것

- **동기화**(선택): 알람, 표시 설정(초·12시간제·테마), 타이머 시간과 프리셋을 다른 PC와 주고받습니다. 동기화는 엔진 1.1.1의 **동기화 폴더**(위젯 관리 창 → 동기화 탭)를 켜고 이 위젯을 고를 때만 동작합니다. 실행 중인 타이머·스톱워치, 알람의 다시 알림 상태, 창 위치는 PC마다 따로입니다.
- 그 밖의 기능과 화면은 1.1.0과 같습니다.

### 설치

- `DeskWidgets-ClockWidget-Setup-1.1.1.exe` 실행 (관리자 권한). 이전 버전 위에 그대로 설치하면 되고, 설정·타이머·알람·테마는 유지됩니다.
- 제어판: **Desk Widgets-ClockWidget 1.1.1**
- 설치 순서: **엔진(Desk Widgets) 1.1.1 먼저**, 그다음 위젯. 엔진 1.1.0을 쓰고 있으면 위젯 관리 창의 **업데이트** 칸에서 엔진을 먼저 업데이트하세요(엔진이 오래되면 위젯 업데이트에 "엔진을 먼저 업데이트"가 표시됩니다).
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**.

### 요구 사항

- **Desk Widgets 엔진 1.1.1 이상** (엔진 API 1.8).
