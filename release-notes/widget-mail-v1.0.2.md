## Desk Widgets-MailWidget 1.0.2 (메일 위젯)

### 새 기능

- **할 일에 추가** (선택, 기본 꺼짐): 메일 보기에서 **할 일에 추가**를 누르면 메일 제목이 할 일 목록 위젯에 들어갑니다(출처로 계정 이름 표시). **메일 → 할 일 연동**과 **할 일 → 메일에서 받기**를 모두 켜야 하고, 같은 메일을 다시 추가하면 기존 할 일을 씁니다. 메일 본문은 복사하지 않습니다.

### 설치

- `DeskWidgets-MailWidget-Setup-1.0.2.exe` 실행 (관리자 권한). 이전 버전 위에 그대로 설치하면 되고, 계정·비밀번호·분류·주소록은 유지됩니다.
- 제어판: **Desk Widgets-MailWidget 1.0.2**
- 설치 순서: **엔진(Desk Widgets) 먼저**, 그다음 위젯. 엔진이 없으면 위젯 설치 파일이 알려 주고 멈춥니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**.

### 요구 사항

- Desk Widgets 엔진 1.0.1 이상 (엔진 API 1.3). 새 메일 카드의 분류 메뉴는 엔진 1.0.2부터, **할 일에 추가**는 엔진 1.0.4와 할 일 목록 위젯 1.0.0이 필요합니다.
