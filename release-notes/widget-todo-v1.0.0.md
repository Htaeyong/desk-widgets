## Desk Widgets-TodoWidget 1.0.0 (할 일 목록 위젯)

첫 정식 버전입니다.

### 주요 기능

- **빠른 입력**: 한 줄로 적고 Enter. 끝에 `내일 3시`, `다음 주 월요일`, `매주 금요일 15:30`처럼 한국어 날짜·시각·매주 반복을 붙일 수 있습니다.
- **여러 목록**, 완료 항목 접기, 끌어서 순서 바꾸기, 마감 강조.
- **알림 카드**: 시각이 정해진 할 일은 때가 되면 카드가 뜨고, 카드에서 **완료**하거나 **다시 알림**을 고릅니다.
- **연동** (선택, 기본 꺼짐): 두레이 업무·메일을 할 일로 받고, 목표 날짜를 캘린더에 표시합니다. 양쪽 위젯 설정에서 모두 켜야 동작합니다.
- 할 일은 이 PC의 위젯 데이터 폴더에만 저장됩니다. 한국어·영어 화면.

### 설치

- `DeskWidgets-TodoWidget-Setup-1.0.0.exe` 실행 (관리자 권한). 개발판(0.0.1) 위에 그대로 설치하면 되고, 할 일과 설정은 유지됩니다.
- 제어판: **Desk Widgets-TodoWidget 1.0.0**
- 설치 순서: **엔진(Desk Widgets) 먼저**, 그다음 위젯. 엔진이 없으면 위젯 설치 파일이 알려 주고 멈춥니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**.

### 요구 사항

- Desk Widgets 엔진 1.0.1 이상 (엔진 API 1.3). 두레이·메일·캘린더 연동은 엔진 1.0.4가 필요합니다.
