## Desk Widgets 1.0.1 (엔진)

알림 카드와 테마 기능을 넓힌 엔진 업데이트입니다. **캘린더 위젯 1.0.0을 쓰려면 이 버전이 필요합니다**(엔진 API 1.3).

### 바뀐 점

- **알림 카드 쌓기**: 새 알림은 항상 바로 맨 위에 뜹니다. 최대 개수를 넘으면 가장 오래된 카드가 잠시 빠져 대기했다가, 자리가 나면 최근에 빠진 것부터 다시 나타납니다. 대기 중인 카드는 버리지 않고, 메모리도 쓰지 않습니다.
- **위젯 공용 알림 카드**: 두레이뿐 아니라 모든 위젯이 알림 카드를 띄울 수 있습니다(제목·본문·아이콘·버튼, 확인할 때까지 유지, 짧은 알림음). 시계 타이머·알람과 캘린더 저장 실패 알림이 사용합니다.
- **테마 배경 불투명도**: 테마마다 배경이 얼마나 비칠지 정할 수 있습니다(위젯 설정 창의 테마 아래 슬라이더, 글자는 그대로 선명).
- **위젯별 테마**: 시계·캘린더도 두레이처럼 테마 패키지를 쓰고, 다른 사람이 만든 테마를 넣어 쓸 수 있습니다. 위젯 설정 창에 공용 **테마** 칸(목록·미리보기·불투명도·테마 폴더 열기)이 생겼습니다.
- 두레이 테마와 이미 만든 두레이 테마는 바꿀 것 없이 그대로 동작합니다.

### 설치

- `DeskWidgets-Setup-1.0.1.exe` 실행 (관리자 권한). 1.0.0 위에 그대로 설치하면 되고, 설정과 설치한 위젯은 유지됩니다.
- 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다: **추가 정보 → 실행**.

### 호환

- 엔진 API 1.3. 1.0~1.2를 요구하는 위젯(두레이 1.0.x 등)도 그대로 동작합니다.
