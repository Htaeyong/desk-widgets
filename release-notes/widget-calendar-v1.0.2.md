## Desk Widgets-CalendarWidget 1.0.2 (캘린더 위젯)

### 새 기능

- **내 캘린더**: 서버 없이 이 PC에만 저장되는 캘린더입니다. 일정을 만들고 고치고 지울 수 있고, CalDAV·ICS 캘린더와 함께 표시됩니다.
- **할 일 마감 표시** (선택, 기본 꺼짐): 목표 날짜가 있는 할 일이 달력에 보입니다. **할 일 → 캘린더에 마감 표시**와 **캘린더 → 할 일 연동**을 모두 켭니다. 달력에서 마감을 눌러 목표 날짜·시각을 고치면 할 일에 저장되고, 날짜를 바꾸거나 지우면 이전 표시는 사라집니다. 완료한 할 일은 설정에서 **숨김** 또는 **완료 표시**로 고릅니다. 할 일은 CalDAV·ICS 서버로 보내지 않습니다.

### 설치

- `DeskWidgets-CalendarWidget-Setup-1.0.2.exe` 실행 (관리자 권한). 이전 버전 위에 그대로 설치하면 되고, 구독·계정·비밀번호·테마는 유지됩니다.
- 제어판: **Desk Widgets-CalendarWidget 1.0.2**
- 설치 순서: **엔진(Desk Widgets) 먼저**, 그다음 위젯. 엔진이 없으면 위젯 설치 파일이 알려 주고 멈춥니다.
- 코드 서명이 아직 없어 SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다: **추가 정보 → 실행**.

### 요구 사항

- Desk Widgets 엔진 1.0.1 이상 (엔진 API 1.3). 할 일 마감 표시는 엔진 1.0.4와 할 일 목록 위젯 1.0.0이 필요합니다.
