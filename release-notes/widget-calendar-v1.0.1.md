## Desk Widgets-CalendarWidget 1.0.1 (캘린더 위젯)

### 고친 점

- **⟳ 새로고침 버튼**: 위쪽 **오늘** 옆에 새로고침 버튼이 생겼습니다(기본·큰 달력). 누르면 아이콘이 제자리에서 돌다가, 켜 둔 모든 캘린더를 서버에 다시 확인한 뒤 멈추고 `마지막 갱신` 시각이 바뀝니다. 오류가 나면 잠깐 알려 주고, 자세한 이유는 설정 창에 있습니다.

### 설치

- `DeskWidgets-CalendarWidget-Setup-1.0.1.exe` 실행 (관리자 권한). 1.0.0 위에 그대로 설치하면 되고, 구독·계정·비밀번호·테마는 유지됩니다.
- 제어판: **Desk Widgets-CalendarWidget 1.0.1**

### 요구 사항

- Desk Widgets 엔진 1.0.1 이상 (엔진 API 1.3)
