## Desk Widgets-StickyNoteWidget 1.1.2-test.1 (스티키 노트 위젯, 내부 테스트)

> Gitea 사전 릴리스입니다. GitHub·다운로드 페이지·앱 안 업데이트에는 표시되지 않습니다.

- 엔진 동기화 폴더에서 노트, 보관함과 첨부 파일을 공유할 수 있습니다. 노트별 색과 기본 표시 설정도 동기화합니다.
- 노트 폴더가 이미 클라우드 동기화 폴더 안에 있으면 노트 파일을 이중 동기화하지 않습니다. 창 위치와 노트 폴더 경로는 PC마다 따로 유지합니다.
- 파일 하나의 동기화 한도는 20MB입니다. 엔진 API 1.8을 지원하는 테스트 엔진이 필요합니다.

설치 파일: `DeskWidgets-StickyNoteWidget-Setup-1.1.2-test.1.exe`.
