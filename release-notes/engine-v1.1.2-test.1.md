# Desk Widgets 1.1.2-test.1 — 내부 테스트 (#108)

작성자: Codex

- 엔진 API 1.8에 폴더 동기화 선언을 추가했습니다. 위젯 관리 창에서 동기화 폴더와 위젯별 데이터 범위를 선택합니다.
- 처음 연결할 때 받아오기·올리기·충돌 항목을 비교하고, 충돌에서는 이 PC 값·다른 PC 값·둘 다 남기기를 선택할 수 있습니다.
- 비밀번호와 토큰, PC별 창 상태와 외부 연동 켜기 상태는 동기화하지 않습니다. 두레이·메일 업무 데이터는 기본 꺼짐입니다.
- 삭제 표시 180일, 오래 연결하지 않은 PC의 재검토, 선택한 값 30일 되살리기, 노트 본문·첨부의 해시 검증과 안전한 파일 쓰기를 포함합니다.

내부 테스트 버전입니다. 서로 다른 두 PC의 실제 클라우드 동기화 프로그램에서 장시간 동작은 아직 확인하지 않았습니다.
