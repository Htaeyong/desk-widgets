# Desk Widgets-AiChatWidget 0.0.5-test.2 — 내부 테스트 (#129, #131)

- **기억:** AI가 규칙을 기억하려 하면 카드로 묻고, 승인한 것만 저장합니다. 저장한 기억은 모든 새 대화에 전달되고, 기억 목록에서 고치거나 지울 수 있습니다.
- **작업 중 중지와 정정:** 작업 중에도 입력할 수 있고, "정정으로 보내기"(지금 단계를 멈추고 고친 내용으로 이어 가기)와 "끝난 뒤 보내기"를 고릅니다.
- **두레이 원본 받기:** 두레이 위젯(1.1.4-test.2)의 알림 카드에서 받기를 누르면 파일이 "두레이에서 받음" 첨부로 올라가고 AI가 이어서 처리합니다. 거절하면 "받지 않음"으로 남습니다.
- 0.0.5-test.1의 내용이 함께 들어 있습니다.
