# 스티키 노트 위젯

바탕화면 스티키 노트입니다(#75, #95, 첫 정식 버전 1.0.0은 #100). 노트마다 작은 창이 하나씩 뜨고, 서식이 보이는 상태로 바로 고치며(WYSIWYG), 내용은 **문서 폴더의 Markdown(.md) 파일**로 저장됩니다.

## 1. 노트는 어디에 저장되나요

- 기본 폴더: `문서\Desk Widgets\스티키 노트` (설정 → 노트 폴더에서 바꿀 수 있음)
- 노트 하나 = `제목.md` 파일 하나. 이미지·첨부 파일은 옆의 `제목.assets` 폴더에 들어가고, md 안에서는 `제목.assets/그림.png` 같은 상대 경로로 이미지를 참조합니다(이미지 문법 `![설명](경로)`).
- 보관함으로 옮긴 노트는 같은 폴더의 `보관함` 하위 폴더로 갑니다(이미지 폴더도 함께).
- 파일 맨 위에 `desk-widgets-memo: <id>` 한 줄짜리 머리말(front matter)이 붙습니다. 다른 프로그램에서 파일 이름을 바꿔도 같은 노트로 알아보기 위한 값이고, Obsidian 속성 같은 다른 머리말 줄은 그대로 둡니다.
- 창 위치·크기·색·열림 여부·항상 위 같은 **화면 설정만** 위젯 설정 폴더(`%APPDATA%\chilgong88\desk-widgets\widgets\memo\settings.json`)에 있습니다.

**제거해도 노트는 남습니다.** 위젯 제거 프로그램은 설치 폴더(`C:\Program Files\chilgong88\widgets\memo`)와, 고르면 위젯 설정 폴더만 지우고, Desk Widgets 제거 프로그램은 `%APPDATA%\chilgong88\desk-widgets`만 지웁니다. 문서 폴더는 어느 쪽도 건드리지 않습니다. 그래서 설정에서 노트 폴더를 프로그램·설정 폴더 **안**으로 고르는 것은 막혀 있습니다.

### 이름이 "메모"에서 "스티키 노트"로 바뀌었습니다 (#95)

메모장과 헷갈리지 않도록 위젯 이름을 바꿨습니다(포스트잇은 3M 상표라 쓰지 않음). 처음 개발판(0.0.1, `MemoWidget`)을 쓰던 경우:

- **설치**: `DeskWidgets-StickyNoteWidget-Setup-0.0.1.exe`를 그냥 설치하면 됩니다. 제어판 항목은 위젯 id(memo)로 만들어지므로 예전 **Desk Widgets-MemoWidget** 항목이 **Desk Widgets-StickyNoteWidget**으로 바뀌고 따로 남지 않습니다. 설정·창 위치·색·열려 있던 노트는 그대로입니다.
- **노트 폴더**: 기본 폴더를 쓰던 경우에만, 업데이트 뒤 처음 켤 때 `문서\Desk Widgets\메모`를 `문서\Desk Widgets\스티키 노트`로 한 번 옮깁니다. 결과는 노트 목록 창 위쪽에 한 번 안내됩니다.
  - 보통은 폴더 이름만 바뀝니다(파일 복사 없음).
  - 예전 폴더의 파일이 사용 중이라(OneDrive 동기화, 다른 프로그램) 이름을 바꿀 수 없으면, 새 폴더로 복사해 모든 파일이 똑같은지 확인한 뒤 새 폴더를 씁니다. 예전 폴더는 지우지 않고 남기니, 새 폴더를 확인한 뒤 직접 지우면 됩니다.
  - 복사도 안 되면 예전 폴더를 계속 씁니다(설정의 노트 폴더에 예전 경로가 들어감).
  - 두 폴더 모두 파일이 있으면 **합치지 않고** 예전 폴더를 계속 씁니다. 설정에서 쓸 폴더를 고르세요.
  - 설정에서 다른 폴더를 직접 고른 경우는 아무것도 옮기지 않습니다.

## 2. 쓰기

| 하는 일 | 방법 |
|---|---|
| 새 노트 | 노트 창의 **+**, 목록의 **+**, 오른쪽 클릭 → 새 노트 |
| 서식 | 창 위 **Aa**로 서식 도구 보이기. 단축키 Ctrl+B 굵게, Ctrl+I 기울임, Ctrl+Shift+X 취소선, Ctrl+E 코드, Ctrl+K 링크 |
| 줄 앞 입력 | `# ` 제목, `- ` 글머리 목록, `1. ` 번호 목록, `[] ` 체크 목록, `> ` 인용. ```` ``` ```` + Enter 코드 블록, `---` + Enter 가로줄 |
| 체크 목록 | 체크 칸을 누르면 완료/미완료 (파일에는 `- [x]` / `- [ ]`) |
| 목록 들여쓰기 | Tab / Shift+Tab |
| 줄 바꿈 | Enter는 새 문단, Shift+Enter는 같은 문단 안에서 줄 바꿈 |
| 이미지 | 붙여넣기(Ctrl+V)나 끌어다 놓기 → `제목.assets`에 파일로 저장 (PNG·JPEG·GIF·WebP, 20MB까지) |
| 첨부 파일 | 끌어다 놓기나 서식 도구의 📎 → `제목.assets`에 복사하고 링크 (200MB까지). **Ctrl+클릭**으로 기본 프로그램에서 열기, 실행 파일(.exe·.bat·.lnk 등)은 한 번 더 묻습니다 |
| 링크 | Ctrl+클릭하면 http·https·mailto 주소만 브라우저·메일 프로그램으로 열림. 같은 폴더의 다른 노트로 가는 링크는 그 노트를 엶 |
| 붙여넣기 | 글자는 서식 없이 붙여넣어집니다(다른 곳의 서식·스크립트가 들어오지 않게) |
| 이름 | 처음 쓴 줄이 노트 이름(파일 이름)이 됩니다(창에서 나가거나 닫을 때). 오른쪽 클릭 → 이름 바꾸기로 직접 정하면 그 뒤로는 자동으로 바뀌지 않습니다 |

저장은 자동입니다. 쓰는 동안 잠깐 멈추면(약 0.6초, 계속 쓰더라도 3초 안에) 저장되고, 위젯을 끄거나 Desk Widgets를 종료할 때도 남은 내용을 저장합니다. 파일은 임시 파일에 쓴 뒤 바꿔 넣으므로 저장 중에 꺼져도 반쯤 쓰인 파일이 남지 않습니다.

### 노트끼리 연결 (`[[ ]]`)

- `[[`를 입력하면 노트 이름 목록이 뜹니다. 글자를 더 치면 좁혀지고, ↑↓로 고른 뒤 Enter나 Tab으로 넣습니다(Esc 닫기). 목록에 없는 이름이면 맨 아래 **새 노트 만들기: 이름**으로 링크만 넣어 둘 수 있습니다.
- `[[이름]]`처럼 닫는 괄호까지 직접 쳐도 링크가 됩니다. `[[이름|보이는 글자]]`(다른 글자로 보이기), `[[이름#소제목]]`도 됩니다. 링크의 글자를 고치면 파일에는 `[[이름|고친 글자]]`로 저장됩니다.
- **Ctrl+클릭**하면 그 노트 창이 열립니다. 아직 없는 노트(점선으로 흐리게 보임)는 그 이름으로 새로 만들어 엽니다. 보관함에 있는 노트는 열지 않고 꺼내라고 안내합니다.
- 노트는 **이름(파일 이름)으로** 찾습니다(대소문자 구분 없음, Obsidian과 같음). 파일에는 `[[이름]]` 그대로 저장되므로 Obsidian에서도 링크로 동작합니다. `[글자](이름.md)` 형식의 링크도 같은 노트 링크로 셉니다.
- 노트 **이름을 바꾸면**(직접 바꾸든 첫 줄로 자동으로 바뀌든) 다른 노트 안의 `[[옛 이름]]`·`[[옛 이름|글자]]`·`[[옛 이름#소제목]]`·`[글자](옛 이름.md)`도 새 이름으로 고쳐집니다(보관함 노트 포함, 코드 안은 그대로). 고친 노트 수가 창 아래에 잠깐 표시됩니다.
- **노트 목록**에는 노트마다 그 노트를 가리키는 노트(백링크)가 `← 할 일, 일기`처럼 표시되고, 이름을 누르면 그 노트가 열립니다.

## 3. 창과 메뉴

- 위쪽 띠를 끌어 옮기고, 가장자리를 끌어 크기를 바꿉니다. **▾** 접기(띠만 남음), **×** 창 닫기(노트는 목록에 남음). 아무것도 쓰지 않은 새 노트를 닫으면 빈 파일은 지워집니다.
- 오른쪽 클릭: 잘라내기·복사·붙여넣기(글 위에서), 새 노트, 노트 목록, **항상 위에 표시**, **색**(노랑·분홍·파랑·초록·보라·회색·어두운 색), 접기, 이름 바꾸기, 탐색기에서 보기, 보관함으로 옮기기, 휴지통으로 옮기기(확인 후, 휴지통에서 되살릴 수 있음), 노트 닫기, 그리고 다른 위젯과 같은 설정·위젯 관리·끄기·종료.
- Win+D를 눌러도 다른 위젯처럼 바탕화면에 남습니다(엔진의 바탕화면 고정 설정을 따름).
- 위젯을 다시 켜면 열려 있던 노트 창이 같은 자리·크기·색으로 돌아옵니다.

## 4. 노트 목록

목록 창(오른쪽 클릭 → 노트 목록, 또는 위젯 관리에서 위젯 이름을 누름): 검색(제목·내용), 새 노트, 누르면 열기, 📌 목록 맨 위 고정, ⊟ 창 닫기, 🗄 보관함으로, 🗑 휴지통으로. **보관함** 탭에서 ↩로 꺼냅니다. 📁은 노트 폴더를 탐색기로 엽니다. ● 표시는 지금 창이 열려 있는 노트입니다.

## 5. 다른 프로그램과 함께 쓰기

- 노트 폴더를 감시합니다. VS Code·Obsidian·메모장에서 고친 내용은 열린 노트 창에 바로 보입니다.
- 노트 창에 **아직 저장하지 않은 내용**이 있을 때 파일이 바깥에서 바뀌면 덮어쓰지 않고 고르게 합니다: **바뀐 내용 보기**(바깥 것을 보이고 내 것은 버림) / **내 내용으로 저장**(내 것으로 덮어씀) / **내 내용은 사본으로**(`제목 (내 사본).md`로 따로 저장하고 바깥 것을 보임). 고르기 전에 위젯을 끄면 내 내용은 사본 파일로 저장됩니다.
- 열린 노트의 파일이 지워지거나 옮겨지면 "노트 파일이 없어졌습니다"가 뜨고, 다시 저장하거나 창을 닫을 수 있습니다. 다른 프로그램에서 이름만 바꾼 경우는 머리말의 id로 따라갑니다.
- **OneDrive 충돌 사본**(`제목-PC이름.md`처럼 같은 id가 든 파일이 하나 더 생김): 원래 파일이 그 노트로 남고, 다른 쪽은 목록에 **충돌 사본**으로 표시됩니다. 열어서 비교한 뒤 필요 없는 쪽을 휴지통으로 옮기세요. 사본을 고쳐 저장하면 그 사본은 새 id를 받아 별도 노트가 됩니다.

## 6. 예전 .txt 노트

노트 폴더의 `.txt` 파일도 목록에 나오고 열립니다. 이때는 **글자만 고치는 모드**(서식·이미지 없음)이고 저장도 .txt 그대로입니다. 오른쪽 클릭 → **Markdown 노트로 바꾸기**를 누르면 같은 이름의 `.md`를 만들고(모든 줄을 글자 그대로 옮김), 원래 `.txt`는 지우지 않고 `보관함` 폴더로 옮깁니다. 다른 곳의 .txt를 가져오려면 노트 폴더에 복사해 넣으면 됩니다.

## 7. 설정

- **노트 폴더**: 폴더 고르기·기본 폴더로·폴더 열기. 다른 폴더로 바꾸면 그 폴더의 노트를 보여 주고, 원래 폴더의 노트는 옮기지 않습니다.
- **새 노트 색**, **글자 크기**(10~24), **배경 불투명도**(배경에만 적용, 글자는 그대로 — 다른 위젯과 같은 방식).

## 8. 안전

- 노트 창은 위젯이 만든 정리된 HTML만 보여 줍니다(허용 목록 방식: 스크립트·iframe·이벤트 속성·style 없음). 파일 안의 HTML 태그는 실행되지 않고 **글자 그대로** 보이며 그대로 저장됩니다.
- 이미지는 **그 노트의 폴더 안 파일만** 위젯이 읽어서 보여 줍니다(8MB까지, 더 크면 자리 표시만). 인터넷 주소의 이미지는 불러오지 않습니다(창의 보안 정책이 외부 요청을 막음).
- 링크는 http·https·mailto만 브라우저로 열고, 첨부 파일은 그 노트의 `.assets` 폴더 안의 것만 엽니다.

## 9. 알려진 제한 (0.0.1)

- 지원하는 Markdown: 제목, 굵게·기울임·취소선, 인라인 코드, 코드 블록, 글머리·번호·체크 목록(중첩), 인용, 링크, 노트 링크 `[[ ]]`, 가로줄, 표(기본), 이미지. 그 밖의 것(각주, 수식, 참조식 링크 `[a][1]`, HTML 태그, 밑줄)은 글자로 보입니다.
- 위젯에서 한 번 고치면 파일 표기가 정리됩니다: `*`/`_` → `**굵게**`·`*기울임*`, `* 목록` → `- 목록`, 번호 다시 매김, 밑줄 제목(`===`) → `#`, 줄 앞 공백 제거, 연속 빈 줄 하나로(빈 줄 하나를 남기려고 쓴 빈 문단은 `&nbsp;`로 저장). 고치지 않은 노트 파일은 열기만 해서는 바뀌지 않습니다.
- 한 줄 바꿈(Enter 없이 이어진 줄)은 Obsidian처럼 줄 바꿈으로 보입니다(다른 Markdown 보기 프로그램은 한 문단으로 합칠 수 있음).
- 표 칸 안의 줄 바꿈은 저장 시 띄어쓰기가 됩니다. 표에 줄·칸을 더하는 버튼은 아직 없습니다(처음 2×2, 칸 안에서 Tab 이동 없음).
- 붙여넣기는 글자만(다른 문서의 서식은 들어오지 않음). 노트 사이 복사도 서식 없이 됩니다.
- 이미지 크기 조절은 없습니다(창 너비에 맞춰 보임). 바깥 변경을 불러오면 실행 취소(Ctrl+Z) 기록이 지워집니다.
- 위젯이 이름을 붙이지 않은(머리말 id가 없는) `.md`·`.txt`는 다른 프로그램에서 이름을 바꾸면 새 노트로 보여 창 위치·색을 잃습니다(위젯에서 한 번 고치면 id가 생김).
- 같은 폴더의 하위 폴더(`보관함` 말고)에 있는 노트는 목록에 나오지 않습니다.
- 강제 종료(작업 관리자 등)나 정전 때는 마지막 0.2~3초 동안 쓴 내용이 저장되지 않을 수 있습니다.
- 5MB가 넘는 노트 파일은 목록에만 나오고 열리지 않습니다.
- `[[ ]]` 링크: 이름이 같은 노트가 여럿이면(다른 폴더는 보지 않으므로 보통 보관함과 겹칠 때) 보관함 밖의 것을 엽니다. `![[그림]]`(Obsidian 끼워 넣기)은 그림이 아니라 링크로 보입니다. 이름 바꾸기로 고칠 때, 그 순간 막 친 글자를 아직 보내지 않은 열린 노트(0.2초 이내)는 건너뜁니다. 새 노트를 만들거나 이름을 바꾸면 이미 열린 다른 노트 창의 "없는 노트" 점선 표시는 그 창을 다시 열 때 바뀝니다. 다른 프로그램에서 이름을 바꾼 경우에는 링크를 고치지 않습니다.

## 10. 사용한 라이브러리

없습니다. Markdown 해석·변환(`lib/markdown.js`)과 HTML 정리기(`lib/html.js`)는 이 위젯을 위해 직접 작성했습니다(위젯 패키지에는 node_modules가 없음, #40). 외부 라이선스 고지 대상이 없습니다.

## 11. 구조 (개발자용)

| 파일 | 역할 |
|---|---|
| `index.js` | 창·메뉴·설정·IPC(`memo-widget` 채널 하나, 보낸 창으로 노트를 구분) |
| `lib/library.js` | 노트 폴더: 목록·id·이름 바꾸기·보관함·휴지통·.txt 바꾸기·assets 복사와 경로 검사 |
| `lib/session.js` | 열린 노트 하나: 저장 지연·원자적 쓰기·바깥 변경/충돌·종료 시 저장 |
| `lib/markdown.js` | Markdown ↔ 편집기 HTML(트리) |
| `lib/html.js` | HTML 해석기와 허용 목록 정리기 |
| `lib/files.js` | 파일 이름 규칙·원자적 쓰기 |
| `memo/`, `list/`, `preload.js` | 노트 창·목록 창 화면(위젯 자체 페이지) |

**창 방식 결정**: 엔진 테마 호스트(`ctx.useThemes`)는 프레임별 여러 창(`openFrame(frame, instanceId)`)을 열 수 있지만, 노트 창에는 맞지 않아 **위젯 자체 창**(`ctx.createWidgetWindow`)을 씁니다. 이유: 테마 호출 인자가 64KB로 제한되어 붙여넣은 이미지를 보낼 수 없음, 격리된 테마 페이지에서는 끌어다 놓은 파일의 경로를 얻을 수 없음, 주 창(목록)을 닫으면 위젯이 꺼짐, 위젯 쪽에서 다른 프레임 창을 닫거나 항상 위를 바꾸는 API가 없음. 그래서 받은 테마는 없고(테마 규격 없음), 색 7가지와 배경 불투명도는 위젯 설정으로 둡니다.

**이미지 보여 주기**: 노트 창은 `img-src data:`만 허용합니다. 위젯 메인 코드가 그 노트 폴더 안의 이미지 파일을 읽어 data URL(8MB까지, 메모리 캐시 48MB)로 HTML에 넣고, 페이지는 저장할 때 `data-asset`(파일 이름)만 돌려보내므로 data URL이 파일에 들어가지 않습니다. 엔진 변경 없이 되고, 외부 주소·다른 폴더 파일을 불러올 수 없습니다.
