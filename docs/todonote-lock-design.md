# 할 일 노트 비밀 노트(노트별 암호 잠금) 설계 (#124)

사용자 결정(2026-11-06)대로 구현한 내용입니다. 쓰는 법은 [할 일 노트](todonote.md), 합의 기록은 정책과 합의사항에 있습니다.

## 1. 암호만으로 동작

키 파일, 계정, 서버, 추가 앱이 필요 없습니다.

- 암호에서 scrypt(N=2^17, r=8, p=1)로 키를 만들어 무작위 **데이터 키**를 감싸고, 데이터 키로 본문과 첨부를 AES-256-GCM으로 암호화합니다.
- 파일에는 salt, nonce, 설정값, 감싼 키, 암호문만 있고 **암호와 키는 어디에도 저장하지 않습니다.**
- **암호를 잊으면 아무도 열 수 없습니다.** 복구 수단은 없습니다.
- 엔진 런타임(Electron 44, Node 24)에서 실제로 돌려 확인했습니다. 키 계산은 개발 PC에서 약 0.5초, 메모리는 128MB를 잠깐 씁니다.
- 데이터 키를 따로 두므로 잘못된 암호(감싼 키가 안 풀림)와 파일 손상(내용이 안 풀림)을 구별하고, 암호를 바꿔도 첨부를 다시 암호화하지 않습니다.

## 2. 파일 형식

**머리말은 평문, 본문과 첨부는 암호문입니다**(사용자 결정: 제목과 마감은 평문). 엔진 동기화가 `.md`·`.txt`만 노트로 읽으므로 확장자는 `.md`를 유지합니다. 그래서 위젯 쪽은 엔진 변경 없이 동기화되고, 엔진의 "둘 다 유지"가 `desk-widgets-memo:` 줄을 고쳐도 그대로 열립니다.

````
---
created: 2026-11-06T01:02:03.000Z
title: 은행 정보
due: 2026-12-01
desk-widgets-memo: 3f9a1c20b7de
---
> 🔒 Desk Widgets 할 일 노트에서 암호로 잠근 노트입니다. 이 파일을 고치면 열 수 없게 됩니다.

```desk-widgets-locked
{"v":1,"kdf":"scrypt","N":131072,"r":8,"p":1,"salt":"…","wrapNonce":"…","wrap":"…","nonce":"…"}
<base64 암호문, 76자마다 줄바꿈>
```
````

- 머리말을 평문으로 두므로 **제목, 만든 시각, 마감·반복·알림·완료, 출처, Obsidian 속성 등 머리말 전체가 파일에서 보입니다.** 이 밖에 폴더(노트·보관함·완료), 대략의 크기, 저장 시각, 첨부 개수와 대략의 크기, 노트 색도 숨기지 않습니다.
- 암호문 안에는 압축한 본문과 첨부 폴더 이름이 있습니다. 파일 이름이 바뀌어도(이름 충돌, 동기화 사본) 열 때 첨부 링크를 고칩니다.
- 암호화한 결과가 5MB를 넘으면 저장을 거절하고 글은 창에 유지합니다(열 수 없는 파일이 되지 않도록).
- `.txt` 노트, 보관함·완료 폴더의 노트, 충돌 사본은 잠글 수 없습니다.

## 3. 다시 잠기는 시점

파일은 항상 암호문입니다. 내용은 메모리에서만 풀어 창에 보여 줍니다. **노트 창을 닫을 때까지 유지합니다**(사용자 결정). 위젯이 꺼지거나 렌더러가 죽어 창이 닫혀도 같습니다. PC 잠금, 절전, 일정 시간 입력 없음으로는 잠기지 않습니다.

- 창이 닫히면 데이터 키를 0으로 지웁니다. 다시 열면 암호를 묻습니다.
- 입력한 암호는 키 계산 뒤 쓰지 않고, 암호 칸은 시도할 때마다 비웁니다. JS 문자열까지 지운다고 보장할 수는 없습니다.
- 창이 열려 있는 동안에는 메모리(절전 파일 포함)에 평문이 있고, 클립보드에 복사한 내용은 그대로 남습니다.

## 4. 어디에서 평문이 새는지 확인한 결과

| 항목 | 동작 |
|---|---|
| 첨부(`.assets`) | 파일마다 암호화하고 **이름도 숨깁니다**(`<해시 40자>.dwenc`, 진짜 이름은 암호문 안). 이미지는 메모리에서 풀어 창에 보이고 캐시하지 않습니다. 다른 파일은 임시 평문 파일을 만들지 않고 **다른 이름으로 저장**으로만 꺼냅니다. 끌어다 놓은 원본 파일은 사용자의 것이라 그대로 둡니다. |
| 목록·검색·미리보기 | 🔒 표시와 제목이 보입니다. 미리보기와 본문 검색 색인은 창이 열려 있어도 만들지 않습니다. 제목으로는 찾아집니다. |
| 백링크·`[[제목]]` | 제목이 평문이라 다른 노트에서 `[[제목]]`으로 열 수 있습니다(암호를 묻음). 잠긴 노트 안의 링크는 색인하지 않으므로, 다른 노트 이름이 바뀌어도 고쳐지지 않고 백링크에도 나오지 않습니다. |
| 파일명·제목(#113) | 파일 이름은 id 이름 또는 바깥 프로그램이 정한 이름 그대로입니다(제목이 원래 평문이라 바꾸지 않음). 폴더 정리는 암호 없이 머리말과 파일 이름만 다룹니다. **자동 제목은 잠글 때 끕니다**(첫 줄이 평문 제목이 되지 않도록). |
| 마감·반복·알림·캘린더 | 평문이라 잠긴 채로 동작합니다(사용자 결정). 알림 카드에는 제목과 마감만 나옵니다. 잠긴 노트의 **완료·날짜 변경은 암호 없이 됩니다**. 반복 노트를 완료해도 체크 목록은 비우지 않습니다(읽을 수 없음). 트레이 메뉴는 내용을 보여 주지 않습니다. |
| MCP(#120) | 목록·검색·읽기·쓰기 도구 모두 잠긴 노트를 **없는 노트처럼** 다룹니다. 창이 열려 있어도 같습니다. 제목과 마감도 넘기지 않습니다. |
| 자동 저장·임시 파일 | 저장 직전에 암호화하므로 `.tmp`에도 암호문만 들어갑니다. 충돌 때 만드는 "내 사본"도 같은 키로 잠깁니다. |
| 동기화 충돌 | 파일 단위라 병합하지 않습니다. "둘 다 유지"의 사본도 같은 암호로 열립니다. 다른 PC에서 잠금·암호가 바뀌면 이 PC의 창을 닫고 다시 열어 암호를 묻습니다. 이때 평문 창에 아직 저장되지 않은 글이 있으면 잃지 않도록 "내 사본"으로 저장합니다(그 사본은 평문입니다). |
| `.sync-removed`(엔진 백업, 30일) | 다른 PC가 보낸 암호화본을 받을 때 **옛 평문이 여기로 옮겨집니다.** 위젯이 시작할 때, 잠글 때, 동기화로 받았을 때 잠긴 노트의 평문 백업을 찾아 영구히 지웁니다. |
| **동기화 폴더 `blobs/`** | 엔진이 내용 해시 이름으로 저장하고 지우지 않아 **옛 평문이 남던 곳입니다.** 덮어쓸 수 없으므로(이름이 내용의 해시이고 다른 PC가 가리킬 수 있음), 엔진이 동기화 끝에 **어느 PC의 현재 기록도 어느 PC의 되돌리기 목록도 가리키지 않는 파일**을, **이 PC가 그 상태를 처음 본 지 하루가 지나면** 지웁니다(한 시간에 한 번까지 확인). 파일 시각은 쓰지 않습니다. 클라우드 프로그램이 원본 시각을 유지해 방금 받은 파일도 오래돼 보일 수 있기 때문입니다. 상태 파일을 읽을 수 없거나 아직 상태가 없는 PC가 있으면 아무것도 지우지 않습니다. 잘못 지워져도 그 내용을 가진 PC가 다음 동기화 때 다시 씁니다. 꺼져 있는 PC가 옛 파일을 가리키면 그 PC가 동기화될 때까지 남습니다. **예외(사용자 결정 2026-11-06)**: 충돌에서 버린 그 버전이 잠그기 전 평문이면, 되돌리기 기록이 끝날 때까지 **최대 30일** 동기화 폴더에 남습니다(지우기까지 하루 더). 이 PC가 다른 PC의 잠금을 "상대 것 받기"로 받아 버린 자기 평문은 충돌을 기다리는 수정이라 올라가지 않았고 백업도 지우므로 해당하지 않습니다. 자세한 내용과 되돌리기 제한은 [동기화와 알림](sync-and-notifications.md) 끝에 있습니다. |
| 클라우드 자체 기록 | OneDrive 등의 버전 기록과 휴지통은 지울 수 없습니다. **민감한 글은 빈 새 노트를 먼저 잠그고 쓰면** 평문이 애초에 만들어지지 않습니다. |
| 휴지통 | 잠글 때 평문 첨부는 휴지통을 거치지 않고 바로 지웁니다. 잠긴 노트를 휴지통으로 보내면 암호문이 갑니다. 잠그기 전에 휴지통에 들어간 평문은 건드리지 않습니다. 디스크에서 지운 평문은 운영체제 수준에서 복구될 가능성이 있습니다. |
| 내보내기·폴더 옮기기 | 할 일 노트에 내보내기는 없습니다. 폴더 옮기기(#108)는 바이트 복사라 암호문 그대로 갑니다. |
| 위젯 설정 파일 | 창 위치·색·알림 상태만 있고 내용은 없습니다. |
| 충돌 사본(OneDrive 등) | 같은 id의 평문 사본은 대신 지우지 않고, 잠글 때 "평문 사본 N개가 남아 있음"을 알립니다. |

## 5. 잠금과 풀기

- **잠그기**: 노트 메뉴 **암호로 잠그기…** 암호를 두 번 넣고(길이 제한 없음, 한 글자도 가능, 빈 값만 안 됨) "잊으면 복구할 수 없음"을 확인합니다. 순서는 첨부 암호화·검증 → 노트 파일 교체(원자적) → 평문 첨부 삭제입니다. 교체 전에 실패하면 평문 노트가 그대로 남고, 교체 뒤 끊기면 남은 평문 첨부를 다음에 열 때 암호화합니다. 창은 계속 열려 있습니다.
- **열기**: 창에 제목과 암호 칸만 보입니다.
- **암호 바꾸기**: 지금 암호와 새 암호를 넣습니다. 감싼 키만 바뀝니다. 옛 파일과 옛 암호가 있으면 같은 데이터 키를 얻을 수 있으므로, 유출이 걱정되면 **잠금 풀기 후 다시 잠그기**(새 데이터 키)를 안내합니다.
- **잠금 풀기**: 창이 열려 있어도 암호를 다시 묻고, 본문과 첨부 이름을 되돌립니다. 평문 첨부를 먼저 쓰고, 노트 파일을 바꾼 뒤 암호문을 지웁니다.
- **잘못된 암호**: "암호가 맞지 않습니다", 파일은 그대로입니다. **손상**(암호문을 바깥에서 고침): "파일이 손상됐거나…", 파일을 고치거나 지우지 않습니다. 첨부를 다른 첨부 파일로 바꿔치기해도 열리지 않습니다.
- **Obsidian 등**: 머리말, 안내 문장, 암호문 코드 블록으로 보입니다. 머리말을 고치거나 속성을 더하는 것, 줄바꿈 형식이 바뀌는 것은 괜찮습니다. 암호문 줄을 고치면 열 수 없습니다. 이 기능이 없는 옛 위젯에서는 같은 모습의 일반 노트로 보입니다.

## 6. 코드

- `widgets/todonote/lib/lock.js`: 암호화(파일을 만지지 않음).
- `widgets/todonote/lib/library.js`: 잠금·풀기, 메모리의 키(`keys`, 창이 열린 노트만), 평문 백업 정리.
- `widgets/todonote/index.js`: 창과 호출 연결. 잠긴 창은 `TEXT_CALLS`를 거절합니다.
- `engine/main/sync/core.js`: `sweepBlobs`. 엔진 API는 바뀌지 않고, 엔진을 업데이트한 PC가 동기화할 때 동작합니다.
