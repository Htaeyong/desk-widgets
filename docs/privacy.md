# 개인정보 안내

Desk Widgets(엔진과 위젯)가 어떤 정보를 어디에 두고 어디로 보내는지 정리한 문서입니다. 이 문서는 소스 코드를 기준으로 썼습니다.

## 요약

- **수집하지 않습니다.** 사용 기록, 오류 보고, 통계(텔레메트리)를 만들거나 보내는 코드가 없습니다. 개발자나 다른 서버로 가는 정보는 없습니다.
- **업데이트 확인**(엔진 1.1.0부터, 기본 켜짐)은 버전 정보만 받아 옵니다. 아래 "업데이트 확인"을 보세요. 설치는 사용자가 누를 때만 합니다.
- 위젯은 **사용자가 설정한 서비스에만** 접속합니다(아래 표).
- 계정 비밀번호와 API 토큰은 **이 PC에 암호화**해 저장하고, 그 계정의 서비스에만 보냅니다.
- **폴더 동기화는 사용자가 켤 때만** 선택한 로컬 폴더에 데이터를 씁니다. 엔진은 클라우드 서버에 직접 접속하지 않으며, OneDrive 같은 PC 프로그램이 그 폴더를 다른 PC로 옮길 수 있습니다.

## 위젯이 접속하는 곳

| 위젯 | 접속하는 곳 | 보내는 것 |
|---|---|---|
| 두레이 대시보드 | Dooray! API(`api.dooray.com` 또는 설정한 주소) | 사용자가 넣은 API 토큰과 업무 조회 요청 |
| 캘린더 | 사용자가 추가한 CalDAV 서버와 ICS 주소 | 그 계정의 아이디·비밀번호(앱 비밀번호), 일정 조회·편집 요청 |
| 캘린더(Google 계정, #114) | 사용자가 **Google 계정 추가**를 눌렀을 때만: 로그인 화면 `accounts.google.com`(사용자의 브라우저), 토큰 `oauth2.googleapis.com`, 캘린더 `www.googleapis.com/calendar/v3` | Google 로그인 토큰(위젯이 비밀번호를 보지 않음), 캘린더 목록·일정 조회·편집 요청, 계정을 지울 때 연결 끊기 요청 |
| 메일 | 사용자가 추가한 IMAP·SMTP 서버 | 그 계정의 아이디·비밀번호, 메일 조회·보내기 요청 |
| 시계, 스티키 노트, 시스템 모니터, 할 일 목록 | 접속하지 않음 | 없음 |
| 엔진 | 업데이트 확인·설치할 때만(아래) | 없음(요청만) |
| 엔진(폴더 동기화) | 접속하지 않음. 사용자가 선택한 로컬 폴더에 파일을 읽고 씀 | 없음 |

- 메일 미리보기는 **외부 이미지를 기본으로 막습니다**(보낸 사람이 메일을 열었는지 알아내는 추적 이미지일 수 있음). 메일마다 "이미지 표시"를 눌렀을 때만 그 메일의 이미지를 받습니다.
- 설정 창의 도움말 링크(예: 앱 비밀번호 만드는 곳)는 누르면 기본 브라우저로 열립니다.
- **Google 계정**: 로그인은 사용자의 기본 브라우저에서 Google과 직접 합니다(위젯 창 안의 로그인 화면 없음). Google이 로그인 결과를 이 PC 안의 임시 주소(`127.0.0.1`, 로그인 한 번 동안만 열림)로 돌려주면 위젯이 받습니다. 위젯이 요청하는 권한은 **캘린더 목록 보기(읽기 전용)** 와 **일정 보기·수정** 둘뿐이고, Google에서 받은 정보는 이 PC의 위젯에서만 쓰며 개발자나 다른 곳으로 보내지 않습니다. 연결은 위젯에서 계정을 지우거나 Google 계정 설정(<https://myaccount.google.com/permissions>)에서 끊을 수 있습니다.
- **테마**는 격리된 창에서 실행되어 인터넷에 접속할 수 없고(네트워크 요청 차단), 계정 정보나 토큰을 받지 않습니다. 테마는 위젯이 정한 화면용 데이터만 받습니다.

## 업데이트 확인 (엔진 1.1.0부터)

| 언제 | 접속하는 곳 | 보내는 것 |
|---|---|---|
| 시작하고 2분 뒤, 그 뒤 하루 한 번, **업데이트 확인** 버튼 | `https://widgets.chilgong88.com/products.json` (다운로드 페이지, Firebase Hosting) | 파일 요청 하나뿐. 설치한 위젯 목록·버전·계정·식별자는 보내지 않습니다 |
| **업데이트** 버튼을 눌렀을 때만 | `github.com`의 이 프로젝트 릴리스 주소와 GitHub 파일 서버(`objects.githubusercontent.com`, `release-assets.githubusercontent.com`) | 설치 파일 요청 하나뿐 |

- 위젯 관리 창의 **위젯 추가**(처음 실행 때 저절로 열림)를 열면 같은 `products.json`을 받고, **선택한 위젯 설치**를 눌렀을 때만 고른 위젯의 설치 파일을 위 GitHub 주소에서 받습니다(자동 확인을 꺼 둬도 같음, 사용자가 화면을 연 동작이므로).
- 일반적인 웹 요청처럼 이 서버들은 접속한 IP 주소와 시각을 볼 수 있습니다(Firebase·GitHub의 개인정보 정책을 따름). 앱은 쿠키나 고유 번호를 보내지 않습니다.
- 자동 확인은 위젯 관리 창 → 일반 설정 → **새 버전 자동 확인**에서 끌 수 있습니다. 끄면 버튼을 누를 때만 확인합니다.
- 받은 설치 파일은 `%TEMP%\desk-widgets-update\`에 두고 다음 실행 때 지웁니다. 마지막 확인 시각과 이미 알린 버전은 `%APPDATA%\chilgong88\desk-widgets\updates.json`에 있습니다.

## 이 PC에 저장하는 것

모두 이 PC의 Windows 사용자 프로필 안에 있습니다.

| 무엇 | 어디에 |
|---|---|
| 엔진과 위젯 설정(창 위치, 테마, 계정 주소, 분류, 알림 조건 등) | `%APPDATA%\chilgong88\desk-widgets\` |
| 캘린더·메일 계정 비밀번호, 캘린더의 Google 로그인 토큰(새로 고침 토큰. 짧게 쓰는 접근 토큰은 메모리에만) | 위젯 설정 폴더의 `secrets.json`, 암호화된 값만 |
| 두레이 API 토큰 | 두레이 위젯 `settings.json`, 암호화된 값 |
| 로컬 일정, 할 일 | 위젯 설정 폴더 |
| 스티키 노트 | `문서\Desk Widgets\스티키 노트`(바꿀 수 있음)의 Markdown 파일 |
| 할 일 노트 | `문서\Desk Widgets\할 일 노트`(바꿀 수 있음)의 Markdown 파일 |
| 폴더 동기화 설정·비교 기준·되돌리기 기록 | 엔진 설정 폴더의 `sync\` |

### 선택한 폴더에 동기화하는 데이터

위젯 관리 → 동기화에서 폴더와 위젯을 고른 뒤 미리보기를 확인하면, 위젯 데이터는 그대로 이 PC에 두고 **엔진이** 고른 데이터의 사본을 선택한 폴더에 씁니다(`state\<이 PC id>\`의 항목 파일과 `blobs\`의 노트·첨부 내용). 할 일·내 캘린더 일정과 CalDAV·Google 계정 정보(이메일·이름·색·캘린더 선택. 비밀번호·로그인 토큰 제외)·알람·노트와 일부 표시 설정이 들어갑니다. **내용은 암호화되지 않습니다.** 선택한 폴더를 OneDrive·Google Drive·Dropbox 같은 프로그램이 동기화한다면 해당 서비스에도 이 데이터가 올라갑니다. 두레이·메일의 분류·규칙·주소록은 업무 제목과 메일 주소가 포함될 수 있으므로 각 위젯의 동기화가 기본 꺼짐입니다. 회사 보안 정책을 확인한 뒤 켜세요.

계정 비밀번호, API 토큰, 비공개 ICS 주소와 이 PC의 창 위치·외부 연동 켜기 상태는 동기화하지 않습니다. 다른 PC에서 계정을 사용하려면 비밀번호를 그 PC에서 다시 입력하고(Google 계정은 그 PC에서 다시 로그인) 연동을 직접 켜야 합니다. 비밀번호·토큰은 엔진의 비밀 저장소(Windows 데이터 보호)에만 있고 동기화 대상이 될 수 없으며, 엔진은 내보내기 직전에 이 PC의 비밀 값이 섞인 항목이 있으면 그 데이터를 내보내지 않습니다. 동기화를 꺼도 위젯 데이터는 원래 이 PC에 있으므로 옮길 것이 없고, 선택한 동기화 폴더의 파일은 남습니다. 폴더 파일을 지우면 다른 PC의 동기화에도 영향을 줄 수 있습니다.

### 비밀번호와 토큰 암호화

비밀번호와 토큰은 Electron `safeStorage`로 암호화합니다. Windows에서는 **DPAPI(Windows 데이터 보호)**를 쓰므로, 이 PC의 같은 Windows 사용자만 풀 수 있습니다. 화면, 로그, 테마에는 보내지 않습니다.

- **평문으로는 저장하지 않습니다.** Windows 암호화를 쓸 수 없으면 두레이·캘린더·메일 위젯 모두 토큰·비밀번호를 저장하지 않고 설정 창에 이유를 알립니다. 이 상태에서는 그 계정을 연결할 수 없습니다.
- 예전 버전의 두레이 위젯은 Windows 암호화를 쓸 수 없을 때 토큰을 평문으로 저장했습니다. 그런 토큰은 다음 실행 때 바로 암호화해 다시 저장하고, 암호화를 쓸 수 없으면 파일에서 지웁니다(그 실행 동안만 쓰고, 다음에는 토큰을 다시 입력해야 함).

## 지우기

- 위젯이나 엔진을 제거할 때 "설정도 함께 삭제할까요?"에서 **예**를 고르면 위의 설정 폴더(비밀번호·토큰 포함)를 지웁니다.
- 스티키 노트 파일은 사용자의 문서이므로 제거해도 지우지 않습니다.
