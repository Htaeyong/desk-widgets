# 개인정보 안내

Desk Widgets(엔진과 위젯)가 어떤 정보를 어디에 두고 어디로 보내는지 정리한 문서입니다. 이 문서는 소스 코드를 기준으로 썼습니다.

## 요약

- **수집하지 않습니다.** 사용 기록, 오류 보고, 통계(텔레메트리)를 만들거나 보내는 코드가 없습니다. 개발자나 다른 서버로 가는 정보는 없습니다.
- **자동 업데이트 확인도 하지 않습니다.** 새 버전은 [Releases](https://github.com/Htaeyong/desk-widgets/releases)에서 직접 받습니다.
- 위젯은 **사용자가 설정한 서비스에만** 접속합니다(아래 표).
- 계정 비밀번호와 API 토큰은 **이 PC에 암호화**해 저장하고, 그 계정의 서비스에만 보냅니다.

## 위젯이 접속하는 곳

| 위젯 | 접속하는 곳 | 보내는 것 |
|---|---|---|
| 두레이 대시보드 | Dooray! API(`api.dooray.com` 또는 설정한 주소) | 사용자가 넣은 API 토큰과 업무 조회 요청 |
| 캘린더 | 사용자가 추가한 CalDAV 서버와 ICS 주소 | 그 계정의 아이디·비밀번호(앱 비밀번호), 일정 조회·편집 요청 |
| 메일 | 사용자가 추가한 IMAP·SMTP 서버 | 그 계정의 아이디·비밀번호, 메일 조회·보내기 요청 |
| 시계, 스티키 노트, 시스템 모니터, 할 일 목록 | 접속하지 않음 | 없음 |
| 엔진 | 접속하지 않음 | 없음 |

- 메일 미리보기는 **외부 이미지를 기본으로 막습니다**(보낸 사람이 메일을 열었는지 알아내는 추적 이미지일 수 있음). 메일마다 "이미지 표시"를 눌렀을 때만 그 메일의 이미지를 받습니다.
- 설정 창의 도움말 링크(예: 앱 비밀번호 만드는 곳)는 누르면 기본 브라우저로 열립니다.
- **테마**는 격리된 창에서 실행되어 인터넷에 접속할 수 없고(네트워크 요청 차단), 계정 정보나 토큰을 받지 않습니다. 테마는 위젯이 정한 화면용 데이터만 받습니다.

## 이 PC에 저장하는 것

모두 이 PC의 Windows 사용자 프로필 안에 있습니다.

| 무엇 | 어디에 |
|---|---|
| 엔진과 위젯 설정(창 위치, 테마, 계정 주소, 분류, 알림 조건 등) | `%APPDATA%\chilgong88\desk-widgets\` |
| 캘린더·메일 계정 비밀번호 | 위젯 설정 폴더의 `secrets.json`, 암호화된 값만 |
| 두레이 API 토큰 | 두레이 위젯 `settings.json`, 암호화된 값 |
| 로컬 일정, 할 일 | 위젯 설정 폴더 |
| 스티키 노트 | `문서\Desk Widgets\스티키 노트`(바꿀 수 있음)의 Markdown 파일 |

### 비밀번호와 토큰 암호화

비밀번호와 토큰은 Electron `safeStorage`로 암호화합니다. Windows에서는 **DPAPI(Windows 데이터 보호)**를 쓰므로, 이 PC의 같은 Windows 사용자만 풀 수 있습니다. 화면, 로그, 테마에는 보내지 않습니다.

- **평문으로는 저장하지 않습니다.** Windows 암호화를 쓸 수 없으면 두레이·캘린더·메일 위젯 모두 토큰·비밀번호를 저장하지 않고 설정 창에 이유를 알립니다. 이 상태에서는 그 계정을 연결할 수 없습니다.
- 예전 버전의 두레이 위젯은 Windows 암호화를 쓸 수 없을 때 토큰을 평문으로 저장했습니다. 그런 토큰은 다음 실행 때 바로 암호화해 다시 저장하고, 암호화를 쓸 수 없으면 파일에서 지웁니다(그 실행 동안만 쓰고, 다음에는 토큰을 다시 입력해야 함).

## 지우기

- 위젯이나 엔진을 제거할 때 "설정도 함께 삭제할까요?"에서 **예**를 고르면 위의 설정 폴더(비밀번호·토큰 포함)를 지웁니다.
- 스티키 노트 파일은 사용자의 문서이므로 제거해도 지우지 않습니다.
- 자세한 내용: [사용자 가이드](user-guide.md)
