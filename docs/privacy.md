# 개인정보 안내

Desk Widgets(엔진과 위젯)가 어떤 정보를 어디에 두고 어디로 보내는지 정리한 문서입니다. 이 문서는 소스 코드를 기준으로 썼습니다.

## 요약

- **수집하지 않습니다.** 사용 기록, 오류 보고, 통계(텔레메트리)를 만들거나 보내는 코드가 없습니다. 개발자나 다른 서버로 가는 정보는 없습니다.
- **업데이트 확인**(엔진 1.1.0부터, 기본 켜짐)은 버전 정보만 받아 옵니다. 아래 "업데이트 확인"을 보세요. 설치는 사용자가 누를 때만 합니다.
- 위젯은 **사용자가 설정한 서비스에만** 접속합니다(아래 표).
- 계정 비밀번호와 API 토큰은 **이 PC에 암호화**해 저장하고, 그 계정의 서비스에만 보냅니다.
- **AI 도우미 연결 (MCP)**(#120·#121, 기본 꺼짐)을 켜면 사용자가 자기 AI 도우미 앱(Claude 데스크톱·Claude Code 등)에 추가한 Desk Widgets 도구가 할 일 노트·캘린더 일정·**메일**·**두레이 업무**·시계 알람을 읽고, 쓰기를 허용했다면 할 일 노트·캘린더 일정·시계 알람과 타이머를 바꿉니다(메일·두레이는 읽기만). Desk Widgets는 인터넷으로 보내지 않지만, **그 앱은 읽은 내용을 자기 서비스(예: Anthropic)로 보냅니다.** 아래 "AI 도우미 연결 (MCP)"을 보세요.
- **폴더 동기화는 사용자가 켤 때만** 선택한 로컬 폴더에 데이터를 씁니다. 엔진은 클라우드 서버에 직접 접속하지 않으며, OneDrive 같은 PC 프로그램이 그 폴더를 다른 PC로 옮길 수 있습니다.

- **할 일 노트의 비밀 노트**(#124)는 사용자가 정한 암호로 본문과 첨부를 이 PC에서 암호화합니다(scrypt, AES-256-GCM). 암호와 키는 저장하지 않으므로 **암호를 잊으면 복구할 수 없습니다.** 아래 "비밀 노트"를 보세요.

## 위젯이 접속하는 곳

| 위젯 | 접속하는 곳 | 보내는 것 |
|---|---|---|
| 두레이 대시보드 | Dooray! API(`api.dooray.com` 또는 설정한 주소) | 사용자가 넣은 API 토큰과 업무 조회 요청. AI 도우미 연결에서 위키·드라이브·캘린더를 켰다면 AI가 부를 때 그 조회 요청(#131) |
| 캘린더 | 사용자가 추가한 CalDAV 서버와 ICS 주소 | 그 계정의 아이디·비밀번호(앱 비밀번호), 일정 조회·편집 요청 |
| 캘린더(Google 계정, #114) | 사용자가 **Google 계정 추가**를 눌렀을 때만: 로그인 화면 `accounts.google.com`(사용자의 브라우저), 토큰 `oauth2.googleapis.com`, 캘린더 `www.googleapis.com/calendar/v3` | Google 로그인 토큰(위젯이 비밀번호를 보지 않음), 캘린더 목록·일정 조회·편집 요청, 계정을 지울 때 연결 끊기 요청 |
| 메일 | 사용자가 추가한 IMAP·SMTP 서버 | 그 계정의 아이디·비밀번호, 메일 조회·보내기 요청 |
| 시계, 스티키 노트, 시스템 모니터, 할 일 목록 | 접속하지 않음 | 없음 |
| 엔진 | 업데이트 확인·설치할 때만(아래) | 없음(요청만) |
| 엔진(폴더 동기화) | 접속하지 않음. 사용자가 선택한 로컬 폴더에 파일을 읽고 씀 | 없음 |
| 엔진(AI 도우미 연결, #120·#121) | 접속하지 않음. 이 PC 안의 명명 파이프로, 사용자의 AI 도우미 앱이 실행한 다리 프로세스와만 이야기함(네트워크 포트 없음) | 도구 결과(할 일·노트 내용 일부, 일정, 메일 목록·본문 글자, 두레이 업무, 시계 알람)를 그 다리에 넘김 |

- AI Widgets 위젯: Claude Code가 `api.anthropic.com`에 접속합니다. 위젯은 연결 확인을 누를 때만 같은 주소에 직접 접속합니다(내 API 키, Anthropic에만). 아래 "AI Widgets 위젯"을 보세요.
- 메일 미리보기는 **외부 이미지를 기본으로 막습니다**(보낸 사람이 메일을 열었는지 알아내는 추적 이미지일 수 있음). 메일마다 "이미지 표시"를 눌렀을 때만 그 메일의 이미지를 받습니다.
- 설정 창의 도움말 링크(예: 앱 비밀번호 만드는 곳)는 누르면 기본 브라우저로 열립니다.
- **Google 계정**: 로그인은 사용자의 기본 브라우저에서 Google과 직접 합니다(위젯 창 안의 로그인 화면 없음). Google이 로그인 결과를 이 PC 안의 임시 주소(`127.0.0.1`, 로그인 한 번 동안만 열림)로 돌려주면 위젯이 받습니다. 위젯이 요청하는 권한은 **캘린더 목록 보기(읽기 전용)** 와 **일정 보기·수정** 둘뿐이고, Google에서 받은 정보는 이 PC의 위젯에서만 쓰며 개발자나 다른 곳으로 보내지 않습니다. 연결은 위젯에서 계정을 지우거나 Google 계정 설정(<https://myaccount.google.com/permissions>)에서 끊을 수 있습니다.
- **테마**는 격리된 창에서 실행되어 인터넷에 접속할 수 없고(네트워크 요청 차단), 계정 정보나 토큰을 받지 않습니다. 테마는 위젯이 정한 화면용 데이터만 받습니다.

- 자동 확인은 위젯 관리 창 → 일반 설정 → **새 버전 자동 확인**에서 끌 수 있습니다. 끄면 버튼을 누를 때만 확인합니다.
- 받은 설치 파일은 `%TEMP%\desk-widgets-update\`에 두고 다음 실행 때 지웁니다. 마지막 확인 시각과 이미 알린 버전은 `%APPDATA%\chilgong88\desk-widgets\updates.json`에 있습니다.

## AI 도우미 연결 (MCP, 엔진 API 1.10, #120·#121)

- **기본 꺼짐.** 위젯 관리 창의 **AI 도우미 연결 (MCP)**에서 켤 때만 동작합니다. 쓰기(할 일 노트의 날짜·완료·새 노트·덧붙이기, 캘린더 일정 만들기·고치기, 시계 알람·타이머)는 따로 **쓰기 허용**을 켜야 하고, 무언가를 지우는 도구는 없습니다. 위젯마다 읽기/쓰기를 끌 수 있습니다.
- **메일·두레이도 켜져 있으면 읽힙니다**(#121): 안 읽은 메일 목록, 메일 찾기, **메일 본문(글자만, 잘라서)**, 두레이 내 업무·마감·멘션, 업무 찾기. 메일은 다른 사람이 보낸 글이고 두레이 업무는 회사 데이터이므로, 그 내용이 **사용자의 AI 앱 서비스(예: Anthropic)로 전달**되는 것을 원하지 않으면 위젯 관리 창에서 **메일·두레이의 읽기를 끄세요**(회사 보안 규정도 확인하세요). 메일 첨부 파일 내용은 넘기지 않고(이름·크기만), 메일을 읽어도 읽음으로 바뀌지 않습니다. 두레이 업무 도구는 위젯이 이미 받아 둔 데이터만 쓰며 두레이 서버에 따로 요청하지 않습니다.
- **두레이 위키·드라이브·캘린더**(#131, 두레이 위젯 설정에서 켤 때만, 기본 꺼짐): AI가 도구를 부를 때 위젯이 저장된 API 토큰으로 **두레이에 읽기 요청(GET)** 을 보내고, 위키 목록·**위키 페이지 글**·드라이브 목록과 **파일 이름·크기**·캘린더 목록과 **일정 제목·시간·장소**를 AI 앱에 넘깁니다. 일정 설명은 넘기지 않습니다. 두 번째 스위치 **파일 내용도 넘기기**(기본 꺼짐)를 켜면 드라이브 파일·위키 첨부 중 **글자 파일(1MB까지)의 내용**도 넘깁니다. 이 내용은 회사 데이터이며 **AI 앱의 서비스(예: Anthropic)로 전달되어 회사 밖으로 나갈 수 있습니다**. 회사 보안 규정을 확인한 뒤 켜세요. 두레이 데이터를 만들거나 바꾸는 요청은 보내지 않고, 토큰은 도구 결과·기록에 넣지 않습니다. 같은 스위치가 켜져 있으면 AI가 **원본 받기**(`fetch_file`, 받을 때마다 Desk Widgets 알림 카드에서 사용자가 **받기**를 눌러야 함)로 드라이브 파일·위키 첨부를 형식 제한 없이 20MB까지 이 PC의 두레이 위젯 데이터 폴더(`fetched`)에 받을 수 있습니다. 결과에는 경로만 들어가지만, AI 앱이 그 파일을 열어 처리하면 내용이 그 서비스로 전달됩니다. 받은 파일은 24시간 뒤 지웁니다.
- 캘린더 일정의 제목·장소·설명(공유 캘린더는 다른 사람이 쓴 글)도 넘어갑니다. 캘린더 계정 비밀번호·Google 토큰·비공개 ICS 주소는 넘기지 않습니다.
- 사용자가 자기 AI 도우미 앱의 설정에 Desk Widgets를 직접 추가해야 연결됩니다. Desk Widgets는 그 앱을 실행하지 않고, 그 앱의 로그인 정보나 설정 파일을 읽거나 고치지 않습니다.
- 도구가 돌려준 것(할 일 제목, 마감, 노트 내용·체크 목록, 미리보기)은 **그 앱이 받아 자기 서비스로 보냅니다**(예: Claude는 Anthropic). 그 처리는 사용자가 그 앱과 맺은 약관·설정을 따릅니다. 보내고 싶지 않은 노트가 있으면 연결을 켜지 마세요.
- 이미지·첨부는 이름만 넘기고 파일 경로·내용은 넘기지 않습니다. 다른 위젯의 데이터와 계정·비밀번호·토큰은 넘기지 않습니다.
- 엔진은 네트워크 포트를 열지 않습니다. 실행할 때마다 이름을 새로 정하는 명명 파이프와 무작위 토큰으로, 같은 Windows 사용자가 실행한 다리만 연결합니다.
- 바꿀 때마다 알림 카드가 뜨고(10분 안에 **되돌리기**), 기록이 남습니다.

## 비밀 노트 (할 일 노트, #124)

- 암호화하는 것: 노트 본문, 첨부 파일의 내용과 이름. 네트워크로 보내는 것은 없습니다.
- **암호화하지 않는 것**: 머리말 전체(제목, 만든 시각, 마감·반복·알림·완료, 출처, 다른 프로그램의 속성), 폴더, 대략의 크기, 저장 시각, 첨부 개수, 노트 색. 알림 카드와 캘린더 연동에는 제목과 마감이 나옵니다. **AI 도우미 연결에는 잠긴 노트의 어떤 정보도 넘기지 않습니다.** 캘린더 화면에는 잠긴 노트의 마감이 보이지만 캘린더의 AI 도구(일정 목록·검색·다가오는 일정·D-day)는 그 노트와 그 노트를 따르는 D-day를 빼고 돌려줍니다(#133). 잠금 여부를 알려 주지 않는 옛 할 일 노트와 함께 쓰면 캘린더 AI 도구는 노트 마감을 모두 뺍니다. **#133 이전 캘린더(1.1.3까지)**는 이 구별을 하지 않아 잠긴 노트의 제목과 마감이 캘린더 도구 결과로 나갈 수 있습니다. 잠긴 노트를 지우며 **일정 유지**(#128)로 내 캘린더에 복사한 일정은 사용자가 만든 보통 일정이라 AI 도구에도 보입니다.
- 노트 창이 열려 있는 동안 내용과 키는 메모리에 있습니다(절전 파일에 들어갈 수 있음). 창을 닫으면 키를 지웁니다. 복사한 내용은 클립보드에 남습니다.
- 첨부를 **다른 이름으로 저장**하면 그 파일은 평문입니다. 끌어다 놓은 원본 파일은 위젯이 지우지 않습니다.
- 잠그기 전의 평문: 이 PC의 평문 첨부와 엔진 백업(`.sync-removed`)은 지웁니다. 동기화 폴더의 옛 내용은 어느 PC도 쓰지 않게 되고 하루가 지나면 엔진이 지웁니다. **예외로, 동기화 충돌에서 버린 버전이 평문이면 그 PC에서 되돌릴 수 있는 동안 최대 30일(지우기까지 하루 더) 동기화 폴더에 남습니다.** 다른 옛 버전은 이 예외에 들지 않습니다. OneDrive 같은 클라우드의 버전 기록과 휴지통, 잠그기 전에 휴지통으로 보낸 파일, 충돌 사본은 지우지 않습니다. 디스크에서 지운 파일은 운영체제 수준에서 복구될 가능성이 있습니다.

## AI Widgets 위젯 (선택, 설치하고 키를 넣었을 때만)

- 설치된 **Claude Code**를 실행합니다. Claude Code가 내 명령과, 작업 중 읽은 파일·명령 결과·도구 결과를 `api.anthropic.com`으로 보냅니다. 무엇이 가는지는 시킨 일에 달려 있습니다. **저장한 요약의 제목과 "언제 쓰는지"는 실행마다**, 내용은 읽을 때 전달됩니다.
- **Desk Widgets 개발자에게는 아무것도 가지 않습니다.** 서버가 없습니다.
- 내 API 키의 조직으로 처리되며 Anthropic 상용 약관을 따릅니다. 보관과 학습은 Anthropic의 안내를 따릅니다.

### 선택한 폴더에 동기화하는 데이터

위젯 관리 → 동기화에서 폴더와 위젯을 고른 뒤 미리보기를 확인하면, 위젯 데이터는 그대로 이 PC에 두고 **엔진이** 고른 데이터의 사본을 선택한 폴더에 씁니다(`state\<이 PC id>\`의 항목 파일과 `blobs\`의 노트·첨부 내용). 할 일·내 캘린더 일정과 CalDAV·Google 계정 정보(이메일·이름·색·캘린더 선택. 비밀번호·로그인 토큰 제외)·알람·노트와 일부 표시 설정이 들어갑니다. **내용은 암호화되지 않습니다.** 선택한 폴더를 OneDrive·Google Drive·Dropbox 같은 프로그램이 동기화한다면 해당 서비스에도 이 데이터가 올라갑니다. 두레이·메일의 분류·규칙·주소록은 업무 제목과 메일 주소가 포함될 수 있으므로 각 위젯의 동기화가 기본 꺼짐입니다. 회사 보안 정책을 확인한 뒤 켜세요.

계정 비밀번호, API 토큰, 비공개 ICS 주소와 이 PC의 창 위치·외부 연동 켜기 상태는 동기화하지 않습니다. 다른 PC에서 계정을 사용하려면 비밀번호를 그 PC에서 다시 입력하고(Google 계정은 그 PC에서 다시 로그인) 연동을 직접 켜야 합니다. 비밀번호·토큰은 엔진의 비밀 저장소(Windows 데이터 보호)에만 있고 동기화 대상이 될 수 없으며, 엔진은 내보내기 직전에 이 PC의 비밀 값이 섞인 항목이 있으면 그 데이터를 내보내지 않습니다. 동기화를 꺼도 위젯 데이터는 원래 이 PC에 있으므로 옮길 것이 없고, 선택한 동기화 폴더의 파일은 남습니다. 폴더 파일을 지우면 다른 PC의 동기화에도 영향을 줄 수 있습니다.

### 비밀번호와 토큰 암호화

비밀번호와 토큰은 Electron `safeStorage`로 암호화합니다. Windows에서는 **DPAPI(Windows 데이터 보호)**를 쓰므로, 이 PC의 같은 Windows 사용자만 풀 수 있습니다. 화면, 로그, 테마에는 보내지 않습니다.

- **평문으로는 저장하지 않습니다.** Windows 암호화를 쓸 수 없으면 두레이·캘린더·메일 위젯 모두 토큰·비밀번호를 저장하지 않고 설정 창에 이유를 알립니다. 이 상태에서는 그 계정을 연결할 수 없습니다.
- 예전 버전의 두레이 위젯은 Windows 암호화를 쓸 수 없을 때 토큰을 평문으로 저장했습니다. 그런 토큰은 다음 실행 때 바로 암호화해 다시 저장하고, 암호화를 쓸 수 없으면 파일에서 지웁니다(그 실행 동안만 쓰고, 다음에는 토큰을 다시 입력해야 함).
