# 사용자 가이드

## PC 간 폴더 동기화 (내부 테스트, #108)

위젯 관리 창의 **동기화** 탭에서 OneDrive·Google Drive·Dropbox 등이 동기화하는 **로컬 폴더**를 고르고, 이 PC 이름과 동기화할 위젯을 선택하세요. 처음 연결할 때 받아올 항목과 올릴 항목을 미리 보여 줍니다. 양쪽에서 같은 항목을 다르게 고쳤다면 **이 PC 것 유지 / 클라우드 것 받기 / 둘 다 남기기** 중 하나를 고릅니다. 최근 비교에서 버린 값은 30일 안에 동기화 탭에서 되살릴 수 있습니다. 오랫동안 연결하지 않았거나 폴더를 바꾸면 변경 내용을 다시 확인해야 합니다.

할 일·내 캘린더 일정·알람·스티키 노트·할 일 노트와 선택한 설정을 동기화할 수 있습니다. 두레이·메일에는 업무 정보가 들어갈 수 있어 기본 꺼짐입니다. 동기화 폴더의 내용은 암호화되지 않으므로 회사 정책을 확인한 뒤 켜세요. 비밀번호·토큰·비공개 구독 주소와 창 위치, 외부 연동 켜기 상태는 다른 PC에 옮기지 않습니다. 노트 폴더가 동기화 폴더와 겹칠 때만 노트 파일 동기화를 건너뜁니다(문서 폴더가 OneDrive 안이어도 주고받음).

충돌이 많으면 비교 화면 위의 **모두 이 PC 값 / 모두 다른 PC 값 / 모두 최신 값** 버튼(위젯별로도 있음)으로 한꺼번에 고른 뒤 필요한 항목만 바꾸세요. 손대지 않은 기본값 설정은 충돌로 묻지 않습니다. 답하기 전에도 충돌한 항목만 멈추고 나머지는 계속 동기화됩니다. **자동 확인 주기**(1·2·5·10·30분, 기본 2분)는 동기화 탭에서 바꿀 수 있고, 그 아래에 마지막·다음 확인 시각과 폴더 감시 상태(네트워크 폴더는 주기 확인만)가 보입니다.

위젯 데이터는 연결과 관계없이 **항상 이 PC에** 저장되고(노트 폴더도 그대로), 엔진이 고른 데이터의 변경만 동기화 폴더로 주고받습니다. 그래서 동기화를 꺼도 옮길 것이 없고, 위젯 데이터와 클라우드 폴더의 파일은 그대로 남습니다. 1.1.3-test 판을 쓰던 PC는 새 판을 처음 시작할 때 엔진이 동기화 폴더에 있던 데이터를 확인·백업한 뒤 이 PC로 되돌립니다(동기화 폴더의 원본은 지우지 않음).

## 설치

Desk Widgets는 **엔진**과 **위젯**을 따로 설치합니다. 엔진(Electron)은 하나만 설치되고, 설치한 위젯들이 그 안에서 함께 실행됩니다(위젯 하나에 약 25~50MB).

**처음 설치하는 경우(위젯 고르기 화면이 들어간 엔진부터)**: 엔진만 설치하세요. 처음 실행하면 위젯 관리 창에 **위젯 추가**가 열리고, 쓸 위젯을 골라 **선택한 위젯 설치**를 누르면 내려받아 차례로 설치합니다.
- 시계·캘린더·스티키 노트가 미리 체크되어 있습니다(계정 없이 바로 쓰는 위젯). 두레이·메일 등은 필요할 때 체크하세요.
- 위젯마다 Windows 관리자 확인 창이 **한 번씩** 나타납니다(위젯이 3개면 3번). 창에서 **예**를 누르세요. 취소했거나 멈추면 해당 위젯에 **건너뛰기·다시 시도**가 나옵니다.
- 이 화면은 **위젯이 하나도 없는 첫 실행에 한 번만** 저절로 열립니다. 닫으면 다시 열리지 않고, 위젯 관리 창의 **위젯 추가 → 위젯 고르기**로 언제든 열 수 있습니다.
- 목록에는 정식 배포된 위젯만 나옵니다(개발 중·동결된 위젯은 나오지 않음). 이미 설치한 위젯은 "설치됨", 지금 엔진보다 새 엔진이 필요한 위젯은 "엔진 업데이트 필요"로 표시됩니다.
- 인터넷에 연결되지 않거나 사이트·GitHub에 접속할 수 없으면 안내와 **다시 불러오기**가 나옵니다. 그래도 엔진은 쓸 수 있습니다. 다운로드 페이지에서 받아 둔 위젯 설치 파일은 **내려받은 설치 파일 열기**로 설치합니다(인터넷이 있으면 게시된 파일과 같은지 확인하고, 없으면 확인할 수 없다는 경고 후 설치).
- 받은 파일은 설치 전에 게시된 파일과 같은지(SHA-256) 확인합니다([앱 안에서 업데이트](updates.md)와 같은 확인).

아래 표처럼 위젯 설치 파일을 따로 받아 직접 설치할 수도 있습니다.

[다운로드 페이지](https://widgets.chilgong88.com)에서 받습니다. 페이지는 제품마다 **항상 최신 버전**을 연결합니다. 모든 버전은 [GitHub 릴리스](https://github.com/Htaeyong/desk-widgets/releases)에 있습니다. 엔진과 위젯은 버전이 따로이며 릴리스도 따로 있습니다(엔진 `engine-v…`, 위젯 `widget-<id>-v…`, 예: 두레이 `widget-dooray-v…`). 첫 공개 릴리스(#100)의 버전: **엔진 1.0.4**, 두레이 1.0.3, 메일 1.0.2, 캘린더 1.0.2, 할 일 1.0.0, 시스템 모니터 1.0.0, 스티키 노트 1.0.0, 시계 1.0.0. **1.1.0부터 엔진과 모든 위젯이 같은 버전**으로 배포됩니다.

> 분할 전의 이전 Dooray Widget 앱(`DoorayWidget-Setup-1.0.x`)은 더 이상 쓰지 않습니다. 새로 설치할 때는 아래 Desk Widgets 파일을 쓰세요.

- 엔진이 없으면 위젯 설치 파일이 "먼저 Desk Widgets를 설치하라"고 알려 주고 멈춥니다.
- **설치하면 바로 사용**: 위젯을 설치하면 실행 중인 Desk Widgets에 바로 나타나 켜집니다(꺼져 있었으면 Desk Widgets가 시작됩니다). 두레이처럼 설정이 필요한 위젯은 그 위젯의 설정 창이 바로 열립니다.
- 사용할 위젯 고르기: 트레이 아이콘 → **위젯 관리 · 설정**에서 위젯별 **사용** 체크.
- 테스트 빌드(1.1.0-test.x)를 설치해 두었다면 정식 1.0.0을 **그대로 설치**하면 됩니다. 설치 프로그램이 테스트 빌드를 설정은 유지한 채 제거하고 설치합니다(버전이 낮아도 막지 않음). 위젯도 같은 방식입니다. 1.1.0-test.1처럼 두레이가 엔진에 들어 있던 테스트 빌드였다면 엔진 설치 후 두레이 위젯을 따로 설치하세요.
- 코드 서명이 없어 처음 실행할 때 Windows SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다. **추가 정보 → 실행**을 누르세요.
- 설정은 PC 사용자별로 `%APPDATA%\chilgong88\desk-widgets`에 저장되며, 엔진이나 위젯을 새 버전으로 설치해도 그대로 유지됩니다.

### 트레이 아이콘과 위젯 관리

위젯이 하나도 떠 있지 않아도 Desk Widgets는 트레이 아이콘으로 실행 중입니다.

- 트레이 아이콘 클릭: **위젯 관리 창** — 설치된 위젯(이름·버전·상태: 사용 중 / 꺼짐 / 호환 안 됨 / 오류), 위젯별 **사용** 켜기/끄기와 **설정**, 그리고 일반 설정. 위젯이 없으면 설치 방법을 안내합니다.
- 트레이 아이콘 오른쪽 클릭: (새 버전이 있으면) **업데이트 있음**, 위젯 관리 · 설정, 위젯별 설정, **Desk Widgets 종료**
- "호환 안 됨": 위젯이 요구하는 엔진 버전과 설치된 Desk Widgets가 맞지 않음. 이유와 함께 엔진 또는 위젯을 업데이트하라고 표시됩니다.
- 위젯 설정은 각 위젯 안에서 엽니다: 두레이는 제목줄 ⚙, 시계는 오른쪽 클릭 → 설정 (위젯 관리 창의 **설정**도 같은 창)

### 이전 이름(Dooray Widget)에서 옮겨 오기

1.1.0부터 앱이 **Desk Widgets 엔진 + 두레이 위젯**으로 나뉘었습니다. 기존 Dooray Widget 1.0.x 사용자는:

1. Desk Widgets(엔진)를 설치합니다. 처음 켜질 때 이전 설정 폴더 `%APPDATA%\dooray-widget`의 내용(두레이 주소·API 토큰, 분류, 조건 알림, 알림 설정, 받은 테마, 창 위치)을 새 폴더의 두레이 위젯 자리로 **복사**해 둡니다.
2. 이어서 두레이 위젯을 설치합니다. 이때 이전 **Dooray Widget** 앱을 설정은 남긴 채 자동으로 제거합니다(자동 실행 등록·바로가기 포함). 두레이 위젯은 옮겨 온 설정으로 바로 시작하며, 토큰을 다시 입력하지 않아도 됩니다.

- 1과 2 사이에 이전 앱에서 바꾼 설정은 옮겨지지 않으므로, 엔진을 설치한 뒤 바로 두레이 위젯을 설치하세요.
- 이전 폴더 `%APPDATA%\dooray-widget`은 백업으로 남겨 두며, **엔진·위젯을 제거할 때 "설정 삭제"를 골라도 지우지 않습니다.** 필요 없으면 직접 지우세요. 새 설정을 지운 뒤 엔진을 다시 설치하면 이 백업에서 다시 옮겨 옵니다.
- 새 폴더에 이미 설정이 있으면 복사하지 않습니다(처음 한 번만).

### 제거

Windows 설정 → 앱(또는 제어판 → 프로그램 제거)에서 위젯과 엔진을 각각 제거합니다.

| 제거 대상 | 묻는 것 | 아니요 (기본) | 예 |
|---|---|---|---|
| 위젯 (예: Desk Widgets-DoorayWidget) | **"○○ 위젯의 설정도 함께 삭제할까요?"** | 그 위젯 설정 유지 (다시 설치하면 그대로) | `%APPDATA%\chilgong88\desk-widgets\widgets\<위젯>` 삭제 |
| 엔진 (Desk Widgets) | **"사용자 설정도 함께 삭제할까요?"** | 모든 설정 유지 | `%APPDATA%\chilgong88\desk-widgets` 전체 삭제 (이전 앱 백업 `%APPDATA%\dooray-widget`은 그대로) |

- 위젯을 제거하면 실행 중인 Desk Widgets에서 바로 사라집니다.
- 엔진을 제거해도 설치한 위젯 폴더는 남습니다. 위젯은 제어판에서 따로 제거하세요.
- 스티키 노트 위젯의 노트(`문서\Desk Widgets\스티키 노트`)는 위젯·Desk Widgets를 제거하거나 설정을 지워도 남습니다.
- 엔진을 제거하면 Windows 시작 시 자동 실행 등록도 삭제됩니다.
- 새 버전을 덮어 설치(업데이트)할 때는 묻지 않고 설정을 유지합니다.
- 명령줄 무인 제거: `/S`는 설정 유지, `/S --delete-app-data`는 설정까지 삭제 (엔진·위젯 모두).

## 업데이트

엔진 **1.1.0**부터 Desk Widgets가 엔진과 설치한 위젯의 새 버전을 알려 줍니다. **자동으로 설치하지 않고**, 사용자가 **업데이트**를 눌렀을 때만 내려받아 설치합니다. 동작 방식: [앱 안에서 업데이트](updates.md)

- **언제 확인하나**: 시작하고 2분 뒤, 그 뒤 하루에 한 번. 위젯 관리 창의 **업데이트 확인** 버튼으로 바로 확인할 수도 있습니다. 자동 확인은 일반 설정 → **새 버전 자동 확인**에서 끌 수 있습니다(버튼은 꺼도 동작).
- **어떻게 알려 주나**: 새 버전을 처음 찾으면 알림 카드 "Desk Widgets 업데이트"(**업데이트 보기** → 위젯 관리 창). 업데이트가 남아 있는 동안 트레이 메뉴 맨 위에 **업데이트 있음 (N)**. 같은 버전은 카드로 다시 알리지 않습니다.
- **위젯 관리 창 → 업데이트**: 제품마다 현재 → 최신 버전과 상태(새 버전 / 최신 / 엔진을 먼저 업데이트 / 정보 없음).
  1. **업데이트**를 누르면 설치 파일을 내려받습니다(진행률 표시).
  2. 다운로드 페이지에 게시된 크기·SHA-256과 같은지 확인합니다. 다르면 파일을 지우고 오류를 보여 주며 실행하지 않습니다.
  3. Windows **관리자 권한 확인 창**(UAC)이 뜹니다. 코드 서명 전에는 "알 수 없는 게시자"로 표시됩니다. **예**를 누르면 설치 프로그램이 실행됩니다. 아니요를 누르면 "설치 프로그램을 실행하지 못했습니다"가 표시되고 **다시 시도**할 수 있습니다.
- **엔진 업데이트**: 설치 프로그램이 시작되면 Desk Widgets가 잠시 뒤 스스로 종료합니다. 설치가 끝나면 다시 실행되고, 설정과 위젯은 그대로입니다. 설치 프로그램에서 취소했다면 Desk Widgets를 시작 메뉴에서 다시 실행하세요.
- **위젯 업데이트**: Desk Widgets는 그대로 실행되고, 설치가 끝나면 그 위젯만 다시 시작됩니다.
- **엔진을 먼저 업데이트**: 위젯의 새 버전이 지금 엔진보다 새 엔진을 요구하면 버튼 대신 이렇게 표시됩니다. 엔진을 먼저 업데이트하세요.
- **정보 없음**: 다운로드 페이지에 그 제품의 설치 파일 정보가 아직 없음(1.1.0 이전에 배포된 버전 등). 다음 배포부터 표시됩니다.
- 업데이트 확인과 설치 때 접속하는 곳은 [개인정보 안내](privacy.md)에 있습니다. 직접 받고 싶으면 지금처럼 [다운로드 페이지](https://widgets.chilgong88.com)에서 받아 설치해도 됩니다.

## 처음 실행 (두레이 위젯)

1. 두레이 위젯을 설치하면 **두레이 대시보드 설정** 창이 열립니다. (이전 Dooray Widget의 설정을 옮겨 왔으면 바로 위젯이 뜹니다.)
2. **두레이 도메인**(예: `mycompany.dooray.com`)과 **API 토큰**을 입력합니다.
   - 토큰 발급: 두레이 → 설정 → API → 개인 인증 토큰
3. **연결 테스트**로 확인한 뒤 **저장**합니다.

입력한 값은 PC 사용자 계정별로 `%APPDATA%\chilgong88\desk-widgets\widgets\dooray\settings.json`에 저장됩니다. API 토큰은 Windows 암호화(DPAPI)로 저장되어 파일에 평문으로 남지 않습니다. 이 PC에서 Windows 암호화를 쓸 수 없으면 토큰을 저장하지 않고 설정 창에 이유를 알립니다(평문으로는 저장하지 않음). 예전 버전이 평문으로 저장해 둔 토큰은 다음 실행 때 암호화해 다시 저장하고, 암호화를 쓸 수 없으면 파일에서 지우므로 토큰을 다시 입력해야 합니다.

## 위젯 화면

### 제목줄

| 버튼 | 동작 |
|---|---|
| ↻ 새로고침 | 모든 데이터를 새로 받음 ([갱신과 알림](sync-and-notifications.md) 참고) |
| 📌 항상 위 | 다른 창 위에 항상 표시 |
| ⚙ 설정 | 두레이 대시보드 설정 창 열기 |
| ✕ | 두레이 위젯 끄기 (분리한 프로젝트 위젯에서는 그 창만 닫기). Desk Widgets는 트레이에서 계속 실행되며, 위젯 관리에서 다시 켭니다. 앱 전체 종료는 트레이 → **Desk Widgets 종료** |

제목 옆 상태 표시: `방금`, `3분 전`(마지막 갱신), `갱신 중…`, `잠금 중 · 갱신 멈춤`, `자리 비움 · 갱신 멈춤` 등.

### 전체 화면

- 위쪽 숫자: **미완료 / 지연 / 마감 임박 / 내 업무** (표시 중인 모든 프로젝트 합계)
- **검색창**: 모든 프로젝트의 업무를 검색
- **프로젝트 / 내 분류** 전환
  - 프로젝트: 프로젝트 카드. **카드를 끌어다 놓아 순서를 바꿀 수 있음**(바로 저장). 업무가 없는 프로젝트는 아래에 접혀 있음
  - 내 분류: 내가 만든 분류 카드

### 프로젝트 화면 (프로젝트 카드 클릭)

- 미완료·지연·임박·최근 7일 완료
- 상태별 막대와 워크플로(접수·처리중 등)별 개수
- 담당자별 미완료(빨간색은 지연)
- 업무 목록: **지연 / 임박 / 내 업무 / 최근** 탭, 검색창(이 프로젝트의 미완료 업무 전체)
- 오른쪽 위 ↗: 이 프로젝트를 **별도 위젯 창**으로 띄우기. 창 위치와 분리 상태는 다음 실행 때도 유지

### 화면 이동 (뒤로/앞으로)

- **마우스 뒤로 버튼** 또는 **Alt+←**: 이전 화면 (제목줄 ←와 같음)
- **마우스 앞으로 버튼** 또는 **Alt+→**: 다시 앞으로. 돌아가면 그때 보던 탭(지연/임박/내 업무/최근)과 스크롤 위치도 복원
- 뒤로 가기는 열린 분류 팝업 닫기 → 검색어 지우기 → 이전 화면 순서로 동작
- 전체 ↔ 프로젝트 ↔ 분류 화면, 프로젝트/내 분류 전환이 기록됨 (분리한 프로젝트 위젯은 화면이 하나라 해당 없음)

### 업무 한 줄

- 제목 클릭: 두레이에서 업무 열기
- 태그 칩: 1개만 보이고 나머지는 `+N`을 눌러 펼침. 칩을 누르면 그 태그로 검색
- 오른쪽 🏷 버튼: 내 분류에 넣기/빼기 (분류에 들어 있으면 색 점으로 표시)

### 바탕화면 위젯처럼 두기

- 평소에는 다른 창처럼 앱을 열면 그 아래로 가려집니다.
- 항상 맨 위에 두려면 제목줄 📌(항상 위)를 켭니다.
- 트레이 → 위젯 관리 · 설정 → 일반 설정 → 동작 → **바탕 화면 보기(Win+D)** 에서 방식을 고릅니다. 모든 위젯(두레이·시계)에 함께 적용됩니다.

| 방식 | 동작 |
|---|---|
| 바탕화면에 고정 (기본) | 위젯을 바탕화면에 딸린 창으로 만들어 Win+D에 **처음부터 숨겨지지 않음**. Win+D를 한 번 더 누르면 숨긴 창이 돌아옴(위젯을 선택한 상태에서도). 탐색기가 재시작돼도 1초 안에 다시 고정 |
| 가려지면 다시 표시 | Win+D로 가려지는 순간을 감지해 다시 보여 줌. 잠깐 깜빡임 |
| 다른 창처럼 숨겨짐 | Win+D에 다른 창과 함께 숨겨짐 |

## 검색

- 검색 대상: 제목, 업무 번호, 프로젝트, 상태, 담당자, 등록자, 태그
- 여러 단어는 **모두 포함**하는 업무만 (예: `홍길동 패치`)
- **초성 검색**: `ㅎㄱㄷ` → 홍길동, `ㅇㅅㅅㅊ` → 예시시청
- 고객사 태그로 검색하면 그 고객사 업무를 프로젝트에 상관없이 모아 볼 수 있음

## 나만의 분류

- 분류는 **이 PC의 앱에만** 저장됩니다(`categories.json`). 두레이나 다른 사람에게 보이지 않습니다.
- 분류 하나에 여러 프로젝트의 업무를 넣을 수 있고, 업무 하나를 여러 분류에 넣을 수 있습니다.
- 분류에 넣은 업무는 완료되거나 숨긴 프로젝트에 있어도 상태를 따라갑니다. 삭제됐거나 볼 수 없게 된 업무는 `확인 불가`로 표시됩니다.
- **분류 관리 창**(내 분류 → 분류 관리, 또는 두레이 설정 → 분류 관리 열기): 이름·색 변경, 순서, 삭제, 분류별 업무 검색, 분류에서 빼기, 완료 업무 정리

## 알림

화면 오른쪽 아래에 카드로 뜹니다. 위로 겹치지 않게 쌓이고, 작업 중인 창의 포커스를 빼앗지 않습니다.

| 알림 | 조건 |
|---|---|
| 나를 멘션 | 새 댓글이나 새 업무 본문에서 나를 멘션 |
| 나에게 배정 | 담당자에 내가 새로 들어감 |
| 새 댓글 | 내 업무 범위 안의 업무에 다른 사람이 댓글 |
| 댓글 수정 | (기본 꺼짐) 내 업무 범위 안에서 다른 사람이 **앞서 알림을 받았거나 앱이 본** 댓글을 고침. 카드에는 `이름 (수정)`과 새 내용이 보임. 앱을 다시 켠 직후의 첫 수정은 놓칠 수 있음 |
| 새 업무 | 표시 중인 프로젝트에 새 업무 (내가 등록한 것 제외) |
| 상태 변경 / 완료 / 마감 지남 | 내 업무 범위 안의 업무 |

- 카드를 누르거나 **열기**: 두레이에서 해당 업무(댓글 알림이면 그 댓글 위치)로 이동
- **분류** 버튼(업무가 있는 카드): 위젯을 열지 않고 그 업무를 내 분류에 넣고 빼기. 누르면 카드가 위로 커지며 분류 목록(색 표시)이 나오고, 눌러서 체크/해제, 아래 칸에 이름을 쓰고 **추가**하면 새 분류를 만들어 바로 넣습니다. 위젯의 내 분류 화면에 바로 반영되고, 버튼에는 들어 있는 분류가 표시됩니다(예: `● 이번 주 집중 +1`). Esc나 카드 밖을 누르면 닫히며, 열려 있는 동안 그 카드의 자동 닫기만 멈춥니다
- **확인**: 닫기
- 쌓이는 순서: **새 알림이 맨 위**, 오래된 알림이 아래. 새 알림은 항상 바로 표시되고, 최대 개수를 넘으면 **가장 오래된 카드가 잠시 빠져 대기**합니다(사라지지 않음). 카드를 닫아 자리가 나면 가장 최근에 빠진 카드부터 맨 아래로 돌아옵니다. 대기 중인 알림이 있으면 **맨 아래 카드**에 `+N건 대기` · **모두 확인**(대기 중인 것까지 모두 닫기)이 표시됨
- 분류 메뉴가 열린 카드는 빠지지 않고, 대신 그다음으로 오래된 카드가 빠집니다. 자동 닫기 시간은 화면에 보이는 동안만 흐르고, 대기했다 돌아온 카드는 처음부터 다시 셉니다
- 판단 기준과 한계는 [갱신과 알림 동작 방식](sync-and-notifications.md) 참고

## 조건 알림

정해 둔 조건을 매일 확인해서 맞지 않으면 알려 줍니다. 예: **일일보고 프로젝트에 전일 등록된 보고가 없으면 알림**.

두레이 설정(⚙) → 알림 → **조건 알림 관리**에서 규칙을 만듭니다.

| 항목 | 설명 |
|---|---|
| 확인할 프로젝트 | 여러 개 선택, 프로젝트마다 따로 판정. 위젯에서 숨긴 프로젝트도 가능. 이름으로 거른 뒤 "보이는 항목 모두 선택" |
| 조건 | **전일** 또는 **당일**에 등록된 업무가 N건 미만이면 알림 (완료된 업무도 셈) |
| 태그 조건 (선택) | 태그 이름에 이 글자가 들어간 업무만 셈. 예: `일일보고` (주간보고와 구분) |
| 확인 시각·요일 | 예: 09:30, **평일만**(월요일은 금요일 기준) 또는 매일 |
| 다시 알림 | 한 번만, 또는 해결될 때까지 30분~4시간마다 |

- 확인 시각에 PC가 꺼져 있었거나 자리를 비웠으면, 돌아왔을 때 그날 한 번 확인합니다.
- 알림 카드: `10/16(금) 등록 없음: 기술팀-업무보고`처럼 미충족 프로젝트를 보여 주고, 누르면 첫 번째 프로젝트를 엽니다.
- **지금 확인**: 저장한 규칙을 바로 확인해 프로젝트별 건수(✓/✕)와 알림 카드를 보여 줍니다. 예약 확인 기록에는 남지 않습니다.
- 규칙 목록 옆 상태: 대기(오늘 확인 전) / 충족 / 미충족 N
- 공휴일은 따로 구분하지 않습니다(평일 기준).

## 시계 위젯

바탕화면에 작은 시계를 띄웁니다. 시계 설치 파일(`DeskWidgets-ClockWidget-Setup`)로 설치하면 바로 나타납니다.

- 끌어서 옮기면 위치를 기억합니다. Win+D 방식은 두레이 위젯과 같습니다.
- 오른쪽 클릭: **항상 위에 표시**(체크) / **스톱워치·타이머 사용**(체크) / **테마**(선택) / **설정** / **위젯 관리** / **이 위젯 끄기** / **Desk Widgets 종료**
- **항상 위에 표시**: 켜면 다른 앱 위에 계속 보이고 Win+D(바탕 화면 보기)에도 남습니다. 끄면 평소처럼 바탕화면에 붙어 다른 앱에 가려지고, Win+D를 눌러도 바탕화면에 보입니다. 오른쪽 클릭 메뉴와 설정 창 어디서 바꿔도 같이 바뀌고 기억합니다.
- **테마**: 오른쪽 클릭 → 테마, 또는 설정 창의 **테마** 칸에서 고르면 바로 바뀝니다(재시작 불필요). 테마 칸은 두레이와 같은 모양입니다: 테마 목록과 설명, **배경 불투명도**, **미리보기**, **테마 폴더 열기**, **목록 새로고침**.

| 테마 | 모양 |
|---|---|
| 다크 글래스 (기본) | 어두운 반투명 카드 |
| 라이트 | 밝은 카드 |
| 미니멀 | 배경 없이 그림자 있는 글자(어떤 배경화면에서도 읽힘) |
| 네온 디지털 | 어두운 바탕에 빛나는 청록 숫자 |
| 아날로그 | 시침·분침이 있는 원형 시계, 날짜는 작게. 초침은 **초 표시**를 켰을 때만 |

- **미리보기**: 테마 칸의 **미리보기**를 누르면 엔진 미리보기 창에서 그 테마가 지금 시각·지금 설정(스톱워치·타이머 켬/끔)으로 실제 동작합니다. **‹ ›** 로 테마를 넘겨 보고, **이 테마로 바꾸기**를 누르면 바로 적용되며 설정 창의 선택도 따라 바뀝니다. 미리보기에서는 탭만 바꿔 볼 수 있고 스톱워치·타이머 버튼은 눌러도 동작하지 않으며, 알람 추가·고치기는 할 수 없습니다. 미리보기의 배경은 그 테마의 배경 불투명도대로 보입니다.
- **배경 불투명도**: 테마 칸의 슬라이더(0~100%)로 시계 배경이 얼마나 비칠지 정합니다. **배경만** 투명해지고 글자·바늘·버튼은 그대로 또렷합니다. 슬라이더는 테마 칸에서 고른 테마의 값이고 **테마마다 따로** 기억합니다. 움직이는 동안 시계에 바로 보이고, **저장**해야 남습니다(취소하거나 창을 닫으면 원래대로). **테마 기본값**은 그 테마 처음 값으로 되돌립니다(다크 글래스 78%, 라이트 88%, 미니멀 0%, 네온 90%, 아날로그 85%). 미니멀은 원래 배경이 없어서, 올리면 뒤에 어두운 카드가 생깁니다. 아날로그는 시계판도 같은 불투명도를 따릅니다.
- **받은 테마 넣기**: 테마 칸의 **테마 폴더 열기**(`%APPDATA%\chilgong88\desk-widgets\widgets\clock\themes`)에 받은 시계 테마 폴더를 넣고 **목록 새로고침**을 누르면 목록에 나옵니다. 같은 id면 내장 테마 대신 쓰입니다. 다른 위젯(두레이 등)의 테마는 "(다른 위젯 테마)", 규격이 맞지 않는 테마는 "(호환 안 됨)"으로 보이고 고를 수 없습니다. 테마는 두레이 테마와 같은 격리 환경(네트워크·파일 접근 없음)에서 실행되고, 시계가 열어 준 기능(스톱워치·타이머·알람 버튼 등)만 쓸 수 있습니다. 만드는 방법: [테마 만들기](theme-guide.md)의 "시계 테마".
- 창 크기는 화면 구성별로 따로 기억합니다: 디지털 테마(다크 글래스와 그 색 테마)는 가로로 넓은 창, 아날로그는 정사각형, 그리고 각각 스톱워치·타이머를 켰을 때의 조금 큰 창(4가지). 테마를 바꾸거나 스톱워치·타이머를 켜고 끄면 그 구성의 마지막 크기로 바뀝니다(처음엔 기본 크기, 같은 중심). 자기 화면을 가진 받은 테마는 크기를 따로 기억합니다.
- **업데이트(#60)**: 테마가 엔진 테마 기능으로 옮겨졌습니다. 업데이트 뒤에도 같은 테마·같은 위치와 크기·같은 배경 불투명도로 뜨고, 돌던 스톱워치·타이머와 알람은 그대로 이어집니다. 이 시계는 **엔진 API 1.3**이 필요하므로 Desk Widgets 엔진을 먼저 업데이트해야 합니다(아니면 위젯 관리 창에 "호환 안 됨").

### 스톱워치·타이머·알람

- 오른쪽 클릭 → **스톱워치·타이머 사용**, 또는 설정 창에서 켭니다(기본 끔). **어느 테마에서나** 창 아래쪽에 탭 **시계 · 스톱워치 · 타이머 · 알람** 이 생기고, 버튼과 화면은 그 테마의 색을 따릅니다. 끄면 테마가 원래 모양(시계만)으로 돌아갑니다.
- 탭을 누르면 화면이 바뀌고, 마지막으로 본 탭을 기억합니다. 버튼·입력 칸이 아닌 곳을 끌면 창이 옮겨지고, 오른쪽 클릭 메뉴도 그대로입니다.
- **동작 중 표시**: 다른 탭을 보고 있는 동안 스톱워치가 돌고 있으면 **스톱워치** 탭에 이름 대신 깜박이는 점과 지난 시간(`12:34`, 1시간부터 `1:02:03`)이, 타이머가 돌고 있으면 **타이머** 탭에 남은 시간이, 켜 둔 알람이 있으면 **알람** 탭에 다음 알람 시각(`⏰ 07:30`)이 보입니다. 일시정지 중이면 점이 깜박이지 않고 흐리게, 멈춰 있으면(처음 상태·끝남) 원래 이름이 보입니다. 탭에 마우스를 올리면 "스톱워치 동작 중 12:34"처럼 나옵니다.
- **시계**: 그 테마의 시계(디지털 테마는 시각과 날짜, 아날로그는 시계판). 설정의 초 표시·12시간제를 따름
- 아날로그 테마의 스톱워치·타이머 화면은 숫자로 보이고 아날로그 테마의 색을 씁니다.
- **스톱워치**: **시작** / **일시정지** / **초기화**, `분:초.1/100초`(1시간부터 `시:분:초.1/100초`). 랩 기록은 아직 없습니다.
- **타이머**: 멈춰 있을 때 `시 : 분 : 초` 칸에 시간을 넣고 **시작**(Enter도 됨). 도는 동안은 남은 시간이 보이고 **일시정지** / **초기화**. 최대 23:59:59.
  - **프리셋** 버튼 3개(기본 **3분 · 5분 · 10분**)를 누르면 그 시간으로 바로 시작합니다.
  - **프리셋 저장**: **저장**을 누르면 프리셋 버튼이 노란 점선(`→ 3분`)으로 바뀝니다. 그중 하나를 누르면 지금 칸에 넣은 시간(도는 중이면 그 타이머의 시간)이 그 자리에 저장됩니다. 다시 **취소**나 Esc를 누르면 저장하지 않고 돌아갑니다.
  - 시간이 다 되면 **알림 카드** "타이머 종료 — `<설정 시간>` 타이머가 끝났습니다"가 짧은 소리와 함께 뜨고 **확인할 때까지 남습니다**. 카드의 **다시 시작**은 같은 시간으로 다시 시작합니다. 타이머 화면은 `00:00`이 깜박이고, **다시 시작** 또는 **초기화**를 누를 수 있습니다.
- **알람**: 정한 시각에 울립니다. 여러 개를 만들 수 있습니다(최대 20개).
  - 목록: 시각, 반복(한 번 / 매일 / 평일 / 주말 / `월·수·금`), 이름. 오른쪽 스위치로 켜고 끕니다. 목록의 알람을 누르면 고치기, **+ 알람 추가**로 새로 만들기.
  - 고치기 칸: `시 : 분`(24시간), 이름(선택, 20자), 반복할 요일(누른 요일만, 아무것도 안 누르면 **한 번**), **저장** / **취소** / **삭제**. Enter는 저장, Esc는 취소.
  - 시각이 되면 **알림 카드** "알람 — `07:30 기상`"이 소리와 함께 뜨고 확인할 때까지 남습니다. **5분 뒤 다시**를 누르면 5분 뒤 한 번 더 울리고(목록에 `다시 07:35`), **끄기**나 확인을 누르면 끝납니다. 반복 알람은 다음 요일에 다시 울립니다.
  - **한 번** 알람은 울리고 나면 스스로 꺼집니다(스위치가 꺼짐, 다시 켜면 다음 그 시각에 울림).
  - **놓친 알람**: Desk Widgets가 꺼져 있었거나 PC가 절전 중이라 울리지 못한 알람은, 다시 켜지거나 깨어났을 때 **"놓친 알람" 카드 한 장**에 모아서 보여 줍니다(소리 없음, 최근 12시간 것만). 1~2분 늦은 정도면 그냥 울립니다.
  - 알람은 **스톱워치·타이머 사용을 꺼도 울립니다**. 알람을 보거나 고치려면 이 설정을 켜서 알람 탭을 엽니다.
- 스톱워치·타이머는 화면이 아니라 시계 위젯 안에서 시각을 기준으로 돕니다. 그래서 테마를 바꾸거나 Win+D를 눌러도 계속 돌고, **스톱워치·타이머 사용을 꺼도 멈추거나 초기화되지 않으며** 꺼 둔 동안에도 타이머가 끝나면 알림이 뜹니다.
- **다시 켜도 남는 것**: 알람, 프리셋, 넣어 둔 타이머 시간, 마지막 탭, 그리고 **돌던 스톱워치·타이머**(시작 시각으로 기억). Desk Widgets를 껐다 켜거나 PC를 재시작해도 그 사이 시간이 포함된 채 이어지고, 꺼져 있는 동안 끝난 타이머는 **다시 켜질 때 알림**이 뜹니다.
- 예전(#45) **시계·스톱워치·타이머 테마**를 쓰던 설정은 처음 켤 때 **다크 글래스 + 스톱워치·타이머 사용 켬**으로 바뀌고, 그 테마의 창 위치·크기와 돌던 스톱워치·타이머는 그대로 이어집니다.
- 알려진 제한:
  - 알림은 Desk Widgets와 시계 위젯이 켜져 있을 때만 뜹니다. 꺼져 있던 동안(또는 시계 위젯을 끈 동안, 절전 중) 끝난 타이머는 다시 켜지거나 깨어난 뒤에 알림이 뜹니다.
  - Windows 시각을 바꾸면 돌던 스톱워치·타이머도 그만큼 바뀝니다. 알람은 1분 안에 새 시각을 따릅니다(시각을 앞으로 당기면 그 사이 알람은 놓친 알람으로).
  - 알람음은 알림 카드의 짧은 소리 한 번입니다(계속 울리기·소리 고르기는 아직 없음).
  - 미리보기 창에서는 실제 스톱워치·타이머·알람이 그대로 보이지만 버튼은 동작하지 않습니다(탭만 바꿔 볼 수 있음).
  - 랩 기록, 여러 타이머 동시 실행, 알림음 고르기는 아직 없습니다.
- 같은 엔진 안에서 돌아가므로 메모리가 약 28MB만 늘어납니다(정책과 합의사항의 측정값 참고).

## 캘린더 위젯

바탕화면에 월 달력과 다가오는 일정을 띄웁니다. 여러 캘린더를 **CalDAV 계정**(iCloud·네이버·네이버 웍스·두레이·기타 CalDAV 서버)이나 **ICS(iCal) 구독 주소**(Google·Outlook·공휴일 등)로 받아 한 달력에 색으로 구분해 보여 줍니다(**Google 계정 로그인**은 준비 중, 아래). CalDAV 계정의 쓸 수 있는 캘린더에는 위젯에서 **일정을 만들고 고치고 지울 수** 있고, ICS 구독은 읽기 전용입니다. 캘린더 설치 파일(`DeskWidgets-CalendarWidget-Setup`)로 설치하면 바로 나타납니다.

### 화면

- **위**: 월 달력. **‹ ›** 로 이전·다음 달(달력 위에서 마우스 휠도 됨), **오늘**로 이번 달로 돌아옵니다. 오늘은 파란 동그라미, 일정이 있는 날은 숫자 아래 **작은 점**(캘린더 색, 최대 3개)이 찍힙니다. 일요일은 빨강, 토요일은 파랑. 다른 달 날짜는 흐리게 보이고, 누르면 그 달로 넘어가 그날이 선택됩니다.
- **아래**: 일정 목록.
  - 날짜를 누르면 **그날의 일정**, 같은 날짜를 다시 누르거나 **다가오는 일정**을 누르면 오늘부터 **다가오는 일정**(기본 7일, 날짜별로 묶음)이 보입니다. 이미 끝난 일정은 다가오는 일정에서 빠집니다.
  - 한 줄: 캘린더 색 막대, 시간(`09:00 – 10:00`, 종일 일정은 `종일`, 며칠에 걸친 일정은 `22:00 ~` / `~ 02:00`), 제목. **종일 일정이 먼저**, 그다음 시작 시각 순서입니다.
  - 일정을 누르면 **자세히**: 날짜·시간, 장소, 캘린더 이름, 설명 앞부분. 일정에 웹 주소(URL)가 있으면 **브라우저에서 열기**(http/https 주소만). 쓸 수 있는 일정이면 **수정** / **삭제**, 아니면 그 이유. 닫기·Esc·바깥 클릭으로 닫습니다.
- **⟳ 새로고침**: 위쪽 **오늘** 옆. 누르면 버튼이 눌린 채 그 안의 아이콘이 돌다가, 켜 둔 모든 캘린더(CalDAV 계정·ICS 구독)를 서버에 다시 물어본 뒤 멈추고 아래 `마지막 갱신` 시각이 바뀝니다. 바뀌지 않은 캘린더는 서버가 짧게 답해(변경 표시·ETag) 부담이 적습니다. 오류가 나면 잠깐 알려 주고, 자세한 이유는 설정 창에 있습니다.
- **+**: 새 일정(CalDAV 계정에 쓸 수 있는 캘린더가 있을 때만 보임). 날짜를 두 번 클릭해도 됩니다.
- **맨 아래**: `마지막 갱신 14:03`(켜 둔 구독 중 가장 오래된 성공 시각), 오류가 있으면 `오류 N`(이유는 설정 창).
- 끌어서 옮기고(제목·빈 곳), 크기를 바꾸면 기억합니다. Win+D 방식은 다른 위젯과 같습니다.
- 오른쪽 클릭: **지금 새로고침** / **항상 위에 표시**(체크) / **테마**(기본·큰 달력) / **한 주의 시작**(일요일·월요일) / **설정** / **위젯 관리** / **이 위젯 끄기** / **Desk Widgets 종료**

### CalDAV 계정 연결 (iCloud · 네이버 · 네이버 웍스 · 두레이 · 기타)

ICS 주소 대신 **계정**으로 연결하면 그 계정의 캘린더 목록에서 볼 캘린더를 고를 수 있습니다. 모두 **앱 전용 비밀번호**(서비스가 발급하는 별도 비밀번호)와 아이디로 연결합니다.

1. 오른쪽 클릭 → **설정** → **CalDAV 계정** → **+ 계정 추가**
2. **서비스**를 고르면 그 서비스의 **앱 비밀번호 발급 방법**이 나옵니다. 안내대로 발급합니다.
3. 아이디와 비밀번호를 넣고 **연결 확인** → 찾은 캘린더 목록이 나옵니다(읽기 전용 캘린더는 `읽기 전용` 표시).
4. 볼 캘린더를 체크하고 색을 고른 뒤 **저장**. 저장하면 바로 받아옵니다.

| **네이버** | 네이버 아이디 | **애플리케이션 비밀번호** | 네이버 로그인 → 내 정보 · 보안 → 2단계 인증 → 애플리케이션 비밀번호 → 생성. 2단계 인증 계정은 로그인 비밀번호로 연결되지 않습니다 |
| **네이버 웍스** | 웍스 이메일 | **외부 앱 비밀번호** | 네이버 웍스 보안 설정(common.worksmobile.com/security-settings) → 외부 앱 비밀번호 → 생성. 조직 관리자가 Admin → 보안 → 서비스 권한에서 CalDAV를 허용해야 하고 플랜에 포함돼 있어야 합니다 |
| **두레이** | 캘린더 > CalDav 화면의 **CalDAV 아이디**(이메일과 다를 수 있음) | 평소 비밀번호, SSO 조직은 그 화면에서 발급한 **비밀번호 키** | 두레이 웹 → 이름 옆 톱니바퀴 → 캘린더 → CalDav. **Business 플랜 이상**에서만 제공되고 **내 캘린더**만 연동됩니다. 자체 구축(전용) 두레이는 그 화면에 나온 https 서버 주소를 **CalDAV 서버 주소** 칸에 넣습니다(보통은 비워 둠) |
| **기타 CalDAV 서버** | 그 서버의 아이디 | 그 서버의 비밀번호(앱 비밀번호가 있으면 그것) | Nextcloud, Radicale, SOGo, Fastmail, 사내 그룹웨어 등. **https** 서버 주소를 넣으면 캘린더 위치는 위젯이 찾습니다(`/.well-known/caldav`도 시도). 동작은 서버에 달려 있습니다 |

- **로그인이 거절되면** 서비스별 이유를 보여 줍니다. 네이버 웍스·두레이는 비밀번호 오류, 관리자 미허용, 플랜 미달이 서버에서 모두 같은 응답(401)으로 오므로 세 가지를 모두 확인하세요.
- **비밀번호 보관**: 설정 파일이 아니라 따로 **암호화**해 저장합니다(Windows 데이터 보호, 이 Windows 사용자만 풀 수 있음). 평문으로는 어디에도 쓰지 않고, 그 계정의 서버에만 보냅니다. 서버가 다른 주소로 보내려 하면(리디렉션·링크) 따라가지 않고 오류로 알려 줍니다(iCloud의 사용자별 서버 `pNN-caldav.icloud.com`만 예외). 이 PC에서 암호화 저장을 쓸 수 없으면 계정을 추가할 수 없다고 안내합니다.
- **비밀번호를 바꾸려면** 그 계정의 비밀번호 칸에 새 비밀번호를 넣고 **연결 확인 · 캘린더 다시 찾기** → 저장. 비밀번호 칸을 비운 채 누르면 저장된 비밀번호로 캘린더 목록만 다시 찾습니다(새로 만든 캘린더 추가).
- 서비스와 아이디는 계정을 만든 뒤 바꿀 수 없습니다(아이디를 바꾸면 연결 확인을 다시 해야 함). 다른 계정은 새로 추가하세요.
- **함께 볼 메일함**(#80, 계정 아래): 서버의 메일 규칙(필터)이 받은편지함이 아닌 메일함으로 옮기는 메일도 보려면 여기서 고릅니다. **메일함 불러오기**를 누르면 서버의 메일함 목록이 나오고(새 계정·바뀐 비밀번호는 먼저 **연결 확인**), 체크한 메일함이 저장 뒤 함께 보입니다. 기본은 받은편지함만.
  - 고른 메일함의 메일은 목록·안 읽은 수·새 메일 알림 카드(내용에 `계정 이름 · 메일함`)·작은 카드·대시보드 숫자에 함께 들어가고, 받은편지함이 아니면 메일함 이름이 함께 보입니다. 읽음·안 읽음·답장·전달·분류는 그 메일함의 메일 그대로 됩니다.
  - **보낸편지함·임시 보관함·휴지통·스팸·전체 보관함**은 "— 제외"로 표시되고 고를 수 없습니다(새로 온 메일이 아니므로). 서버에서 없어진 메일함은 "서버에 없음"으로 보입니다.
  - 새로 고른 메일함은 처음 한 번 **알림 없이** 목록만 채우고, 그 뒤 들어오는 메일부터 알립니다.
- **계정 삭제**: **삭제** → 저장하면 그 계정의 저장된 비밀번호와 일정도 지웁니다. 체크를 끄면 받지 않고 보이지 않습니다(비밀번호는 남음).
- 받는 기간: 보이는 달의 앞뒤 한 달과 다가오는 일정 기간. 다른 달로 넘기면 그 기간을 곧바로 더 받습니다. 캘린더마다 서버의 변경 표시(getctag/sync-token)를 먼저 보고 바뀌지 않았으면 일정을 다시 받지 않습니다.

### Google 계정 연결 (#114)

> **준비 중**: Google의 앱 확인(verification)이 끝날 때까지 **정식 버전(1.1.1 등)에는 Google 로그인이 들어 있지 않습니다**. 설정의 **Google 계정** 칸은 꺼져 있고 안내가 나옵니다. 그동안 Google 캘린더는 iCal 주소를 **ICS 구독**으로 넣어 읽기 전용으로 보세요(아래 "ICS 구독"). 아래 설명은 내부 테스트 빌드(`-test.N`)와 확인 뒤의 정식 버전 기준입니다.

Google은 앱 비밀번호로 캘린더(CalDAV)를 열어 주지 않아 **Google 로그인(OAuth)** 으로 연결합니다. 연결하면 CalDAV 계정과 똑같이 캘린더를 골라 보고, 쓸 수 있는 캘린더에는 일정을 만들고 고치고 지울 수 있습니다.

1. 오른쪽 클릭 → **설정** → **Google 계정** → **+ Google 계정 추가**
2. 평소 쓰는 **브라우저**에 Google 로그인 화면이 열립니다. 로그인하고 **캘린더 목록 보기**와 **일정 보기·수정**을 모두 허용합니다. "로그인이 끝났습니다. 이 창을 닫아도 됩니다"가 나오면 브라우저 탭을 닫습니다.
3. 설정 창에 계정 이메일과 캘린더 목록이 나옵니다(기본 캘린더와 쓸 수 있는 캘린더가 체크됨, 공휴일·공유받은 캘린더는 `읽기 전용`). 볼 캘린더와 색을 고르고 **저장**.

- **Google 비밀번호는 위젯이 보지 않습니다.** 로그인은 브라우저에서 Google과 직접 하고, 위젯은 Google이 준 로그인 토큰만 받아 이 PC에 **암호화**해 저장합니다(Windows 데이터 보호). 토큰은 Google에만 보냅니다. 접속하는 곳: `accounts.google.com`(로그인, 브라우저), `oauth2.googleapis.com`(토큰), `www.googleapis.com/calendar/v3`(캘린더).
- 로그인이 끝나지 않으면 5분 뒤 저절로 그만둡니다. **로그인 그만두기**로 바로 그만둘 수 있습니다.
- **다시 로그인**: Google 쪽에서 연결을 끊었거나(Google 계정 → 보안 → 타사 앱 연결), 비밀번호를 바꿨거나, 오래 쓰지 않아 로그인이 만료되면 상태 줄에 이유가 나오고 계정의 **다시 로그인**을 누르면 됩니다(같은 Google 계정이어야 함). 그동안은 마지막으로 받은 일정을 그대로 보여 줍니다.
- **다른 PC**: 폴더 동기화를 켜면 계정 항목(이메일·이름·색·캘린더 선택)은 다른 PC에도 가지만 로그인 토큰은 가지 않습니다. 그 PC에서는 계정이 꺼진 채 나타나고, 켜면 **로그인**을 눌러 한 번 더 로그인해야 합니다.
- **계정 삭제**: **삭제** → 저장하면 Google에서도 이 위젯의 연결을 끊고(같은 Google 계정으로 로그인한 다른 PC의 연결도 함께 끊김) 토큰과 받아 둔 일정을 지웁니다.
- 바꿀 수 없는 일정: 반복 일정(회차 하나 포함), 다른 사람이 보낸 회의 초대, 생일·Gmail에서 만든 일정·집중 시간·부재중, 읽기 전용 캘린더. Google 캘린더에서 바꾸세요. "근무 위치" 항목은 보이지 않습니다.
- 정식 버전이거나 빌드에 Google 로그인 설정이 없으면 버튼이 꺼져 있고 "Google 계정 로그인은 아직 준비 중" 안내가 나옵니다. 그때는 Google 캘린더의 iCal 주소를 **ICS 구독**으로 넣으면 읽기 전용으로 볼 수 있습니다. 테스트 빌드에서 추가한 Google 계정은 목록에 남지만 로그인할 수 없다는 오류를 보이고, 받아 둔 일정은 그대로 보입니다.
- 공개 전 상태(Google 앱 확인 전)에서는 개발자가 등록한 테스트 계정만 로그인할 수 있고 7일마다 다시 로그인해야 합니다. 준비 절차는 [Google 로그인 준비](google-oauth-setup.md).

### 테마: 기본 · 큰 달력

오른쪽 클릭 → **테마**(바로 바뀜), 또는 설정 창 **표시**의 **테마 칸**(Desk Widgets 공용 칸: 목록·설명·미리보기·배경 불투명도·테마 폴더 열기·목록 새로고침, 두레이·시계와 같은 모양)에서 고르고 **저장**합니다. 두 테마는 테마 패키지(`widgets\calendar\themes\default`, `big`)라 다른 사람이 만든 캘린더 테마도 같은 방식으로 넣어 쓸 수 있습니다.

| 테마 | 모양 |
|---|---|
| 기본 | 작은 창(300×460). 위에 월 달력(일정 있는 날에 색 점), 아래에 선택한 날·다가오는 일정 목록 |
| 큰 달력 | 큰 창(기본 800×640, 크기 조절 가능). 6주 달력이 창을 채우고 **날짜 칸 안에 일정**이 보입니다. 아래 목록은 없습니다 |

- 창 위치·크기는 **테마마다 따로** 기억합니다. 큰 달력으로 바꾸면 처음엔 기본 크기로 같은 자리(중심)에 열리고, 바꾼 크기는 다음에도 그대로입니다. 기본으로 돌아가면 기본 테마의 마지막 크기로 돌아갑니다(예전 버전에서 쓰던 위치·크기는 기본 테마로 이어짐).
- **큰 달력의 날짜 칸**:
  - 시간 일정: `09:00 제목`(캘린더 색 점), 시작 시각 순서.
  - 종일 일정과 **여러 날 일정**(밤을 넘기는 일정 포함): 캘린더 색 **막대**가 그 날들을 잇습니다. 주가 바뀌면 다음 줄에서 이어지고, 각 주의 첫 칸에 제목이 보입니다. 같은 일정은 그 주 안에서 같은 높이에 그려집니다.
  - 칸에 다 들어가지 않으면 `+N개`. 창을 키우면 더 많이 보입니다.
- 날짜 칸(빈 곳)이나 `+N개`를 누르면 그날의 **전체 일정 창**(일정을 누르면 자세히, **+ 새 일정**), 일정을 누르면 **자세히**(수정·삭제는 기본 테마와 같음), 날짜를 **두 번 클릭**하면 새 일정입니다. 오늘·주말 색·한 주의 시작 설정은 기본 테마와 같습니다.
- **미리보기**: 테마 칸의 **미리보기**는 그 테마를 실제 일정으로 띄웁니다(이전·다음, **이 테마로 바꾸기**). 미리보기 안에서는 일정을 만들거나 고치거나 지울 수 없고 링크도 열리지 않습니다.
- **받은 테마 넣기**: 테마 칸의 **테마 폴더 열기**(`%APPDATA%\chilgong88\desk-widgets\widgets\calendar\themes`)에 테마 폴더를 넣고 **목록 새로고침**. 같은 이름(id)이면 받은 테마가 내장 테마보다 먼저입니다. 다른 위젯의 테마는 "(다른 위젯 테마)"로 보이고 고를 수 없습니다.
- **받은 테마가 할 수 없는 것**: 테마는 일정만 받아서 그립니다. CalDAV 계정·비밀번호·ICS 주소는 볼 수 없고(설정 창에만 있음), 일정 만들기·수정·삭제는 테마 안에서 **클릭이나 키 입력을 한 직후에만** 되며, 삭제는 늘 위젯이 띄우는 확인 창을 거칩니다. 링크는 테마가 주소를 넘기는 것이 아니라 그 일정에 저장된 http(s) 주소만 위젯이 엽니다. 테마는 인터넷에 접속할 수 없습니다.
- **업데이트한 뒤**: 쓰던 테마, 창 위치·크기(테마마다), 배경 불투명도가 그대로입니다. 계정·비밀번호·구독·저장된 일정은 건드리지 않습니다.
- **배경 불투명도**: 테마 칸의 슬라이더(0~100%)로 위젯 배경이 얼마나 비칠지 정합니다. 테마 칸에서 고른 테마의 값이고 테마마다 따로 기억합니다(기본 80%, 큰 달력 84%). 움직이는 동안 위젯에 바로 보이지만 **저장**해야 남습니다(**취소**하거나 설정 창을 닫으면 저장된 값으로 돌아감). **테마 기본값**은 그 테마의 원래 값으로 돌립니다(이것도 저장해야 남음). 글자·칸 선·일정 막대와 색은 그대로이고 0%면 배경 없이 글자와 선만 보입니다. 일정 자세히·편집·그날 일정 창은 읽기 쉽도록 늘 거의 불투명합니다.

### 일정 만들기 · 수정 · 삭제 (CalDAV 계정)

> **처음에는 테스트용 캘린더에서 해 보세요.** 위젯이 쓰는 내용은 원래 캘린더(서버)에 바로 반영되고, 삭제는 되돌릴 수 없습니다. 서비스마다 위젯이 확인하지 못한 동작이 있을 수 있으니 중요한 캘린더에 쓰기 전에 빈 캘린더(또는 새로 만든 캘린더)로 만들기·수정·삭제를 한 번씩 해 보는 것을 권합니다.

- **만들기**: 달력 위쪽 **+**(선택한 날, 없으면 오늘) 또는 **날짜를 두 번 클릭**. 제목, 캘린더(쓸 수 있는 캘린더만, 마지막에 쓴 캘린더가 먼저 선택됨), 종일, 시작·끝 날짜와 시간(기본: 다음 정각부터 1시간. 설정의 **새 일정은 종일로 시작**을 켜면 **종일이 체크된 채** 고른 날 하루로 열리고, 종일을 풀면 다음 정각부터 1시간으로 채워집니다), 장소, 설명을 넣고 **저장**(Enter도 됨). 취소·Esc·바깥 클릭으로 닫습니다.
- **수정 · 삭제**: 일정을 누른 자세히 창의 **수정** / **삭제**. 수정에서는 캘린더를 바꿀 수 없습니다. 삭제는 확인 창에서 **삭제**를 눌러야 지워집니다.
- **저장은 뒤에서**: **저장**·**삭제**(확인 창 다음)를 누르면 편집 창·자세히 창이 바로 닫히고, 바뀐 내용이 곧바로 달력에 보입니다(새·수정 일정은 흐리게 `저장 중…`, 삭제한 일정은 바로 사라짐). 서버에 쓰고 **그 캘린더를 다시 읽어** 실제로 바뀐 것을 확인하는 일은 그동안 뒤에서 하고, 끝나면 보통 모양으로 돌아옵니다. 저장 중인 일정은 끝날 때까지 다시 수정할 수 없습니다. 같은 일정을 고친 뒤 바로 지우면 서버에도 그 순서대로 갑니다.
- **실패하면 알림 카드**(확인할 때까지 남음, 같은 일정은 한 장으로 바뀜): `일정 저장 실패` / `일정 삭제 실패`(네트워크·로그인·서버 오류, 다른 곳에서 바뀜)와 `반영 확인 안 됨`. 카드에 일정 제목과 이유가 나오고, 달력은 서버에 있는 내용으로 돌아갑니다(만들려던 일정은 사라지고, 지우려던 일정은 다시 보임). **다시 시도**는 같은 저장·삭제를 다시 보내고, 다른 곳에서 바뀐 일정은 덮어쓰지 않도록 서버의 새 내용으로 편집 창을 엽니다(삭제는 바뀐 일정을 먼저 보여 줌). **열기**는 위젯에서 그 날짜·일정을 보여 줍니다. 성공하면 카드는 뜨지 않습니다.
- 저장 중에 캘린더 위젯을 끄거나 Desk Widgets를 종료하면: 이미 서버로 보낸 요청은 그대로 끝나지만(결과 알림 없음) 아직 차례를 기다리던 저장·삭제는 보내지 않고 버립니다. 종료가 요청 중간이면 서버에 반영됐는지 알 수 없으니, 다시 켠 뒤 달력(서버 내용)을 확인하세요.
- **반영 확인 안 됨**(⚠): 서버가 요청을 받았다고 했지만 다시 읽었을 때 바뀐 내용이 없을 때입니다(두레이에서 실제로 있었던 현상). 위젯은 서버에 있는 내용을 그대로 보여 주고(바꾸기 전 상태) 알림 카드로 알려 주며, 다시 보내거나 지우고 새로 만드는 식으로 억지로 바꾸지 않습니다(서버가 나중에 반영할 수도 있어 카드에 다시 시도는 없음). 원래 캘린더 앱에서 확인하세요. 나중 새로고침에서 바뀐 내용이 보이면 표시가 사라집니다.
- **다른 곳에서 바뀐 일정**: 위젯이 보여 준 뒤 다른 기기나 앱에서 그 일정이 바뀌었으면 덮어쓰지 않고 알림 카드로 "다른 곳에서 이 일정이 바뀌었습니다"라고 알린 뒤 새 내용을 받아 옵니다. 카드의 **다시 시도**로 새 내용을 보고 다시 수정하세요.
- 수정할 때는 **바꾼 항목만** 고쳐 씁니다. 위젯이 보여 주지 않는 알림(미리 알림), 참석자, 서비스 고유 정보는 그대로 남습니다. 설명을 고치면 Outlook 등이 쓰는 HTML 설명 사본은 지웁니다(이전 설명이 계속 보이지 않도록).
- 시간은 **UTC**로 저장합니다(종일 일정은 날짜만). 다른 캘린더 앱에서는 각자 시간대에 맞춰 같은 시각으로 보입니다.
- **여기서 바꿀 수 없는 일정**(자세히 창에 이유가 나옴, 원래 캘린더 앱에서 바꾸세요):
  - ICS 구독 캘린더의 일정, 서버가 쓰기 권한을 주지 않은 캘린더(공유받은 캘린더 등)
  - **반복 일정**(매주 회의 등)과 반복 중 하루만 바꾼 일정
  - **다른 사람이 보낸 회의 초대**(주최자가 내 계정이 아니고 참석자가 있는 일정). 두레이처럼 CalDAV 아이디가 이메일과 다르면 내가 만든 회의도 여기에 해당할 수 있습니다
  - 한 파일에 여러 일정이 묶여 있거나, 서버가 일정의 버전(ETag)을 주지 않는 경우

### D-day (#76)

날짜까지 남은 일수(또는 지난 일수)를 달력 위젯에서 바로 봅니다. 새 위젯이 아니라 캘린더 위젯의 부가 기능입니다.

- **만들기**: ① 일정을 눌러 연 자세히 창의 **D-day로 표시**(읽기 전용 일정·반복 일정·구독 일정에도 쓸 수 있음) ② 달력 위쪽 **★** 또는 D-day 줄의 **+ 추가**로 제목·날짜·색만 넣기. 이미 표시한 일정은 같은 버튼이 **D-day 해제**로 바뀝니다(일정은 지워지지 않음).
- **세는 방식**: 앞으로 `D-3`, 오늘 `D-day`, 지나면 `D+2`. **당일 포함**을 켜면 당일이 `D+1`(첫날이 1일째, 사귄 날·입사 100일 같은 기념일용). **매년 반복**(생일·기념일)은 다음에 돌아오는 날을 세고 지나도 보관되지 않으며, 2월 29일은 평년에 **2월 28일**로 셉니다.
- **일정에서 만든 D-day**는 일정 번호(uid)로 연결되어 일정 날짜가 바뀌면 따라가고(반복 일정은 다음 회차), 제목도 따라갑니다(D-day 창에서 직접 고치면 그 제목을 씁니다). 일정이 지워지거나 계정이 꺼지면 **마지막 날짜로 계속 세고** `일정 없음` 표시가 붙습니다.
- **기본 테마**: 달력과 일정 목록 사이에 **D-day 줄**(가까운 순, 기본 3개, 넘치면 `+N개 더`). 줄을 누르면 D-day 창(수정·삭제·**날짜로 이동**). D-day가 하나도 없으면 줄은 보이지 않습니다.
- **큰 달력**: D-day 날짜 칸 모서리에 `★ 제목` 배지, 창 위쪽에 가장 가까운 D-day 최대 3개 요약 줄. 배지·요약을 누르면 D-day 창.
- **보관함**: 날짜가 지난 한 번짜리 D-day는 기본 7일 뒤 줄에서 빠져 **보관함**으로 갑니다(삭제 아님, 줄의 **보관함 (N)**으로 보기·수정·삭제. 날짜를 고치면 진행 중으로 돌아옵니다).
- **알림(선택)**: D-day 창의 **알림 받기**를 켜면 오전 9시에 **당일**과 **1·3·7일 전** 중 고른 날 알림 카드가 뜹니다. 설정의 **D-day 알림 카드**(이 PC에서만, 기본 꺼짐)도 켜야 합니다. 같은 날짜의 같은 알림은 한 번만, 놓친 알림은 그날 안에만 늦게 보냅니다. 카드의 **열기**는 그 날짜로 이동합니다.
- **PC 간 동기화**: D-day 목록과 알림 규칙은 다른 PC와 동기화됩니다(동기화를 켠 경우). 어떤 알림을 이미 보냈는지와 알림 스위치는 PC마다 따로입니다.
- 설정(캘린더 → 표시): D-day 표시(기본 켬), 줄의 최대 개수(1~10, 기본 3), 보관까지 일수(기본 7, 0 = 옮기지 않음), D-day 알림 카드(이 PC, 기본 꺼짐). D-day는 500개까지입니다.

### ICS 구독 추가하기

오른쪽 클릭 → **설정** → **구독한 캘린더 (ICS)** → **+ 구독 추가** → 이름·색·주소를 넣고 **저장**. 저장하면 바로 받아오고, 각 구독 아래에 `마지막 갱신 · 일정 N개 · 캘린더 이름` 또는 오류 이유가 보입니다.

- 주소는 `https://…`, `http://…`, `webcal://…`(https로 받음)을 넣을 수 있습니다.
- 체크를 끄면 그 구독은 받지 않고 달력에도 보이지 않습니다(주소는 남음). **삭제**하면 그 구독의 저장된 일정도 지웁니다.
- 어디서 주소를 찾나요:
  - **Google 캘린더**(웹): 설정 → 왼쪽 **내 캘린더의 설정**에서 캘린더 선택 → **캘린더 통합** → **iCal 형식의 비공개 주소** 복사. 이 주소를 아는 사람은 누구나 일정을 볼 수 있으니 남에게 보이지 마세요(유출되면 같은 곳에서 재설정).
  - **Outlook.com / Microsoft 365**(웹): 설정 → 캘린더 → **공유 캘린더** → **캘린더 게시**에서 캘린더와 공개 범위를 고르고 **게시** → **ICS** 링크 복사. 회사 계정은 관리자가 게시를 막아 두었을 수 있습니다.
  - 그 밖의 서비스도 "iCal", "ICS", "캘린더 구독 주소", "webcal" 주소를 제공하면 그대로 넣으면 됩니다.
- **대한민국 공휴일**(Google 공개 캘린더):
  `https://calendar.google.com/calendar/ical/ko.south_korea%23holiday%40group.v.calendar.google.com/public/basic.ics`

### 갱신

- 기본 **15분마다**(설정에서 5~1440분), 그리고 위쪽 **⟳**·오른쪽 클릭·설정 창의 **지금 새로고침**으로 바로 받습니다.
- 서버가 지원하면 바뀌지 않은 캘린더는 짧은 "변경 없음" 응답만 받습니다(Google 공개 주소는 지원하지 않아 매번 전체를 받습니다).
- PC가 잠겨 있거나 절전·자리 비움 중에는 받지 않고, 돌아오면 바로 받습니다(두레이 위젯과 같은 규칙).
- 마지막으로 받은 일정은 PC에 저장해 두어, Desk Widgets를 다시 켜면 **바로** 보이고 인터넷이 끊겨도 그대로 보입니다. 받기에 실패하면 이전 일정을 그대로 보여 주고 설정 창에 이유를 표시합니다.

### 알려진 제한

- 일정 쓰기는 CalDAV 계정의 쓸 수 있는 캘린더만, 반복 일정·남의 회의 초대 등은 읽기 전용(위 "여기서 바꿀 수 없는 일정"). 일정을 다른 캘린더로 옮기기, 반복 일정 만들기, 알림·참석자 편집은 없습니다. Google 계정 로그인(#114, 위)은 Google 앱 확인 뒤 정식 버전에 들어갑니다. Microsoft(Outlook) 계정 로그인은 나중이며, 그때까지 Outlook은 ICS 주소로 구독하세요(읽기 전용).
- 일정 쓰기는 실제 계정(iCloud·네이버·네이버 웍스·두레이)으로 아직 확인하지 못했습니다. 테스트용 캘린더에서 먼저 해 보세요.
- CalDAV: 실제 계정으로는 아직 확인하지 못했습니다(서버 응답 형태는 my_calendar_sync에서 확인된 것을 따름). 공유·구독 캘린더는 서버가 목록에 주는 것만 보입니다. 할 일(VTODO)만 담는 캘린더는 목록에 나오지 않습니다.
- 반복 일정: 매일·매주·매월·매년, 간격, 횟수·종료일, 요일(둘째 월요일, 마지막 금요일 등), 날짜(매월 말일 등), 월을 지원합니다. 시·분 단위 반복(BYHOUR 등), 주 번호·연중 날짜 반복, "이후 모든 일정 변경"(RANGE=THISANDFUTURE)은 지원하지 않아 반복의 시작 시각 그대로 보입니다.
- 시간대: 일정의 시간대(IANA 이름, Windows 이름 `Korea Standard Time` 등)를 반영해 PC 시각으로 보여 줍니다. 알 수 없는 시간대 이름은 PC 시각으로 봅니다.
- 알림(일정 시작 전 알림 카드)은 아직 없습니다.
- 한 구독 파일은 10MB까지, 응답은 20초까지 기다립니다.

## 메일 위젯

여러 메일 계정의 **받은편지함을 한 목록**으로 바탕화면에 띄웁니다(1.0.0). IMAP으로 연결하는 **두레이 메일 · 네이버 메일 · 다음(카카오) 메일 · Gmail(앱 비밀번호) · 기타 IMAP 서버**를 지원하고, 새 메일이 오면 알림 카드를 띄웁니다. 새 메일·답장·전달은 **위젯에서 그 계정으로 보내고**(#68, SMTP), 원하면 계정마다 PC의 메일 프로그램이나 웹메일로 넘길 수도 있습니다. 메일 설치 파일(`DeskWidgets-MailWidget-Setup`)로 설치하면 바로 나타나고, 계정이 없으면 설정 창이 열립니다.

Outlook.com·Microsoft 365는 Microsoft가 IMAP 비밀번호 로그인을 막아 아직 연결할 수 없습니다. **Outlook 클래식 연동(#66)**과 **Microsoft·Google 로그인(OAuth, #67)**이 다음 단계입니다.

### 화면 (기본 테마)

- **위**: `메일` + 안 읽은 메일 합계, **✎** 새 메일 쓰기, **⟳** 지금 새로고침(세 테마 모두): 누르면 버튼이 눌린 채 ⟳ 글자가 돌고, 모든 계정을 서버에 다시 물어본 뒤 멈추며 `새 메일 3통` / `새 메일 없음` / 오류(계정 이름과 이유)를 잠깐 보여 주고 아래 `갱신 HH:MM`이 바뀝니다. 새 메일을 바로 알려 주는(IDLE) 계정도 다시 확인합니다.
- **계정 칩**(계정이 둘 이상일 때): `전체`와 계정마다 색 점·이름·안 읽은 수. 누르면 그 계정만 보이고 다시 누르면 전체로. 연결 오류인 계정은 `⚠` 표시(마우스를 올리면 이유).
- **목록**: 모든 계정의 메일을 **받은 시각 최신순**으로(계정마다 고른 **함께 볼 메일함**의 메일도, 아래). 한 줄에 계정 색 막대, 보낸 사람, 받은편지함이 아닌 메일은 메일함 이름 꼬리표, 📎(첨부)·★(별표), 시각(오늘은 `14:05`, 어제, 요일, 날짜), 제목, 본문 앞부분. **안 읽은 메일은 굵게**. 맨 아래 **더 보기**로 30통(설정)씩 더 보입니다.
- 메일을 누르면 **본문 보기**: 제목·보낸 사람·받는 사람·날짜·첨부 이름과 크기, 본문(텍스트). 버튼: **원문 보기**(서식·이미지가 있는 원래 모양, 아래 "안전한 원문 보기"), **답장** / **전체 답장** / **전달**, **안 읽음**(안 읽음으로 되돌리고 목록으로), **웹메일**(그 계정의 웹메일). ‹ 또는 Esc로 목록으로.
- **뒤로·앞으로**: 마우스 **옆 버튼**(뒤로·앞으로) 또는 **Alt+← / Alt+→**로 목록 ↔ 메일, 계정 거르기를 오갑니다(두레이 위젯과 같은 방식). 목록으로 돌아오면 거르기·스크롤 위치·마지막으로 연 메일(파란 표시)이 그대로입니다. 되돌아갈 곳이 없으면 아무 일도 없습니다(위젯이 닫히지 않음). ‹ 버튼과 Esc도 앞 화면으로 갑니다. 작은 카드 테마는 화면이 하나라 옆 버튼에 반응하지 않습니다.
- 메일을 열면 **읽음으로 표시**합니다(서버에도, 설정에서 끌 수 있음). 다른 프로그램에서 읽거나 지운 메일은 위젯에도 곧 반영됩니다.
- **맨 아래**: 마지막 확인 시각, 오류가 있으면 `⚠ 연결 오류 N개 — 설정`.
- 오른쪽 클릭: **지금 새로고침** / **새 메일 쓰기** / **새 메일 알림**(체크) / **항상 위에 표시** / **테마**(기본·작은 카드) / 설정 / 위젯 관리 / 이 위젯 끄기 / 종료.
- **작은 카드** 테마: 안 읽은 메일 수, 계정 색 점, 최근 메일 몇 통(창 높이만큼). 메일을 누르면 바로 원문 보기 창이 열립니다.
- **계정 대시보드** 테마(#72, 계정이 많을 때): 큰 창(기본 720×520, 크기 조절)에 계정마다 카드 한 장(창 너비에 따라 2~4줄, 많으면 스크롤).
  - 카드: 계정 이름·색·주소, 연결 상태(오류면 이유), **새 메일**(안 읽은 수)·**중요**(별표 수) — 둘 다 **서버가 센** 받은편지함 전체(와 함께 볼 메일함) 숫자, 메일이 있는 분류만 색 칩(**불러온 메일 중** 수), 최근 메일 3통 제목(안 읽음 굵게).
  - 숫자를 누르면 그 계정 목록이 그 조건으로 열립니다(예: 중요 → 그 계정의 별표 메일). 계정 이름 → 그 계정 전체, 제목 → 그 메일.
  - 계정 목록: 빠른 거르기 **전체 · 안 읽음 · 중요 · 분류별**, **더 보기**(그 계정만 더 불러옴), ✎ 새 메일은 **그 계정으로** 보냄. **안 읽음·중요**는 서버에 그 메일 목록을 물어 아직 불러오지 않은 오래된 메일까지 보여 주므로, 숫자와 목록이 같습니다(#83, 계정·메일함마다 처음 200통, 더 많으면 더 보기). 거르기를 누른 직후 오래된 메일이 몇 초 안에 이어 붙을 수 있습니다. **분류** 거르기만 불러온 메일 중에서 고릅니다(목록 위에 안내가 나옴, 숫자보다 적으면 더 보기).
  - 메일: 기본 테마와 같은 본문 보기(원문 보기·답장·전체 답장·전달·안 읽음·웹메일·분류).
  - 대시보드 ↔ 계정 ↔ 메일은 ‹·Esc·마우스 옆 버튼·Alt+←/→로 오가고, 돌아오면 스크롤 위치와 마지막으로 연 메일 표시가 그대로입니다. 위쪽에 모든 계정의 안 읽음·중요 합계.
  - `--mock-data`로 실행하면 예시 계정 7개(하나는 일부러 오류)로 볼 수 있습니다.

- **로그인 실패가 반복되지 않게**: 서버가 로그인을 거절하면 위젯은 혼자 다시 시도하지 않습니다(계정이 잠길 수 있음). 비밀번호를 고쳐 저장하거나 **지금 새로고침**을 누르면 다시 시도합니다. 네트워크 오류는 5초 → 15초 → … 최대 15분 간격으로 다시 연결합니다.
- **계정별 설정**(계정 아래 **알림 · 쓰기 · 웹메일**): 이 계정의 새 메일 알림, 새 메일·답장·전달을 쓸 곳(**메일 프로그램** 또는 **웹메일**), 알림 카드의 **열기**(위젯에서 보기 또는 웹메일), 웹메일 주소(두레이는 회사 주소, 예: `https://회사.dooray.com/mail`), 내 메일 주소(전체 답장에서 빼기).
- **계정 삭제**: **삭제** → 저장하면 그 계정의 비밀번호와 저장된 목록도 지웁니다. 체크를 끄면 연결하지 않습니다(비밀번호는 남음).

### 새 메일 알림

- 위젯이 켜져 있는 동안 도착한 **안 읽은 메일**마다 알림 카드 한 장: 제목 = 보낸 사람, 내용 = 메일 제목 · 계정 이름. 버튼 **열기**(위젯에서 그 메일을 보여 주고 읽음 표시, 계정 설정이 웹메일이면 웹메일), **읽음**(서버에 읽음으로 표시), **분류 ▾**(이 PC의 메일 분류 붙이기·새로 만들기, Desk Widgets 1.0.2 이상).
- 한 번에 4통 이상 오면 `새 메일 N통` 카드 한 장으로 묶습니다.
- 알리지 않는 것: 위젯을 켠 직후의 **첫 동기화**(밤새 온 메일 등은 목록과 안 읽은 수로만), **12시간보다 오래된** 메일(다른 폴더에서 옮겨 온 메일 등), 다른 곳에서 이미 읽은 메일. 자리 비움·잠금 중에 온 메일은 돌아와 다시 연결할 때 알립니다.
- 끄기: 설정 → 알림 · 읽음 → **새 메일 알림 카드**(전체), 또는 계정마다. 오른쪽 클릭 → 새 메일 알림.
- 대부분의 서버는 **IDLE**(새 메일을 바로 알려 주는 기능)을 지원해 몇 초 안에 알립니다. IDLE이 없는 서버는 **확인 주기**(기본 10분)마다 확인합니다.
- **함께 볼 메일함**(#80)은 IDLE이 받은편지함에만 걸리므로 **3분마다** 바뀌었는지(STATUS) 묻고 바뀐 메일함만 엽니다. 그래서 규칙으로 옮겨진 메일의 알림은 최대 몇 분 늦을 수 있습니다. **⟳ 새로고침**은 바로 확인합니다. 연결은 계정마다 하나 그대로입니다.

### 주소록 (이 PC에서만, #70)

메일 쓰기 창의 받는 사람·참조·숨은 참조 칸에 몇 글자를 치면 **주소록**에서 이름·주소가 나옵니다(위아래 화살표로 고르고 Enter 또는 Tab, 마우스로 눌러도 됨, Esc로 닫기). 이미 칩으로 넣은 주소는 나오지 않습니다. 초성으로도 찾습니다(예: `ㅎㄱㄷ` → 홍길동).

- **자동으로 모임**: 받은 메일의 보낸 사람·받는 사람·참조와 위젯에서 보낸 메일의 받는 사람(숨은 참조 포함). 내 계정 주소와 no-reply 같은 자동 발신 주소는 모으지 않습니다. 자주 보낸 주소가 먼저 나옵니다.
- **관리**: 설정 → **주소록** — 검색, 이름 고치기(고친 이름은 메일에서 다른 이름이 와도 그대로), 삭제(지운 주소는 받은 메일에서 다시 모이지 않고, 그 주소로 보내면 다시 들어감). 바로 적용됩니다.
- **가져오기**: 설정 → 주소록 → **가져오기 (vCard·CSV)** — 웹메일·휴대폰·Outlook에서 내보낸 `.vcf`(vCard 2.1·3.0·4.0) 또는 `.csv`(Google·Outlook 형식, "이름·이메일" 열이 있는 한국 웹메일 형식, UTF-8 또는 EUC-KR) 파일. 한 번에 여러 파일, 파일당 20MB까지.
- 이 PC에만 저장되고(`widgets\mail\contacts.json`) 어디에도 보내지 않습니다.
- **서비스 주소록과 직접 연결(CardDAV)은 아직 없습니다**: Gmail은 Google이 CardDAV에 OAuth 로그인을 요구하므로(앱 비밀번호 불가) #67 이후, 네이버·다음(카카오)·두레이는 앱 비밀번호로 연락처를 읽을 수 있는 공식 안내를 확인하지 못했습니다(확인 필요). 그때까지는 웹메일에서 주소록을 vCard·CSV로 내보내 가져오세요.

### 메일 분류 (이 PC에서만, #69)

두레이 위젯의 분류처럼 메일에 **분류**(예: 중요, 결재, 나중에)를 붙여 모아 볼 수 있습니다. 분류는 **이 PC에만** 저장되고(`%APPDATA%\chilgong88\desk-widgets\widgets\mail\categories.json`) 메일 서버·웹메일·다른 PC에는 반영되지 않습니다.

- **붙이기**: 위젯 목록에서 메일을 **오른쪽 클릭**, 또는 본문 보기의 **분류** 버튼, 또는 메일 보기 창의 **분류 ▾** → 체크(한 메일에 여러 개). 아래 칸에 이름을 넣고 **만들기**를 누르면 새 분류가 생기고 그 메일에 바로 붙습니다.
- **보이기**: 메일 줄 아래·본문 보기·메일 보기 창에 분류 색 칩.
- **거르기**: 위젯 위쪽 분류 칩(**모든 분류** · 분류별(불러온 메일 중 개수) · **분류 없음**). 다시 누르면 전체로. 뒤로·앞으로에도 포함됩니다. 지금 불러온 메일 안에서 거르므로 오래된 메일은 **더 보기** 후에 나옵니다.
- **관리**: 설정 → **메일 분류** — 이름·색 바꾸기, ▲ 순서, 삭제, 추가(이름 30자, 50개까지). 분류를 지우면 붙어 있던 메일에서도 빠집니다(메일은 그대로).
- 같은 메일은 계정 + Message-ID로 알아보므로 다시 받거나 위젯을 다시 켜도 분류가 그대로입니다. 새 메일 **알림 카드**의 **분류 ▾**로도 붙이고 새로 만들 수 있습니다(Desk Widgets 1.0.2 이상, 한 통짜리 카드만, 여러 통을 묶은 카드에는 없음).

### 안전한 원문 보기 · 이미지 표시

**원문 보기**는 위젯이 띄우는 **메일 보기 창**에서 메일을 원래 모양(HTML)으로 보여 줍니다. 메일은 남이 보낸 내용이라 다음처럼 격리합니다.

- 메일 내용은 **JavaScript가 꺼진**, 다른 화면과 분리된 보기에서 열립니다(따로 쓰는 메모리 안 세션, 권한·내려받기 없음). 스크립트·프레임·플러그인·입력 폼·`on…` 속성·`javascript:` 링크는 미리 지웁니다.
- **외부 이미지는 기본으로 막습니다**(보낸 사람이 메일을 열었는지 알아내는 추적 이미지일 수 있음). 막힌 이미지가 있으면 `외부 이미지 표시를 막았습니다` 안내와 **이 메일만 이미지 표시** 버튼이 나옵니다. 누르면 **그 메일만**, Desk Widgets를 끌 때까지 보입니다(쿠키·보낸 페이지 주소는 보내지 않음). 메일 안에 들어 있는 이미지(첨부된 인라인 이미지)는 바로 보입니다.
- 링크는 **눌렀을 때만**, `http`·`https`·`mailto` 주소만 기본 브라우저(또는 메일 프로그램)로 엽니다. 마우스를 올리면 창 아래에 실제 주소가 보입니다(보이는 글자와 다른 주소인지 확인).
- 첨부 파일은 이름과 크기만 보입니다(1.0.0에서는 내려받기 없음. 웹메일이나 메일 프로그램에서 여세요).
- 아주 큰 메일은 인라인 이미지를 빼거나 텍스트로 보여 줍니다.
- **뒤로·앞으로**: 메일 보기 창이 열린 채 다른 메일의 원문 보기를 누르면 같은 창에 열립니다. 마우스 옆 버튼(뒤로) 또는 Alt+←는 앞서 보던 메일로(최근 10통), 더 앞이 없으면 **창을 닫습니다**. 앞으로(옆 버튼·Alt+→)는 다시 다음 메일로.
- 메일 본문은 **메모리에만** 두고(최근 20통) 디스크에 쓰지 않습니다.

### 메일 보내기 (위젯에서, #68)

**✎ 새 메일**, **답장**, **전체 답장**, **전달**(위젯·메일 보기 창)을 누르면 위젯의 **메일 쓰기 창**이 열립니다. 메일 프로그램으로 넘기면 그 프로그램의 기본 계정으로 나가 보내는 사람이 틀릴 수 있어, 위젯이 **그 계정의 보내는 메일 서버(SMTP)로 직접** 보냅니다(계정 설정의 쓰기 방식 기본값 "위젯에서 보내기", 이전 버전에서 저장한 "메일 프로그램"도 한 번 이것으로 바뀜).

> **처음에는 자기 자신에게 테스트 메일을 보내 보세요.** 계정마다 받는 사람에 자기 주소를 넣고 보낸 뒤, 받은편지함에 도착하는지·보낸 사람이 맞는지·보낸편지함에 한 통만 남는지 확인합니다.

- **보내는 계정**: 답장·전달은 원래 메일이 온 계정이 기본입니다. 목록에서 다른 계정으로 바꿀 수 있습니다(보낼 수 없는 계정은 이유와 함께 흐리게).
- **받는 사람 / 참조 / 숨은 참조**: 주소를 넣고 **Enter**·쉼표(,)·세미콜론(;)·**Tab**을 누르거나 칸을 벗어나면 주소 하나가 **칩** 하나가 됩니다(이름이 있으면 이름이 보이고, 마우스를 올리면 `이름 <주소>` 전체). `홍길동 <hong@example.com>, b@x.com`처럼 여러 주소를 붙여 넣으면 주소마다 칩이 생깁니다. 칩의 **✕**로 빼고, 빈 칸에서 **Backspace**는 마지막 칩을 뺍니다. 주소가 아닌 것은 **빨간 칩**이 되고, 빨간 칩이 있으면 보내지 않습니다(눌러서 고치기). 답장·전체 답장·전달은 원래 메일에서 칩을 채웁니다(답장: Reply-To 또는 보낸 사람, 전체 답장: + 받는 사람·참조에서 보내는 계정의 주소와 중복 제외). 숨은 참조는 메일 머리글에 쓰지 않습니다.
- **본문**: 텍스트(서식 없음). 답장은 "날짜, 보낸 사람 님이 작성:" 다음에 `> ` 인용, 전달은 "전달된 메일" 머리글 + 원문. 제목에는 `Re:` / `Fwd:`가 붙고(이미 있으면 그대로), 답장은 대화로 묶이도록 In-Reply-To·References 머리글을 넣습니다.
- **서명**: 계정 설정의 **서명 (메일 쓸 때 자동으로 넣기)**(계정 칸, 연결 확인 아래)이 새 메일·답장·전달 모두 본문 아래(답장·전달은 인용 위)에 `-- ` 줄과 함께 들어갑니다(텍스트만). 쓰기 창에서 **보내는 계정**을 바꾸면 서명도 그 계정 것으로 바뀝니다. 서명 부분을 직접 고쳤으면 그대로 둡니다. **보내는 사람 이름**을 넣으면 받는 사람에게 그 이름으로 보입니다.
- **파일 첨부**: 📎 파일 첨부 → PC 파일 고르기(여러 개). 첨부는 **모두 합쳐 20MB**까지, 크기가 보이고 **빼기**로 뺄 수 있습니다. 파일은 보낼 때 읽습니다(그사이 옮기면 실패로 알려 줌).
- **전달할 때 원본 첨부**: 원래 메일의 첨부가 20MB 안이면 "원본 첨부를 함께 보냄"이 켜진 채 나오고, 보낼 때 서버에서 받아 붙입니다. 너무 크면 함께 보내지 않는다고 쓰기 창에 표시합니다.
- **보내기**(Ctrl+Enter): 주소를 확인한 뒤 쓰기 창이 **바로 닫히고** 뒤에서 보냅니다. 위젯 아래에 `✉ 보내는 중…`, 끝나면 `보냈습니다: 제목`.
- **실패하면** 확인할 때까지 남는 알림 카드 `메일 보내기 실패`(제목과 이유: 로그인 거절, 보내는 주소 거절, 받는 사람 거절, 너무 큼, 연결 오류). 받는 사람 하나라도 거절되면 아무에게도 보내지 않습니다. 카드의 **다시 열기**는 쓴 내용·받는 사람·첨부를 그대로 둔 쓰기 창을 엽니다.
- **보낸편지함**: 보낸 뒤 그 계정의 보낸편지함(서버가 \Sent로 표시한 폴더, 없으면 "Sent"·"보낸메일함" 같은 이름)에 한 통 넣습니다. 서버가 이미 넣었으면(같은 Message-ID가 있으면) 넣지 않아 두 통이 되지 않습니다. Gmail은 서버가 스스로 저장하므로 기본으로 넣지 않습니다. 계정 설정 **보낸 메일 저장**: 자동 / 위젯이 저장 / 저장하지 않음.
- 답장을 보내면 원래 메일에 **답장함** 표시(\Answered)를 합니다.
- 쓰던 메일은 **메모리에만** 있습니다(디스크에 쓰지 않음). 보내지 않고 창을 닫으면 버릴지 묻고, Desk Widgets를 끄면 사라집니다. 보내기에 실패한 메일은 위젯이 켜져 있는 동안 **다시 열기**로 돌아옵니다.
- 보내는 메일 서버는 받는 서버와 같은 아이디·비밀번호(앱 비밀번호)로 로그인합니다. 새로 저장하는 비밀번호는 없습니다. 암호화된 연결(SSL/TLS 465 또는 STARTTLS 587)로만, 인증서를 확인하고, STARTTLS를 지원하지 않는 서버에는 비밀번호를 보내지 않습니다.

| 서비스 | 보내는 메일 서버 (위젯이 넣음) | 확인 |
|---|---|---|
| 네이버 메일 | `smtp.naver.com` 465, SSL/TLS | IMAP/SMTP 사용 설정이 켜져 있어야 함 |
| 다음(카카오) 메일 | `smtp.daum.net` 465, SSL/TLS | IMAP/SMTP 사용 설정 |
| Gmail | `smtp.gmail.com` 465, SSL/TLS | 앱 비밀번호 |
| 두레이 메일 | `smtp.dooray.com` 465, SSL/TLS | **확인 필요**(공식 안내로 확인하지 못함). 다르면 설정에서 바꾸기 |
| 기타 | 직접 입력: SMTP 서버·포트·보안 | |

**연결 확인**을 누르면 받는 서버와 함께 보내는 서버 로그인도 시험합니다(메일은 보내지 않음). 결과에 `보내기(SMTP) 로그인 확인됨` 또는 안 되는 이유가 나옵니다.

### 쓰기: 메일 프로그램 · 웹메일로 넘기기 (계정 설정에서 고른 경우)

계정 설정의 **새 메일·답장·전달을 쓸 곳**을 "메일 프로그램" 또는 "웹메일"로 바꾸면 예전처럼 넘깁니다. 이때 보내는 계정은 그 프로그램·웹메일이 정합니다.

- **메일 프로그램**: `mailto:` 링크로 Windows의 기본 메일 앱(Outlook 클래식·새 Outlook·Thunderbird·Windows 메일 등, Windows 설정 → 앱 → 기본 앱 → 메일)에 받는 사람·제목이 채워진 새 메일 창을 엽니다. 답장·전달에는 원문 앞부분이 짧게 인용됩니다(링크 길이 제한 때문에 약 2,000자 안에서 잘림, 끝에 `…`). 첨부 파일은 넘어가지 않습니다.
- **기본 메일 프로그램 정하기**: 답장·새 메일에 아무 반응이 없거나 "메일 프로그램을 열지 못했습니다"가 나오면 Windows에 mailto 링크를 열 프로그램이 없는 것입니다(예전 Windows "메일" 앱은 더 이상 제공되지 않아, 기본 앱 화면에 MS-UNISTORE-EMAIL·OUTLOOKMAIL만 "메일"로 남아 있는 경우가 있음). **Windows 설정 → 앱 → 기본 앱 → "링크 유형별 기본값 선택"**(또는 검색 창에 `mailto`) → **MAILTO** → Outlook 클래식·Thunderbird 등을 고르세요. 위젯 설정 창의 메일 계정 칸 아래에 지금 등록된 프로그램이 보입니다.
  - 등록된 프로그램이 **없으면**, 웹메일 주소가 있는 계정은 자동으로 **웹메일**로 씁니다("기본 메일 프로그램이 없어 웹메일로 열었습니다"). 웹메일 주소도 없으면 위 설정 방법을 안내합니다.
  - 등록은 돼 있는데 실제로는 아무 창도 뜨지 않는 경우(없어진 앱이 남아 있는 등)는 위젯이 알 수 없습니다. 그래서 넘긴 뒤 "아무 창도 뜨지 않으면…" 안내와 **웹메일로 쓰기** 버튼을 함께 보여 줍니다. 계정 설정의 쓰기를 **웹메일**로 바꾸면 항상 웹메일로 씁니다.
- **웹메일**: 그 계정의 웹메일을 브라우저로 엽니다. **Gmail**은 받는 사람·제목이 채워진 쓰기 화면이 바로 열리고, 다른 서비스는 웹메일 첫 화면이 열립니다(거기서 새 메일·답장을 누르세요).
- 웹메일에서 그 메일 바로 열기: Gmail은 그 메일을 찾아 엽니다(Message-ID 검색). 다른 웹메일은 첫 화면이 열립니다.

**Thunderbird에서 그 메일 찾기**(수동, 확인 필요): 메일 보기 창의 **Message-ID 복사**로 메일의 고유 번호를 복사한 뒤, Thunderbird에서 직접 열어 볼 수 있습니다. Thunderbird가 `mid:` 주소로 메일을 여는 기능이 있다고 알려져 있지만 공식 문서로는 확인하지 못했습니다. 명령 프롬프트에서 시험해 볼 명령(복사한 값을 `<Message-ID>` 자리에):

```bat
"C:\Program Files\Mozilla Thunderbird\thunderbird.exe" -mail "mid:<Message-ID>"
```

열리지 않으면 Thunderbird 검색 창에 제목으로 찾으세요. 위젯이 Thunderbird를 대신 실행하거나 조작하지는 않습니다.

### 갱신 · 자리 비움

- 위젯을 켜면 마지막에 받은 목록(보낸 사람·제목·시각, 본문 제외)을 바로 보여 주고, 서버에 연결해 새 메일만 받습니다.
- 새 메일은 IDLE로 바로, 없으면 **확인 주기**(분, 2~1440, 기본 10)마다. 25분마다 IDLE을 다시 걸고 그때 읽음·삭제 상태도 맞춥니다.
- PC가 잠겨 있거나 절전·자리 비움 중이면 **연결을 끊고**, 돌아오면 다시 연결해 그동안 온 메일을 받습니다(알림 포함).

### 알려진 제한 (1.0.0)

- 받은편지함과 계정 설정에서 고른 **함께 볼 메일함**(#80, 계정마다 최대 10개)만. 검색·삭제·이동·별표 바꾸기는 없습니다.
- 함께 볼 메일함은 **최근 50통**까지 보이고 **더 보기**로 그 이전 메일을 불러오지 않습니다(받은편지함만 더 보기). 3분마다 확인하므로 다른 곳에서 바꾼 읽음·별표는 그 메일함에 새 메일이 오거나 안 읽은 수가 바뀔 때, 또는 ⟳ 새로고침에 맞춰집니다.
- Gmail처럼 한 메일이 받은편지함과 다른 라벨에 함께 있으면 한 번만(받은편지함 것으로) 보입니다. 안 읽은 수는 서버 숫자를 더하므로 이런 메일은 두 번 셀 수 있습니다.
- 첨부 파일 내려받기 없음(이름·크기만, 전달할 때만 함께 보냄). 보내는 메일은 텍스트만(서식·HTML 편집 없음), 임시 저장은 메모리에만.
- Outlook.com·Microsoft 365 계정과 Outlook 클래식 연동은 아직 없습니다(#66·#67). Google Workspace처럼 앱 비밀번호를 막은 계정도 #67(OAuth)에서.
- 자체 서명 인증서를 쓰는 사내 메일 서버는 연결할 수 없습니다(인증서를 확인하지 못하면 연결하지 않음).
- 두레이 메일의 IMAP 서버 값·조건, 다음(카카오) 메일의 앱 비밀번호 필요 여부는 **확인 필요**입니다. 실제 계정으로는 아직 확인하지 못했습니다(자동 테스트는 가짜 IMAP 서버로).
- 웹메일 바로 열기는 Gmail만 그 메일·쓰기 화면을 엽니다.

## 시스템 모니터 위젯 (#74)

`DeskWidgets-SystemMonitorWidget-Setup`을 엔진 다음에 설치하면 PC 상태를 바탕화면에 표시합니다. **다크 글래스**(기본), **오션 그래프**, **막대**, **미니 바** 테마를 고를 수 있습니다. CPU 전체 사용률과 최근 기록, 메모리 사용량, 드라이브별 여유 공간, 디스크 읽기·쓰기 속도, 네트워크 송수신 속도, GPU 사용률, 배터리 상태와 가동 시간을 보여 줍니다. 코어별 CPU 사용률은 설정에서 켤 수 있습니다.

GPU 성능 카운터나 배터리가 없는 PC에서는 해당 항목을 **측정 불가**로 표시하고 다른 항목은 계속 갱신합니다. 측정은 1~10초 간격(기본 2초), CPU 기록은 최근 10~300초(기본 60초)로 설정할 수 있습니다. 창이 보이지 않거나 자리 비움 상태면 새 측정을 멈추고, 돌아오면 다시 측정합니다. PowerShell·WMI 프로세스는 실행하지 않습니다.

## 할 일 목록 위젯 (#77)

`DeskWidgets-TodoWidget-Setup`을 설치하면 기본 목록 하나가 만들어집니다. 입력 칸에 할 일을 적고 **Enter**로 추가하며, 체크하면 완료 항목 아래로 접힙니다. 목록을 여러 개 만들고 이름을 바꾸거나 선택할 수 있습니다. 할 일은 끌어서 순서를 바꾸고 삭제할 수 있습니다. 목록을 삭제하면 그 안의 할 일도 함께 삭제됩니다.

입력 끝에 한국어 날짜를 붙일 수 있습니다. 예를 들어 `보고서 제출 내일 오후 3시`, `회의 준비 다음 주 월요일`, `정리 매주 금요일 15:30`처럼 적습니다. `오늘`·`내일`·`모레`, `다음 주 <요일>`, `매주 [요일]`, `3시`·`오후 3시`·`15:30`을 해석합니다. 날짜만 정한 항목은 그날 마감으로 강조하고, 시간이 정해진 항목은 시간이 되면 알림 카드가 뜹니다. 반복 할 일을 체크하면 다음 주 같은 요일로 넘어갑니다.

알림 카드에서 **완료**하거나 **다시 알림**을 선택할 수 있습니다. 다시 알림 간격은 설정에서 고릅니다(기본 10분). PC가 꺼져 있는 동안 지난 알림 중 12시간보다 오래된 것은 뒤늦게 띄우지 않습니다. 할 일은 이 PC의 위젯 데이터 폴더에만 저장됩니다. 첫 버전에는 하위 할 일, 전역 빠른 추가 단축키, 외부 서비스 동기화가 없습니다.

### 두레이·메일·캘린더와 연결 (#94)

엔진 1.0.4/API 1.6과 이 기능을 지원하는 위젯을 함께 설치한 뒤, 각 위젯의 설정에서 필요한 연동을 켭니다. 기본값은 꺼짐입니다. 두레이 업무를 할 일로 추가하려면 **두레이 → 할 일 연동**과 **할 일 → 두레이에서 받기**를 모두 켭니다. 메일도 **메일 → 할 일 연동**과 **할 일 → 메일에서 받기**를 모두 켭니다. 각 위젯의 업무·메일에서 직접 **할 일에 추가**를 누를 때만 제목과 출처 정보가 복사됩니다. 같은 원본을 다시 추가하면 기존 할 일을 사용합니다.

할 일 목표 날짜를 캘린더에 표시하려면 **할 일 → 캘린더에 마감 표시**와 **캘린더 → 할 일 연동**을 모두 켭니다. 캘린더에서 할 일 마감을 선택해 목표 날짜·시각을 수정하면 할 일 원본이 변경되고 이전 날짜의 표시는 사라집니다. 캘린더 설정에서 완료한 할 일을 **숨김** 또는 **완료 표시**로 고릅니다. 캘린더의 **내 캘린더**는 인터넷 없이 일반 일정을 만들고 수정·삭제하는 별도 저장소로, CalDAV·ICS와 함께 표시됩니다. 연동을 꺼도 이미 복사한 할 일과 로컬 일정은 유지됩니다.

연동을 켜면 설정에 상대 위젯의 설치·사용 상태와 호환 엔진·연동 기능 등 필요 조건을 표시합니다. 조건이 부족하면 설정은 켜 둔 채 기능만 기다리며, 조건이 충족되면 사용할 수 있습니다. 목표 날짜가 있는 할 일은 별도의 CalDAV·ICS 서버 일정으로 자동 전송되지 않습니다.

## 테마

두레이 설정(⚙) → 화면 → 테마에서 고르고 저장하면 바뀝니다. 창 크기는 화면 구성별로 따로 기억합니다.

**미리보기**: 테마 옆 **미리보기** 버튼을 누르면 팝업 창에서 그 테마가 **내 데이터로** 실제 동작합니다.
- 위쪽 바의 ‹ › 버튼(또는 키보드 ←/→)으로 다른 테마로 넘기기, Esc로 닫기
- **이 테마로 바꾸기**를 누르면 위젯에 바로 적용됩니다 (설정 창의 선택도 함께 바뀜)
- 미리보기 안에서는 분류 넣기·순서 변경·별도 위젯·항상 위는 동작하지 않습니다. 업무 클릭(두레이 열기)과 새로고침은 됩니다.
- 반투명 테마의 아크릴(바탕이 흐리게 비치는 효과)은 미리보기에서는 보이지 않습니다.
- 미리보기의 배경은 테마마다 정해 둔 **배경 불투명도**대로 보입니다.

**배경 불투명도**: 설정 창 테마 선택 아래 슬라이더(0~100%)로 위젯 배경이 얼마나 비칠지 정합니다.
- 설정 창에서 고른 테마의 값이고(이름이 옆에 표시) **테마마다 따로** 기억합니다.
- **배경만** 투명해지고 글자·업무 카드·버튼·메뉴는 그대로입니다. 0%면 배경 없이 내용만 보입니다.
- 움직이는 동안 켜져 있는 위젯(그 테마일 때)과 열린 미리보기에 바로 보이고, **저장**해야 남습니다(**취소**하거나 설정 창을 닫으면 저장된 값으로 돌아감). **테마 기본값**은 그 테마의 원래 값으로 되돌립니다(이것도 저장해야 남음).
- 기본값: 다크 글래스 62%, 빅서 라이트 78%, 미니 바 94%, 미드나잇·선셋·모노 미니멀·사이드바·칸반 보드·일정 100%. 페이퍼는 불투명 창이라 슬라이더가 없습니다.
- 받은 테마는 테마가 지원할 때만(`theme.json`의 `background`) 슬라이더가 보입니다.

| 종류 | 테마 | 특징 |
|---|---|---|
| 기본 구성(색만 다름) | 다크 글래스(기본), 빅서 라이트, 미드나잇, 선셋, 모노 미니멀 | 요약 숫자 + 프로젝트 카드, 프로젝트 대시보드, 내 분류 넣기·관리, 끌어서 순서 변경 등 **모든 기능** |
| 사이드바 | 사이드바 | 메신저 앱처럼 왼쪽 레일(홈·내 업무·프로젝트·분류)에서 고르고 오른쪽에서 업무 목록. 넓게 펼쳐 두는 용도 |
| 칸반 | 칸반 보드 | 대기·할 일·진행 중 열에 업무 카드. 프로젝트 선택, 내 업무·지연/임박만 보기. 가로로 넓은 창 |
| 일정 | 일정 | 마감일 순으로 지난 업무·오늘·내일·이번 주·다음 주. 이번 주 달력 띠, 내 업무/전체 전환 |
| 미니 바 | 미니 바 | 얇은 띠에 지연·임박·내 업무·미완료 숫자만. 숫자를 누르면 그 목록이 아래로 펼쳐지고 Esc·▲로 접힘 |
| 예제 | 페이퍼 | 테마 제작용 최소 예제 |

- 사이드바·칸반·일정·미니 바에서는 업무를 **내 분류에 넣는 기능과 프로젝트 순서 변경이 없습니다**. 분류는 볼 수 있고(사이드바), 넣기·순서 변경은 기본 구성 테마나 분류 관리 창에서 하세요.
- 모든 테마에서 검색(초성 포함), 업무 클릭 시 두레이 열기, 새로고침, 항상 위를 지원합니다.
- 프로젝트를 별도 위젯으로 띄우는 버튼은 기본 구성·사이드바·칸반에 있습니다. 이미 띄운 위젯은 어느 테마에서든 그 테마 모양으로 표시됩니다.

## 실행 옵션 (개발·문제 해결용)

| 옵션 | 동작 |
|---|---|
| `--settings` | 시작할 때 위젯 관리 창 열기 |
| `--widgets-dir <폴더>` | 설치된 위젯 대신 이 폴더의 위젯 사용 |
| `--widget <폴더>` | 위젯 소스 폴더를 함께 불러오기 (위젯 개발, [위젯 만들기](widget-dev.md)) |
| `--mock-data` | 두레이 대신 가상 데이터 사용 (설정도 별도 폴더). 캘린더는 계정 대신 예시 캘린더(반복·종일·여러 날·초대 일정, 만들기·수정·삭제는 메모리 안에서). 메일은 예시 계정 3개와 메일(HTML·텍스트·첨부·외부 이미지), 20초 뒤 새 메일 한 통 |
| `--theme <폴더>` | 지정한 폴더의 테마로 실행 |
| `--devtools` | 테마 창 개발자 도구 (F12) |
| `--gpu` | 하드웨어 가속 사용 (기본은 꺼서 메모리 절약) |
| `--legacy-data-dir <폴더>` | 이전 Dooray Widget 설정을 이 폴더에서 옮겨 오기 (`--user-data-dir`와 함께 쓰는 이전 처리 확인용) |
