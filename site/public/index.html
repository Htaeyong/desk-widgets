Desk Widgets

무료 윈도우 바탕화면 위젯 엔진과 위젯

두레이 위젯, 캘린더 위젯, 메일, 할 일, 스티키 노트를 윈도우 바탕화면에 두고 필요한 위젯만 골라 설치합니다. 무료 · 오픈소스.

엔진 다운로드 (준비 중) GitHub에서 보기

엔진 · Windows 10/11 (x64)

설치 순서

  1. 엔진을 설치합니다. 엔진이 위젯을 불러오고 관리합니다.
  2. 처음 실행하면 쓸 위젯을 고르는 화면이 나옵니다. 고른 위젯이 차례로 설치되고(위젯마다 Windows 관리자 확인 창이 한 번씩 뜹니다) 엔진에 바로 나타납니다.
  3. 위젯 설치 파일을 따로 받아 직접 설치해도 됩니다. 아래 위젯 목록의 다운로드로 받으세요. 인터넷이 없는 PC에는 받아 둔 설치 파일을 위젯 고르기 화면의 내려받은 설치 파일 열기로 설치할 수 있습니다.

SmartScreen 안내 아직 코드 서명을 하지 않아 설치할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. 추가 정보 → 실행을 누르면 계속 설치됩니다. 소스 코드는 GitHub에서 누구나 확인할 수 있습니다.

시스템 요구 사항: Windows 10 또는 11 (64비트)

    코드 서명 정책 (Code signing policy)

    Desk Widgets는 SignPath Foundation의 무료 오픈소스 코드 서명을 신청했습니다. 승인되면 설치 파일은 SignPath.io가 무료로 서명하고, 인증서는 SignPath Foundation이 발급합니다. 지금 받는 설치 파일은 아직 서명되지 않았습니다.

    • 서명 대상: 이 저장소의 GitHub Actions 워크플로가 릴리스 태그에서 만든 설치 파일만 서명하고, 서명 요청은 매번 사람이 직접 승인합니다. 개인 PC에서 만든 파일은 서명하지 않습니다.
    • 커밋·검토·승인: @Htaeyong
    • 개인정보: 사용자가 직접 연결한 서비스(두레이, 메일, 캘린더 계정 등) 외에는 어떤 정보도 보내지 않습니다. 개인정보 처리

    Code signing for Desk Widgets has been applied for with SignPath Foundation. Once approved: free code signing provided by SignPath.io, certificate by SignPath Foundation. Current installers are unsigned.
